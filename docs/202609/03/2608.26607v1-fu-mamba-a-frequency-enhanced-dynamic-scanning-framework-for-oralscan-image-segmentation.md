## 摘要
口扫图像分割对于数字牙科中的计算机辅助诊断和治疗规划至关重要。然而，现有的视觉状态空间模型（SSM）通常依赖手动设计的扫描顺序将图像块展平为序列，这破坏了语义空间连续性，并阻碍了从关键前景区域提取连贯特征。此外，数据采集过程中的光照不均、反射表面和噪声等因素会通过削弱高频细节同时增强低频分量来扰乱频率分布，从而阻碍边界的精确定位。针对这些挑战，我们提出了FU-Mamba，一种在SSM架构中融合动态扫描和频域增强的创新框架。具体来说，动态Mamba块（DMB）通过可训练的偏移预测网络自适应地学习采样偏移，并执行灵活的双线性插值，从而实现内容感知扫描，保持空间连贯性。此外，频域增强块通过小波引导分解和频谱池化来平衡频谱分量，提高了在不利成像条件下的鲁棒性。实验结果表明，FU-Mamba在分割精度上取得了显著提升，在牙齿分割数据集上评估时，平均交并比（mIoU）指标提高了1.1%。项目页面：https://byte2bite.github.io/FU-Mamba/

## Abstract
Oralscan image segmentation is essential for computer-aided diagnosis and treatment planning in digital dentistry. However, existing visual state space models (SSMs) often rely on manually designed scanning orders to flatten image patches into sequences, which disrupts the semantic spatial continuity and hinders coherent feature extraction from key foreground regions. Moreover, elements such as inconsistent lighting, reflective surfaces, and noise during data acquisition disrupt the frequency distribution by diminishing high-frequency details while enhancing low-frequency components, consequently hindering the accurate localization of boundaries. In response to these challenges, we introduce FU-Mamba, an innovative framework that incorporates dynamic scanning and frequency domain enhancement within the SSM architecture. Specifically, the Dynamic Mamba Block (DMB) adaptively learns sampling offsets via a trainable offset prediction network and performs flexible bilinear interpolation, enabling content-aware scanning that preserves spatial coherence. Furthermore, a frequency domain enhancement block balances spectral components through wavelet-guided decomposition and spectrum pooling, improving robustness under adverse imaging conditions. Experimental findings indicate that FU-Mamba attains a notable enhancement in segmentation accuracy, evidenced by a 1.1% increase in the mean intersection over union (mIoU) metric when evaluated on the dental segmentation dataset. ## 2. 提出方法论

### 2.1 总体架构

- 基于 **UNet 架构**，包含编码器、解码器和跳跃连接。
- 编码器由多个 **DMB（Dynamic Mamba Block）** 堆叠而成，负责特征提取。
- 跳跃连接中嵌入 **FEB（Frequency domain Enhancement Block，频域增强块）**，实现跨尺度特征融合与频率均衡。

### 2.2 SSM 基础原理

- SSM 以隐状态 \(h(t)\) 建模输入 \(x(t)\) 到输出 \(y(t)\) 的映射，满足线性微分方程：
  \[
  h'(t) = \alpha h(t) + \beta x(t),\quad y(t) = \theta h(t) + \delta x(t)
  \]
- Mamba 框架通过时间步参数 \(\Delta t\) 将连续参数离散化（采用零阶保持 ZOH）：
  \[
  \alpha = \exp(\Delta \alpha),\quad \beta = (\Delta \alpha)^{-1}(\exp(\Delta \alpha) - I)\cdot\Delta\beta
  \]
- 离散化后系统状态更新为：\(h_t = \alpha h_{t-1} + \beta x_t\)、\(y_t = \theta h_t + \delta x_t\)。
- Mamba 的关键特点是 \(\beta\)、\(\theta\) 随输入动态变化，从而保持线性复杂度。

### 2.3 动态 Mamba 块（DMB）

- **核心思想**：动态扫描机制由**偏移预测网络（OPN）**根据输入特征学习内容感知的采样位置。OPN 由 3×3 深度卷积、层归一化、GELU 激活和线性投影组成，预测的偏移经 tanh 约束并缩放至 [-0.25, 0.25]，避免过大采样位移。
- **数学描述**：
  - OPN 预测偏移：\(\Delta r = OPN([x_1, x_2, ..., x_n])\)
  - 更新采样坐标：\(p'[h,w,:] = p[h,w,:] + \Delta r[h,w,:]\)
  - 双线性插值采样：\(X'[h,w] = \phi(p'_{h,w}, X)\)
  - 插值权重：\(g(a_x, r_x, a_y, r_y) = \max(0, 1-|a_x-r_x|) \times \max(0, 1-|a_y-r_y|)\)
- **扫描流程**：先对输入特征中每个位置（patch的锚点）预测偏移 → 更新采样坐标 → 用双线性插值在特征图上采样 → 每个特征块的采样点被排序，按动态坐标空间的空间邻近性（由排序函数 sort(p') 产生顺序）→ 重排后的序列送入 SSM。
- **边界约束策略**：预测的采样位置会裁剪到有效特征图范围内，超出边界的坐标将被投影回最近有效位置，确保牙齿边缘和低对比度区域的稳定特征提取。额外增加偏移正则化损失来约束空间位移的平滑性。
- **编码器通道配置**：四个阶段的通道数为 {64, 128, 256, 512}。DMB 在多个特征尺度上集成，逐步降低空间分辨率并增加特征维度。DWConv 和 ConvFFN 增强局部特征提取。

### 2.4 频域增强块（FEB）

- **核心思想**：利用人眼对比度敏感函数对中频最敏感的特点，通过提升低频频谱、平衡高、低频分量，使频谱分布偏向中频，以减轻高频噪声干扰并保留低频结构信息。FEB 由两个模块组成：
- **WSPM（Wavelet-guided Spectral Pooling Module，小波引导的谱池化模块）**：
  - **DWT-Conv**：可视为对输入特征分别经过深度卷积（DWConv）与批量归一化（BN）两条路径后，再执行深度维度的特征分割（Depth Split）。固定使用 Haar 小波核，对特征进行单层小波分解，得到 LL、LH、HL、HH 四个子带，通道数为 \(R^{\frac{H}{2} \times \frac{W}{2} \times 4C}\)；对子带沿通道拼接后做 1×1 卷积融合，再沿通道拆分回四个增强子带，最后通过逆小波变换重构特征图，并引入残差连接以缓解重建过程中的信息丢失。
  - **SPF（Spectrum Pooling Filter，频谱池化滤波器）**：利用 2D DFT 将空间特征映射到频域，执行中心化后分离出低频 \(S_{lf}\) 和高频 \(S_{hf}\) 区域（低频区域定义为以原点为中心的圆形区域），通过 FFT shift 仅重排频率分量空间排列不改变其幅值和相位，确保结构边界一致性；再经逆变换映射回空间域，以加权融合方式平衡高、低频成分：
    \[
    \tilde{Z} = \lambda f_{lp}(Z) + (1-\lambda) f_{hp}(Z)
    \]
  - 多分支设计：采用多分支架构，包含不同卷积深度和核形状的卷积分支——可分离卷积（1×n 与 n×1 核）增强方向敏感度，空洞卷积（rate=1、3、5、7）扩大感受野，各分支特征在通道维度拼接后由 1×1 卷积自适应融合。低频频域半径根据特征分辨率自适应：\(r = \min(H,W)/8\)，以在不同尺度上保持一致的覆盖率并避免过度抑制中频。

### 2.5 算法流程总结

DMB 的动态扫描通过 OPN 预测每个图像块的坐标偏移，结合原始坐标计算更新后的采样位置，并通过双线性插值从特征图中提取对应位置的特征；重排后的序列随后输入 SSM 进行建模。FEB 则通过深度学习变换和频谱池化实现对频率特征的校正与再平衡，最后解码器输出分割掩码。整体损失为分割损失（Dice + 交叉熵）加上偏移正则化项（权重为 0.01）。

## 6. 主要结论与发现

- **性能提升显著**：FU-Mamba 在 DSD 上 mIoU 达 **92.3%**（mBIoU 88.9%），较 U-Mamba（90.1%）提升 **2.2%**；在 OralVision 上 mIoU 91.6%（mBIoU 88.0%）。
- **相比 SAM 基线**：在 mIoU 上比 HQ-SAM 分别高出 1.1%（DSD）和 1.3%（OralVision）；比基础 SAM 提升 3.6%（DSD）和 3.5%（OralVision）。
- **效率–精度均衡**：与 HQ-SAM（91.4M 参数、168.2G FLOPs、69.5ms）相比，FU-Mamba 仅需 36.2M 参数、53.1G FLOPs、28.2ms 延迟，即以约 1/3 计算开销实现更高 mIoU，较 U-Mamba 仅增加 3.4M 参数和约 6.9ms 延迟。
- **消融研究结果**：DMB 使 mIoU 在 DSD 上比连续扫描增加 1.2%，优于局部扫描 0.7%；完整 FEB 比无 FEB 提升 1.4% mIoU；λ=0.7 为最优频率平衡权重。
- **可视化分析**：在光照差、金属嵌件、阴影/反射存在的情况下，U-Mamba 的牙齿分割不完整、HQ-SAM 的分割结果有空洞，而 FU-Mamba 能完整分割牙齿区域并抑制噪声/反射/阴影的影响，产生更精细、空洞更少的掩码，还能更好地区分牙龈和面颊界限。
- **讨论**指出 DMB 和 FEB 通过结构感知重排、中频放大和频谱再平衡，显著提升了模型边界刻画和鲁棒性能。

## 7. 优点

- **动态扫描机制创新**：DMB 提出的偏移预测网络以轻量化方式（3×3 DWConv + LN + GELU + Linear + tanh）动态调整采样点，实现内容感知的扫描路径规划，使模型能自适应聚焦关键前景区域，保留空间连续性。
- **频域建模的集成**：融合小波分解（DWT-Conv）与频谱池化（SPF），在深度学习中显式实现对频率成分的重新平衡，针对口腔图像特有的光照不均、金属伪影等挑战进行优化。
- **低秩频率分解的精度与效率兼顾**：固定 Haar 小波核不引入额外可学习参数；SPF 的 FFT shift 只重排频率分量位置（不改变幅值和相位），避免结构信息丢失；将频域操作放在下采样后的深层特征上以降低开销。整体上以较小的参数量和计算开销提升分割精度。
- **体系化消融**：对扫描设计、频域增强块、频率平衡参数、增量模块进行了节级消融，每次实验重复三次随机种子，给出均值±标准差，实验证据较充分。
- **模块化设计适用性强**：DMB 和 FEB 与 UNet 结构结合自然，可推广到其他线性注意力分割模型中。
- **人工设计扫描缺陷规避**：无需手工指定扫描顺序，通过动态采样学会了能捕捉关键结构的特征序列，从根本上去除了传统固定扫描方式对空间结构的破坏。

## 8. 不足与局限

- **失效范围**：极难成像条件（强噪声、强反射、低对比、重度牙结石遮挡）下仍会失效，约 6.5% 的测试样本存在明显分割退化，主要包括边界泄漏和局部结构遗漏。
- **动态偏移的不稳性**：不可靠的局部特征可能导致偏移预测网络生成不稳定的采样偏移，阻碍 SSM 中的结构聚合。
- **频域增强的限度**：当高频噪声与反射伪影在频谱中占主导地位时，FEB 对边界信息的增强效果减弱，难以将退化信号与有意义的边界信息分开。
- **实验覆盖限制**：训练数据来自特定临床场景（数字口内扫描仪采集），跨设备泛化能力有待外部验证。数据分布偏差和验证集规模限制可能使结论存在过拟合风险。
- **计算与数据需求**：45 轮训练和 batch size 24/32 需要较高 GPU 显存；推理延迟 28.2ms 略高于轻量级方法如 Vim（20.7ms）和 U-Mamba（24.9ms），对资源受限环境（如嵌入式移动临床设备）的部署仍有一定挑战。
- **频率增强维度**：频率平衡权重 λ 是全局固定的（0.7），未能根据局部上下文自适应调节；不同解剖区域对高/低频信息的需求可能不同。
