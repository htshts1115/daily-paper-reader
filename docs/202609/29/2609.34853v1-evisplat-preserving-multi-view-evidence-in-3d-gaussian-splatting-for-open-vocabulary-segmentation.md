## 摘要
开放词汇3D场景理解能够根据自由形式的文本查询进行物体定位与分割，而无需固定的类别词汇表。许多近期方法基于3D高斯泼溅，并在获知查询之前，将多视图观测（例如来自单个视图的掩码裁剪）整合为语言特征或紧凑的物体描述符。然而，同一物体的观测会随视角变化，且信息量并不相同：有些观测揭示与特定查询相关的线索，而另一些则提供不完整或误导性的证据。因此，查询前整合可能会抑制后续查询所依赖的线索。我们提出EviSplat，它将单个观测特征保留下来，作为后续文本查询的证据。EviSplat在类别无关的3D实例中保留各个观测特征，这些实例表示物体、物体部件或背景区域。它还为每个高斯学习一个分布，描述其观测支持哪些视觉外观。给定文本查询，EviSplat使用每个实例最相关的观测对其进行评分。然后，它通过将实例级相关性与局部支持的证据相结合，为每个高斯计算得分，并以该高斯被观测到的频率和明确程度进行加权。因此，不同查询可以从同一保留证据中利用不同的视觉线索。在多种数据集和评估协议上的实验展示了最先进的性能，证明了将多视图证据保留到查询时，并根据查询对其进行聚合的优势。

## Abstract
Open-vocabulary 3D scene understanding enables object localization and segmentation from free-form text queries without a fixed category vocabulary. Many recent methods build on 3D Gaussian Splatting and consolidate multi-view observations, such as masked crops from individual views, into language features or compact object descriptors before the query is known. However, observations of the same object vary across viewpoints and are not equally informative: some reveal cues relevant to a particular query, whereas others provide incomplete or misleading evidence. Pre-query consolidation can therefore suppress cues on which a later query depends. We introduce EviSplat, which preserves individual observation features as evidence for later text queries. EviSplat retains individual observation features within class-agnostic 3D instances that represent objects, object parts, or background regions. It also learns, for each Gaussian, a distribution describing which visual appearances its observations support. Given a text query, EviSplat scores each instance using its most relevant observations. It then computes a score for each Gaussian by combining instance-level relevance with locally supported evidence, weighted by how often and how unambiguously that Gaussian was observed. Different queries can thus draw on different visual cues from the same preserved evidence. Experiments across diverse datasets and evaluation protocols demonstrate state-of-the-art performance, supporting the benefit of preserving multi-view evidence until query time and aggregating it according to the query.

- **技术基础**：近年来大量方法基于 3D Gaussian Splatting（3DGS）构建场景表示，并将多视图观测（如单视图的 SAM 掩码裁剪）编码为 CLIP 特征。
- **核心矛盾**：
  - 同一物体的不同视角观测**信息量并不均等**：某些观测包含与特定查询相关的线索，另一些则因遮挡、模糊或掩码不准而不完整甚至误导。
  - 现有方法倾向于**在查询前进行整合**（feature distillation 或 descriptor clustering），将多视图观测压缩为语言特征或紧凑物体描述符。
  - 这种**预查询压缩（pre-query consolidation）**会抑制后续查询所依赖的线索，且一个整体上能很好代表物体的特征，未必能保留区分特定查询所需的信息。
- **整体含义**：论文主张应**将多视图证据保留至查询时刻**，让不同查询从同一组证据中抽取不同的视觉线索，从而缓解预查询压缩带来的信息损失。

## 2. 方法论

### 2.1 核心思想

EviSplat 构建**两级证据表示**，在查询到来之前只保留证据、不做语义压缩：
- **实例观测库（Instance Observation Banks）**：保留每个类无关 3D 实例的**个体观测特征**，供查询时选择。
- **高斯证据场（Gaussian Evidence Field）**：为每个高斯学习一个**外观分布**，记录该高斯局部支持的视觉外观。

查询时通过**查询引导的证据聚合**，将实例级相关性与高斯局部证据融合，得到每个高斯的分。

### 2.2 关键技术细节

**（1）多视图证据保留（§4.1）**

- **观测收集**：每个观测 $o$ 包含 SAM 掩码 $m_o$ 和单位范数 CLIP 特征 $x_o$。
- **实例关联**：采用 LaGa 的类无关亲和场，渲染并池化得到观测级亲和特征 $a_o$，用 HDBSCAN 聚类形成类无关 3D 实例 $i$，成员构成实例观测库 $B_i$。
- **证据集（Evidence Set）**：为每个高斯 $g$ 在每个源视图 $v$ 中，按渲染质量占比选出一个关联最强的观测：
  - 关联度 $u_g(o)$ = 高斯渲染质量落在掩码 $m_o$ 内的比例（考虑遮挡与透射率）。
  - 证据集 $E_g = \{o_g^{(v)} \mid u_g(o_g^{(v)}) > 0\}$。
- **关联置信度**：用相对余量 $\omega_g(o) = 1 - \frac{\max_{o' \neq o} u_g(o')}{u_g(o)} \in [0,1]$ 衡量关联的明确程度；跨高斯归一化得到权重 $w_g(o)$。
- **证据分布**：用 spherical K-means 构建冻结的视觉原型码本 $C=\{c_k\}_{k=1}^K$，将证据集加权投票到最近原型，得到经验分布 $q_g$：
  $$q_g(k) = \frac{\sum_{o \in E_g, \kappa(o)=k} w_g(o)}{\sum_{o \in E_g} w_g(o)}$$
- **高斯证据场**：为每个高斯学习共享隐向量 $z_g \in \mathbb{R}^D$ 和每尺度线性解码器 $W$，用 softmax 逼近 $q_g$：
  $$p_g = \mathrm{softmax}\left(\frac{W z_g}{\|z_g\|_2}\right), \quad L_{\text{evid}} = -\mathbb{E}_g\left[\sum_k q_g(k)\log p_g(k)\right]$$
  - **只有隐向量和解码器可训练**，3DGS 场景、CLIP 编码器、亲和场均冻结；训练**不使用文本查询或标签词汇**。

**（2）查询引导的证据聚合（§4.2）**

最终高斯得分：
$$s_g(t) = b_g(t) + \rho_g \max(e_g(t) - b_g(t), 0)$$

- **实例先验 $b_g(t)$**：
  - 对每个实例库中的个体特征分别计算 LERF 相关性 $r(x_o, t)$，再用 **mean-β 池化**（取最大的 $\lceil \beta n \rceil$ 个得分的均值）得到实例相关性 $R_i(t)$。
  - 通过查询无关的软亲和分配 $\pi_g(i)$ 加权得到 $b_g(t) = \sum_i \pi_g(i) R_i(t)$。
- **高斯局部证据 $e_g(t)$**：
  - 对码本原型计算相关性 $r(c_k, t)$，在**固定概率质量 $\gamma$** 约束下取最大平均相关性：
    $$e_g(t) = \max_\delta \frac{1}{\gamma}\sum_k \delta(k) r(c_k, t), \quad 0 \le \delta(k) \le p_g(k), \sum_k \delta(k) = \gamma$$
  - 按相关性降序贪心填充概率预算；$\gamma=1$ 退化为期望相关性。
- **观测可靠性 $\rho_g$**：
  $$\rho_g = \frac{n_g}{n_g + \bar{n}} \bar{\omega}_g \in [0,1]$$
  - $n_g$ 为证据集大小，$\bar{n}$ 为场景平均，$\bar{\omega}_g$ 为平均关联余量；观测越少或关联越模糊，可靠性越低。
  - 局部证据**只用于提升先验**（正修正），不可靠时修正幅度小。
- **多尺度与分割**：跨语义尺度平均得分后阈值化，渲染选中的高斯得到分割掩码；新查询只需重算 $r(x_o,t)$ 和 $r(c_k,t)$，表示、$\pi_g$、$\rho_g$ 均查询无关且构建一次。

## 6. 主要结论与发现

- **LERF-OVS**：EviSplat 平均 mIoU **70.7**（相对 LaGa 基线 63.6 提升 **11.2%**），mAcc@0.25 **86.5**（基线 81.9），四个场景中三个取得最优。
- **3D-OVS**：mIoU **97.4**，略优于此前最佳（97.1）。
- **ScanNet**：19/15/10 类设置下 mIoU 分别 **40.41 / 44.85 / 50.71**，mAcc 分别 **57.88 / 62.89 / 71.03**，多数类别取得最优或次优。
- **组件互补性**：
  - 仅实例先验即可将基线从 63.6 提升至 **66.2 mIoU**（无需额外表示学习）。
  - 加入高斯局部证据与可靠性加权后进一步提升至 **70.7**。
  - 观测聚合方式对比：top-β 均值（66.2）> 全平均（62.8）> 最大值（60.0），支持查询相关的子集选择。
- **局部证据聚合**：固定概率质量聚合（70.7）优于概率加权均值（67.5）和最大原型相关性（44.2）。
- **存储效率**：$D=16, K=256$ 场达到与稀疏经验分布相当的 mIoU（70.2 vs. 70.1），局部存储从 307.7 MiB 降至 173.3 MiB（**减少 43.7%**）。
- **鲁棒性**：30% 特征替换下 EviSplat 下降 1.91 点，小于基线的 4.78 点；掩码腐蚀下变化在 0.13 点以内。
- **遮挡场景**：>30% 遮挡时相对基线提升 **+10.42** 点，大于 ≤30% 遮挡的 **+5.52** 点。

## 7. 优点

- **问题洞察精准**：明确指出预查询整合会抑制查询相关线索，并用实验（目标区分度、外观差异相关性）支撑这一动机。
- **两级证据表示设计合理**：实例观测库保留个体证据，高斯证据场刻画局部支持，二者互补且消融实验证实。
- **训练完全无文本/无标签**：证据场仅用观测分布自监督训练，可泛化到任意查询，无需为新查询重训练。
- **查询无关量预计算**：$\pi_g$、$\rho_g$、证据分布均构建一次，查询时只算相关性，效率友好。
- **固定概率质量的聚合设计**：在期望相关性与最大相关性之间取得平衡，避免忽略概率支撑。
- **可靠性加权**：同时考虑观测数量与关联明确性，且 $\bar{n}$ 来自场景自身，无需额外超参。
- **存储可控**：通过隐向量+解码器压缩经验分布，提供精度-存储权衡点。
- **实验规范**：报告多次运行标准差、明确评估约定、区分单次消融与统计结果、提供失败案例（如 RAMEN 下降）。

## 8. 不足与局限

- **依赖源掩码质量与冻结 CLIP 特征**：论文自述，保留观测本身无法克服 CLIP 在**属性组合与空间关系**理解上的固有缺陷。
- **固定高斯-实例分配**：高斯到实例的亲和分配是预计算且查询无关的，论文将"改进固定分配"列为未来方向。
- **场景级增益不均匀**：主结果中 RAMEN 从实例先验的 65.1 降至 62.9；部分查询（如 "rubics cube"、"pour-over vessel"）实例先验单独使用时反而低于基线。
- **部分实验为单次运行**：参数敏感性、观测质量、融合规则对比等均为单次运行，作者已声明不构成留出测试。
- **遮挡与相关性分析样本有限**：高遮挡组仅 19 对，TEATIME 仅 1 对；外观差异相关性的因果解释受可见性、掩码内容混杂。
- **算力信息不完整**：仅说明单张 NVIDIA B200，未给出 GPU 数量、完整训练时长、端到端系统开销。
- **存储测量范围有限**：报告的存储不含观测库（190.24 MiB）、码本、可靠性值、亲和场与几何，非完整系统存储。
- **应用限制**：论文伦理声明指出，语言检索可能暴露个人空间与物品敏感信息；分割质量随查询、外观、可见性变化，基准性能不代表安全关键场景的可靠性。
