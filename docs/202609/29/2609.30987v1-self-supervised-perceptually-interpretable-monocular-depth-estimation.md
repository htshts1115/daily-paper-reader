## 摘要
自监督单目深度估计（MDE）能够在不依赖真实标注监督的情况下从单目图像预测深度，这使其在大规模和真实世界应用中具有吸引力。尽管准确率稳步提升，大多数现有方法仍然难以解释，因为深度是从 RGB 表示中推断出来的，而 RGB 表示掩盖了单个感知图像分量的影响。这种透明性的缺乏限制了对失败案例的系统分析，并降低了在安全关键场景中的可信度。本文提出了一种用于感知可解释单目深度估计（PIMDE）的自监督框架，旨在将深度预测与输入图像中不同的感知分量关联起来。该方法不直接在 RGB 输入上操作，而是将每张图像分解为一组感知特征图（PFM），每张图编码特定的视觉线索。不同的深度估计分支独立处理这些 PFM，以生成深度估计（PIDE），随后通过显式融合策略进行组合。这种表述使我们能够直接考察每个感知线索对最终深度预测的贡献。在 KITTI 基准数据集上进行的实验表明，PIMDE 达到了与已有自监督 MDE 方法相当的性能，同时为不同感知线索如何影响深度估计提供了额外洞见。这些结果表明，感知分解可以在不牺牲深度估计准确率的情况下支持可解释性。

## Abstract
Self-supervised monocular depth estimation (MDE) enables depth prediction from monocular images without requiring ground-truth supervision, making it attractive for large-scale and real-world applications. Despite steady improvements in accuracy, most existing methods remain difficult to interpret, as depth is inferred from RGB representations that obscure the impact of individual perceptual image components. This lack of transparency limits systematic analysis of failure cases and reduces confidence in safety-critical settings. This paper presents a self-supervised framework for perceptually interpretable monocular depth estimation (PIMDE), designed to associate depth predictions with distinct perceptual components of the input image. Rather than operating directly on RGB inputs, the proposed method decomposes each image into a set of perceptual feature maps (PFMs), each encoding a specific visual cue. Distinct depth estimation branches process these PFMs independently to produce depth estimates (PIDEs), which are subsequently combined through an explicit fusion strategy. This formulation allows us to examine directly the contribution of each perceptual cue to the final depth prediction. Experiments conducted on the KITTI benchmark dataset demonstrate that PIMDE achieves performance comparable to established self-supervised MDE methods while providing additional insight into how different perceptual cues influence depth estimation. These results indicate that perceptual decomposition can support interpretability without sacrificing depth estimation accuracy.

## 1. 核心问题与研究动机

- **背景**：单目深度估计（MDE）在自动驾驶、机器人、生物医学等安全敏感领域具有重要价值。相比双目/主动传感（ToF、LiDAR），单目方案成本更低。基于深度学习的自监督 MDE 利用连续帧间的几何与光度关系进行训练，无需真值深度标注。
- **核心问题**：现有自监督 MDE 方法虽精度不断提升，但内部决策过程高度不透明。深度直接从 RGB 表示回归，而 RGB 将纹理、颜色、光照、结构等视觉线索纠缠在同一隐空间中，导致：
  - 无法解释深度预测究竟由哪些图像特征主导；
  - 预测失败时难以判断错误来自纹理缺失、颜色误导还是光照变化；
  - 限制了失败案例的系统分析，降低了安全关键场景下的信任度。
- **现有方案的不足**：已有可解释性尝试多为**事后工具**（post-hoc），只能高亮有影响的图像区域，无法说明具体视觉线索如何贡献于深度预测。
- **核心洞察**：人类感知深度本质上是**多线索**的（纹理梯度、颜色关系、明暗、结构边界），因此将感知图像分量在深度估计前显式分离，可提供更透明的替代方案。
- **整体含义**：本文提出 PIMDE（Perceptually Interpretable Monocular Depth Estimation），据称是首个**内在可解释**（inherently interpretable）、且与人类感知一致的 MDE 框架，其思想源自加性卷积神经网络（ACNN）的解释机制。

## 2. 方法论

### 2.1 核心思想

- 不直接在 RGB 上操作，而是先将输入图像分解为一组**感知特征图（PFMs）**，每个 PFM 编码一种特定视觉线索；
- 每个 PFM 输入一个**独立的并行深度估计分支**（结构相同），各自产生完整的**感知逆深度估计（PIDE）**；
- 各分支 PIDE 通过**显式、固定的融合机制**组合成最终逆深度图，使每个感知线索的贡献可被直接考察。
- 基础架构借鉴 **R-MSFM**（循环多尺度特征调制，逐步迭代精化）与 **ACNN** 的并行多分支加性设计。

### 2.2 感知特征图（PFM）分解

- 采用**对立色（opponent-based）感知表示**，聚焦颜色与纹理，动机来自颜色/纹理在人类形状与场景感知中的作用。
- 选用感知均匀的 **CIE-Lab** 空间（分量近似正交）：
  - **a 通道** → 红-绿对立（RG）；
  - **b 通道** → 蓝-黄对立（BY）；
  - **L 通道** → 感知亮度，含丰富结构与纹理信息。
- 对亮度分量进一步做 **2D 离散小波变换（2D-DWT）** 以捕获纹理（多分辨率、符合人类视觉）：
  - 低频近似 → **明-暗对立（LD）**；
  - 第一层最高频带 → **粗-细纹理（CF）**，与边缘密度和细结构细节相关。
- 最终形成 4 个 PFM：**RG、BY、CF、LD**。作者强调 PFM 并非完整几何深度线索，而是可独立分析的感知分量。

### 2.3 深度估计模型与融合

- 设 PFMs 集合 P = {P₁,…,P_N}，每个 P_i ∈ ℝ^{H×W}。
- 各分支经循环精化过程预测 PIDE：
  - **d̂_i(s) = f_θ(P_i)**，i = 1,…,N，s 为精化迭代次数；
  - 关键点：PIDE 是**深度近似图**而非中间特征图，这是实现分支级可解释性的前提。
- 第 s 次迭代的融合：
  - **d̂(s) = Σ_i ω̃_i · d̂_i(s)**，其中 ω̃_i ≥ 0 且 Σω̃_i = 1。
- **融合权重获取（两阶段策略）**：
  1. 先用均匀权重 ω = 1/N 训练初始模型，生成融合深度；
  2. 通过**基于减法的分析**逐一移除分支，测量最终融合深度图的变化，得到各分支的相对差异度量向量 ω；
  3. 用 **softmax 归一化**得到最终权重：**ω̃ = softmax(ω)**；
  4. 该权重计算一次后**固定**，用于最终训练。

### 2.4 自监督训练损失

- **姿态网络**预测目标帧与相邻源帧间的相对相机变换：T_{t→t'} = PoseNet(I_t, I_{t'})，t' ∈ (t−1, t+1)。
- **可微视图合成**：I^s_{t'→t} = I_{t'}(proj(T_{t→t'}, D_t^s, K))，K 为相机内参，proj 基于针孔模型投影。
- **掩码光度重投影损失**：
  - L_p = Σ_s β^{N−s} · min_{t'} μ(I_t, I_{t'}, I^s_{t'→t}) ⊙ pe(I_t, I^s_{t'→t})；
  - β 强调后期精化；⊙ 为逐元素乘；
  - 自动掩码 **μ** 剔除违反运动假设的像素：μ = [min_{t'} pe(I_t, I^s_{t'→t}) < min_{t'} pe(I_t, I_{t'})]；
  - 逐像素光度损失 **pe = (α/2)(1 − SSIM) + (1 − α)·SmoothL1**。
- **边缘感知平滑正则**：L_s = Σ_s β^{N−s} (|∂_x d^{s*}_t| e^{−∂_x I_t} + |∂_y d^{s*}_t| e^{−∂_y I_t})，其中 d^{s*}_t 为均值归一化逆深度，防止逆深度趋于零。
- **最终损失**：L_final = L_p + λL_s。
- **分支辅助监督**：总目标 **L = L_final + λ_b Σ_i L_branch_i**，λ_b 控制分支级监督贡献。

### 2.5 可解释性机制

- 设 D_full 为使用全部分支的融合逆深度，D^{−b} 为移除分支 b 后的融合结果。
- 分支贡献定义：**ΔD = D_full − D^{−b}**。
- 由于融合操作固定且两次一致，差异可直接归因于被移除的感知分支，形成分支特异性贡献图。

## 7. 优点与亮点

- **内在可解释性设计**：不同于事后可视化，PIMDE 将可解释性嵌入模型结构本身——每个分支对应明确、有物理/感知意义的线索（RG/BY/CF/LD），融合权重固定且可追溯。
- **感知动机明确**：基于 CIE-Lab 对立色与 2D-DWT，与人类视觉感知机制（颜色对立、多分辨率纹理）对应良好，具有认知科学依据。
- **融合权重数据驱动**：通过减法分析 + softmax 归一化获得权重，避免人为设定，且权重可解释为经验贡献度。
- **可解释性与精度兼顾**：在 KITTI 上达到与主流自监督方法相当的精度，同时提供额外诊断能力。
- **分支 PIDE 是完整深度图**而非中间特征，使得分支级分析具有实际意义，这是实现可解释性的关键设计选择。
- **提供实用诊断工具**：可用于判断深度预测受结构/亮度/颜色主导，有助于安全关键场景下的失败归因。
