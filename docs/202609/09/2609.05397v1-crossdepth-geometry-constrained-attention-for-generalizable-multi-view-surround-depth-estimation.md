## 摘要
对周围环境进行可靠的3D理解是自动驾驶的核心要求。多视角环视相机系统提供了广泛的场景覆盖，但空间上相邻的图像通常仅有极小的重叠。因此，大多数像素的深度必须从单目外观线索中推断。这些线索在不同图像中可能表现不同，从而可能被深度估计模型进行不同的解释。我们针对跨图像不一致性的两个主要来源：相机内参的差异以及每幅图像有限的感受野。我们通过将特征条件化于逐像素的相机感知光线嵌入来解决前者，使网络能够考虑单目线索中与相机相关的变化。我们通过将每个像素的上下文扩展到其自身图像之外，利用受几何合理区域约束的跨图像注意力来解决后者，该区域由标定后的相机装置推导而来。该模型基于光度一致性以全自监督方式进行训练。在DDAD和nuScenes上的评估表明，在域内和跨域评估中，所提方法相较于最先进的自监督方法，在整体深度精度和跨图像深度一致性方面均有提升。代码可在 https://abualhanud.github.io/CrossDepthPage/ 获取。

## Abstract
Reliable 3D understanding of the surrounding environment is a core requirement for autonomous driving. Multi-view surround camera rigs provide broad scene coverage, but the spatially adjacent images typically overlap only minimally. Consequently, the depth of most pixels must be inferred from monocular appearance cues. These cues can appear differently across images and may therefore be interpreted differently by the depth estimation model. We target two main sources of cross-image inconsistency: differences in camera intrinsics and the limited receptive field of each image. We address the former by conditioning the features on per-pixel camera-aware ray embeddings, enabling the network to account for camera-dependent variations in monocular cues. We address the latter by extending each pixel's context beyond its own image through cross-image attention constrained to geometrically plausible regions, derived from the calibrated rig setup. The model is trained in a fully self-supervised manner based on photometric consistency. Evaluations on DDAD and nuScenes show improved overall depth accuracy and cross-image depth consistency over state-of-the-art self-supervised methods under in-domain and cross-domain evaluation. Code is available at https://abualhanud.github.io/CrossDepthPage/.

## 1. 核心问题与整体含义

**（1）研究动机与问题背景**

- 在自动驾驶等机器人任务中，可靠的 3D 场景理解至关重要，而深度估计是其中的关键环节。相比激光雷达这类直接测距传感器，基于图像重建 3D 结构成本更低且能提供密集的辐射信息。
- 多视角环视相机系统（surround-view camera rig）能够提供 360°场景覆盖，且相机间存在空间基线。若相机相对位姿以公制单位给定，可通过跨视角的光度一致性实现自监督训练，使模型学习预测具有绝对尺度意义的度量深度，无需昂贵的深度标签。
- **核心难点**在于：环视相机相邻视角的图像重叠区域非常小，大多数像素的深度主要依赖单目外观线索（物体大小、语义、遮挡、透视关系、场景布局等），而这类线索存在两类诱发跨图像不一致的因素：
  1. **相机内参差异**：同一 3D 点在具有不同内参的相机中投影，其表观尺度与透视形态有差异，模型对单目线索的解读也会相应不一致，导致同一点在不同图像中被预测为不同深度。
  2. **单张图像感受野受限**：单目线索嵌在各自图像的局部上下文中。同一 3D 点在多个视角下的周边上下文不同，深度预测可能不统一。

**（2）论文要解决的整体问题**

如何通过对这两个不一致源头的显式建模，让环视多相机深度估计在**域内和跨域**场景下都具备更高的深度精度与**跨图像深度一致性**，并且仍保持完全自监督训练范式（不依赖深度真值标签）。

## 2. 方法论

**（1）总体架构**

- 深度网络采用编码器-解码器结构：**DINOv3 ViT-S**（通过 LoRA 微调）作为共享编码器，将 N 个环视图像独立编码为多尺度 patch 特征 \(F_t=\{F_{t,l}\}_{l=1}^{L}\)；解码器基于 **DPT** 头；另有一个 **ResNet18-UNet** 位姿网络（仅在训练中用于估计前视相机的时间位姿）。
- 关键流程分两个阶段：
  1. **第一次前向**：在不启用跨图像注意力的情况下预测初始深度；
  2. **第二次前向**：利用初始深度引导在圆柱面上确定每个 token 的几何合理邻域，再启用跨图像注意力，获得最终深度预测。

**（2）跨图像特征聚合（Cross-Image Feature Aggregation）**

- **圆柱投影（Shared Cylindrical Grid）**：将每个图像 token 先用预估计深度、相机内参及 camera-to-ego 变换投影至 3D，再映射到以各相机投影中心质心为原点的公共竖直圆柱坐标 \((\theta_s, h_s)\)，从而使各图像的重叠区域在圆柱空间中映射到邻近位置。
- **避免穷举检索的高效离散化**：将圆柱表面离散为 \(B_\theta=360\) 个角度格和 \(B_h=128\) 个竖直格。每个 token 按式 (1) 获得二维格坐标，从此 2D 网格中直接取样 \(K_W \times K_W\)（默认 \(K_W=5\)）的局部窗口。横向越界的窗口自动回卷到另一侧；竖直方向越界格点直接忽略。每格允许最多 \(K_{\max}\) 个 token，候选 key 数为 \(M=K_W^2 \cdot K_{\max}\)，远小于全部 token 数。
- **跨图像注意力**：在编码器每个被选层对跨图像特征做 8 头注意力，注意权重为在 M 个几何约束候选上通过 softmax 归一化缩放点积，仅允许查询 token 与其他视角图像中的候选 token 交互（不做图像内注意力，因编码器自注意力已覆盖图像内关系）。这是与 CylinderDepth 的重要差别：CylinderDepth 用距离加权的非学习固定权重，而 CrossDepth 的权重是**可学习的且仅施加在几何合理范围内**；同时由于离散化带来的高效检索，CrossDepth 能在所有传入解码器的特征层上施加跨图像注意力，而非 CylinderDepth 的单粗分辨率。

**（3）相机感知光线嵌入（Camera-Aware Ray Embedding）**

- 为每个 patch token 根据其对应像素的相机光线方向（由内参决定）构建射线方向图 \(B_t\)，并施加 NeRF 的**正弦编码** \(\gamma_{L_{dir}}(\cdot)\)（\(L_{dir}=11\)），得到光线嵌入 \(R_t\)。
- \(R_t\) 与编码器特征 \(F_t\) 连接后，经 **CAMFusion** 模块（3×3 卷积）融合，在解码器的各个阶段注入，使特征能够建立“视觉外观—相机参数—度量深度”之间的非线性关系，而不是像传统方案那样只做全局焦距归一化和统一深度缩放。
- 相机间相对位姿不放入光照嵌入，因其已被跨图像注意力的几何约束所覆盖。

**（4）自监督训练方式**

- 训练不依赖 GT 深度，仅用**光度一致性**。损失在给定合成视图与真实视图间计算（SSIM + L1 组合）。
- 采用三类监督：
  1. **空间（spatial）**：相邻相机间，投影公式见式 (8)，提供公制尺度监督；
  2. **时间（temporal）**：同一相机相邻帧之间，位姿由 ResNet18-UNet 位姿网络预测（前视相机），再通过刚体变换转到各相机；投影公式见式 (9)；
  3. **时空（spatio-temporal）**：不同相机且不同帧之间，变换组合两两关系，见式 (10)。
- 辅助损失包括：边缘感知平滑损失、稠密深度一致性损失（DCCL）、多视图重建一致性损失（MVRCL），总损失见式 (11)，权重为 \(\lambda_{sp}=0.03\)、\(\lambda_{spt}=0.1\)、\(\lambda_{sm}=0.1\)、\(\lambda_{DCCL}=1\times10^{-3}\)、\(\lambda_{MVRCL}=0.2\)。

## 6. 主要结论与发现

- **总体精度更高**：在 DDAD 和 nuScenes 上，域内和跨域绝大多数指标优于 FSM、SurroundDepth、VFDepth、CVCDepth 和 CylinderDepth（例如 DDAD 域内 RMSE 从 CylinderDepth 的 12.76 m 降到 11.87 m，δ<1.25 从 70.9% 升到 74.7%）。
- **跨图像一致性提升显著**：尤其是在重叠区域 Depth Cons 改善明显；DDAD 域内重叠区 Depth Cons 为 4.60 m，显著低于次优的 CylinderDepth 5.68 m 和 CVCDepth 5.89 m；跨域重叠区从 CylinderDepth 7.09 m 降到 4.51 m，提升幅度很大。
- **几何约束 vs. 无约束注意力**：实验显示，将注意力约束在几何合理邻域比无约束注意力带来更好的总体精度与一致性；但邻域窗口过小或过大都会导致一致性与精度退化，\(K_W=5\) 是最优选择。
- **光线嵌入 vs. 焦距缩放**：逐 token 的相机感知光线嵌入优于焦距缩放+全局缩放因子的做法，表明模型能利用射线方向学习非线性的内参到深度映射。
- **骨干微调**：LoRA 微调比完全冻结骨干略好，但差距不大，说明预测练的 DINO 特征已包含了相当充分的单目深度线索，这与相关大模型结论一致。
- **内存与效率**：效率对比表明该方法虽沿多尺度特征做注意力，但显存开销与 CylinderDepth 相当，优于单帧 3D 体素特征融合的方法（VFDepth）和无约束跨图像注意力的方法（SurroundDepth）。

## 7. 优点

- **直击根源问题**：清晰地区分并针对性解决两类不同来源的跨图不一致（内参差异、上下文有限），而不是笼统地用单一全局缩放因子补偿。
- **用模型置换不可学习的固定匹配权重**：相对 CylinderDepth，CrossDepth 使用可学习注意力权重并加入几何约束，既保留了“只在重叠相关区域聚合”的先验引导，又让网络自行决定特征相似度权重，避免了非学习权重带来的过度平滑。
- **高效离散化方案**：将连续圆柱空间离散成二维网格，从邻域搜索 O(Z²)（穷举距离）和跨图像注意力 O(Z²) 降到 O(ZM)，使注意力能施加到更高分辨率的所有解码器特征层上，这是设计上的实质贡献。
- **泛化能力导向**：大量实验覆盖域内与跨域双向评测，并将一致性指标与精度指标并列呈现，多方位检验泛化力。
- **自监督**：整个过程不需要深度标注，有利于大型数据扩展和迁移；配合公开代码，可复现门槛较低。

## 8. 不足与局限

- **自述局限**：论文作者明确提到——跨图像注意力只在编码器特征上应用，未在解码器内部实施，因此靠近物体边界处可能出现局部深度伪影；此外，受算力条件限制，未在更大训练规模上验证方法的可扩展性。
- **实验覆盖方面**：只在 DDAD 与 nuScenes 两个自动驾驶环视数据集上验证，未见极端天气、夜晚、雨天等视觉退化条件的评测，也没有多传感器异构设置（如不同外参尺寸基线的车）的评测。
- **潜在偏差风险**：实验未报告随机种子与多次重复的方差/显著性检验；定量指标以整体平均值比较为主，尚不确定提升是否在难例（远距离小目标、遮挡、无纹理区域）上均匀分布。
- **应用限制**：完全光度一致性自监督本身依赖场景静态、光照稳定等假设，动态物体、自车与相机标定误差较大、重叠区域极小等情况可能损害训练；推理时间与吞吐量未给出，不便于评估实际车上实时部署前景。
