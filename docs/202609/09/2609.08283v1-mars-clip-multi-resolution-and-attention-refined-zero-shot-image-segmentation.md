## 摘要
对比语言-图像预训练（CLIP）在零样本迁移中展现了令人印象深刻的能力，但由于低空间分辨率和结构信息的丢失，其往往难以应对密集预测任务。为解决这些局限，我们提出了MARS-CLIP（用于CLIP的多分辨率与注意力精炼分割），一种用于零样本语义分割的新颖框架。我们的方法引入了两个关键策略：（i）多分辨率特征提取模块，将局部细粒度特征与全局上下文相融合，以克服输入分辨率的限制；（ii）注意力精炼机制，将中间层的空间和颜色偏差注入最终的自注意力块中，以准确恢复对象边界。在六个公开数据集上的一系列实验表明，MARS-CLIP显著优于最先进的方法。

## Abstract
Contrastive Language-Image Pre-training (CLIP) has demonstrated impressive capabilities in zero-shot transfer but often struggles with dense prediction tasks due to low spatial resolution and the loss of structural information. To address these limitations, we propose MARS-CLIP (Multi-resolution and Attention Refined Segmentation for CLIP), a novel framework for zero-shot semantic segmentation. Our approach introduces two key strategies: (i) a multi-resolution feature extraction module that fuses local fine-grained features with global context to overcome input resolution constraints, and (ii) an attention refinement mechanism that injects spatial and color biases from intermediate layers into the final self-attention block to accurately restore object boundaries. A set of experiments on six public datasets demonstrates that MARS-CLIP significantly outperforms state-of-the-art methods.

## 2. 论文提出的方法论

- **总体思路**：MARS-CLIP 以 CLIP ViT 编码器为基础，通过两条互补的改进路径——**多分辨率特征融合**与**结构感知注意力精炼**——获得高分辨率、边界校准的图像特征，再与文本特征计算余弦相似度生成分割图。
- **（一）多分辨率特征提取**
  - 输入图像先经反射填充，划分成 N×M 个局部区域（crop size 选 112×112）。
  - 每个局部区域被缩放到编码器要求的 K×K 尺寸后分别送入 CLIP 图像编码器，提取细粒度的局部特征；按原空间位置拼接形成高分辨率特征图 \(F_{local}\)。
  - 同时将整幅图像缩放后送入编码器，得到保留全局上下文的 \(F_{global}\)。
  - 二者通过加权融合：
    \[
    F_{refined} = \alpha \cdot Up(F_{global}) + (1-\alpha) \cdot F_{local}
    \]
    其中 α 设为 0.8，`Up` 为双线性上采样。
- **（二）结构感知注意力精炼**
  - 采用 SCLIP 提出的 \(KK^\top\) 相似度替代标准 \(QK^\top\) 注意力作为基础注意力计算。
  - 在最终层注意力中加入 **双重重偏置**：
    - **内部空间偏置 \(B_{int}\)**：来源于中间层（第 8 层）的注意力图，该类注意力图保留更多输入图像的空间布局。
    - **外部颜色偏置 \(B_{color}\)**：将图像从 sRGB 转换至 CIELAB 色彩空间，对像素/ patch 计算高斯核颜色相似度，以捕捉锐利物体边界：
      \[
      B_{color}(i,j)=\exp\left(-\frac{\|c_i-c_j\|_2^2}{2\sigma^2}\right),\quad \sigma=30.0
      \]
  - 最终注意力为：
    \[
    A_{final} = Softmax\left(\frac{K_{final}K_{final}^\top}{\sqrt{d}} + B_{total}\right)
    \]
    再与最终的 Value 相乘并经过线性层得到精炼输出。
  - 借鉴 ClearCLIP 的发现，移除最终 Transformer 块中的残差连接和前馈网络，以减少噪声干扰，强化精炼注意力的效果。
- **（三）零样本分割推理**
  - 文本端：以目标类别名套入 80 个 ImageNet 风格模板，经 CLIP 文本编码器取平均得到文本特征。
  - 图像端：将精炼特征图逐像素与各类别文本特征计算余弦相似度，取最大值作为预测类别，上采样至原始尺寸。
  - 可选的 PAMR（Pixel Adaptive Mask Refinement）作为后处理，并设背景类阈值为 0.1。

## 6. 论文的主要结论与发现

- MARS-CLIP 在 **全部 8 种数据集设置、两种后处理条件下**均取得了优于现有 SOTA 的 mIoU。
  - 无 PAMR 时：V21 达到 62.0%，City 达到 38.2%（较 NACLIP 高 2.7 个百分点），C-Obj 34.5%，PC60 33.8%，ADE 18.5%，C-Stf 24.4%。
  - 使用 PAMR 时：V21 达 65.8%，City 达 40.1%（较 NACLIP 高 1.8 个百分点），PC60 35.9%，PC59 39.2%，C-Obj 36.7%，ADE 19.8%，C-Stf 26.1%。
- 在包含高分辨率图像和细粒度物体的数据集（如 Cityscapes、ADE20K）上提升最大，说明多分辨率特征提取有效弥补了固定输入分辨率对细节的损失。
- 注意力精炼（尤其颜色偏置）对边界恢复贡献明显；组件消融表明 Multi 和 Bias 是互补的，同时使用增益最大。
- 推理开销几乎不增加（峰值内存相同、单图推迟约 0.0013 s），证明方法在实用性上具有吸引力。

## 7. 优点

- **不依赖外部模型**：相比 ProxyCLIP、FreeDA 等方法（需额外运行 DINO、Stable Diffusion），MARS-CLIP 只利用 CLIP 内部结构和输入图像本身的信息，维持了计算效率和部署简洁性。
- **双路径互补设计**：从“提升分辨率 → 补足细节”和“恢复边界 → 修正结构”两方面分别解决 CLIP 的两个固有缺陷，逻辑清晰且消融验证有效。
- **结合 low-level 视觉先验**：将 CIELAB 颜色空间中的感知距离引入注意力偏置，是一种轻量但效果显著的空间边界增强方式。
- **训练自由（Training-free）**：无需标注数据、不更新任何权重，可直接作用于预训练 CLIP，便于作为通用即插即用模块嵌入其他零样本分割流程。

## 8. 不足与局限

- **光照与对比度敏感**：论文自述颜色偏置依赖颜色距离，在低光照、低对比度或色彩相近区域（如夜间场景、灰度图像）中边界恢复效果可能退化，内部空间偏置仅能部分缓解，未系统验证该场景下的鲁棒性。
- **单个骨干网络验证**：只在 ViT-B/16 上实验，缺少对较大/不同 CLIP 变体的扩展结论，无法判断方法收益是否随模型规模缩放。
- **多分辨率计算代价描述有限**：文中未披露完整的端到端时间与显存统计，只报告单图单设置下的指标；crop 方式可能在高分辨率业务场景中带来明显延迟，缺少与外部模型类方法的 scale 对比。
