## 摘要
我们提出ENEAS，一种统一的、文本可提示的实例跟踪与语义发现方法。文本可提示的分割模型，包括最新的基础模型如SAM 3，仍然存在时间幻觉、空间碎片化和语义误分类问题：当目标离开视野时未能报告其缺失，在极端特写时将局部纹理而非完整对象分割，以及优先考虑视觉特征而非本体论现实，导致类似视觉的人工制品（如雕像、绘画或反射）被分割为目标实体。ENEAS以单一方法实现两种功能：对唯一实例的精确跟踪与高质量分割，以及通过语义验证层解析文本查询命中的每个实例的开放概念发现。对于跟踪，我们将几何上鲁棒的SeC架构（之前仅限于点交互）扩展了文本提示适配器，并利用其时间记忆，使目标在消失时被保持而不漂移到干扰物，并且即使目标填满整个视野也能保持完整。对于发现，验证层结合了高速视觉嵌入匹配与条件VLM细化，仅对模糊候选进行语义推理，这过滤了纯视觉模型无法区分的本体论错误，同时保持低延迟。ENEAS设计时考虑到3D重建，其中单个误分类干扰物会破坏资产，它为视频、广泛的库以及时间或空间无序数据集合解锁了高质量语义跟踪与分割，同时具备区分真实实例与其“替身”（看起来相似但并非同一物体）的能力。代码和模型可在 https://github.com/speridlabs/eneas 获取。

## Abstract
We present ENEAS, a unified, text-promptable method for instance tracking and semantic discovery. Text-promptable segmentation models, including the latest foundation models such as SAM 3, still suffer from temporal hallucinations, spatial fragmentation, and semantic misclassification: they fail to report target absence when an object leaves the field of view, segment local textures instead of the complete object during extreme close-ups, and prioritize visual features over ontological reality, so that visually similar artifacts such as statues, paintings, or reflections are segmented as target entities.   ENEAS works two ways from a single method: precise tracking and high-quality segmentation of a unique instance, and open-concept discovery of every instance a text query names, resolved by a semantic verification layer. For tracking, we extend the geometrically robust SeC architecture, previously limited to point interactions, with a text-prompting adapter and leverage its temporal memory, so that the target is held through disappearance without drifting to distractors and kept whole even when it fills the entire view. For discovery, the verification layer combines high-speed visual embedding matching with conditional VLM refinement, invoking semantic reasoning only for ambiguous candidates, which filters out the ontological errors that visual-only models cannot distinguish while keeping latency low. Designed with 3D reconstruction in mind, where a single misclassified distractor corrupts the asset, ENEAS unlocks high-quality semantic tracking and segmentation of video, of broad libraries, and of collections of temporally or spatially unordered data, together with the discrimination to tell true instances from their doppelgangers: things that look alike but are not the same. The code and models are available at https://github.com/speridlabs/eneas

## 1. 论文的核心问题与整体含义

**研究动机与背景**  
- 文本引导分割（text-guided segmentation）已发展为现代视觉理解的基础能力，用户给出自然语言提示后，模型需要返回像素级掩码，并可用于**实例跟踪**（视频中跟随特定对象）或**语义发现**（发现场景中某概念的所有实例）。
- 以 SAM 3 为代表的基础模型虽强大，但在非结构化视频中仍存在三类系统性失败：
  1. **时间幻觉**：目标离开视野或严重遮挡时，模型不报告目标缺失，而会对类似物体（如窗帘、头发）产生虚假检测；
  2. **空间碎片化**：极端特写下只分割局部细节（如笔触、人物局部），而非完整对象；
  3. **语义/本体误判**：视觉相似的雕像、绘画、反射等被分割为目标实体，模型只响应视觉外观而忽视本体论本质。
- 论文将这些失败归因于**强感知 + 弱验证**（strong perception coupled with weak verification）这一共因，其实际触发场景是三维重建：在无序、部分遮挡的采集视图上，必须精确隔离目标对象、剔除游客等干扰物。而现有方法（如 SAM 3）往往返回多幅绘画或把雕像分割成人，无法直接使用。

**核心论点**  
- 需要将**几何提案（geometric proposal）与语义验证（semantic verification）解耦**，不仅“定位形状”，还必须“验证本质”，从而在跟踪中维持身份（identity）、在语义发现中实现本体论正确（ontological correctness）。

## 2. 论文提出的方法论

**总体架构**：ENEAS 是一个统一方法，输入自然语言提示 p 和帧集合 {Iₜ}（可为有序视频或无序图像集），输出二值掩码。它由两个模式共享相同的底层组件（Florence-2 作区域提案，SAM 2 作掩码生成）：
- **实例跟踪模式**（prompt 指向特定实例）：单掩码跟踪 + 报告消失；
- **语义发现模式**（prompt 命名类别）：逐帧检测每个实例并对模糊候选做语义验证。

**共享组件**：  
- 区域提案算子 G(I, p)：用 Florence-2-Large 生成候选框；  
- 分割算子 S(I, r)：用 SAM 2 将区域转为掩码。

---

### 2.1 实例跟踪
- 以 SeC（[85]）为基础，该架构为 SAM 2 增加目标的概念级记忆，通过大视觉语言模型渐进构造目标的高层表示，在场景变化时将概念注入掩码解码器，从而鲁棒应对视角剧变和目标消失/重现。
- SeC 原生仅支持点交互，ENEAS 为其增加**文本驱动初始化**：在参考帧上，G(Iₜ₀, p) 得到区域 r₀，然后用 r₀ 初始化跟踪器；后续掩码由 SeC 的时间记忆 T 传播得到：
  \[
  M_t = T(I_t \mid r_0, H_t)
  \]
- 该机制保证目标不可见时输出空掩码（true negative），不漂移到相似干扰物；在极端特写下保持完整掩码而非碎片化。

### 2.2 语义发现
采用级联式成本递增管线，每阶段仅处理前一阶段无法判定的候选（见下图流程）：

1. **区域提案**（低成本、高召回、允许误报）：Florence-2 对每帧生成候选区域 Rₜ = G(Iₜ, p)，并合并重复框。
2. **嵌入验证**（中速视觉过滤）：  
   - 使用 SigLIP 2（sigmoid 配对损失，避免 softmax 互相抑制、保证每个图‑文对独立评分）逐候选计算与类别文本的相似度；  
   - 采用**提示集成**（prompt ensemble），平均多组类别措辞的嵌入分数，缓解“整图训练 → 局部裁剪推理”的域偏移；  
   - 设两个阈值 τ_rej < τ_acc，将候选分成三组：
     - s(r) ≥ τ_acc → 直接接受；
     - s(r) < τ_rej → 直接丢弃；
     - τ_rej ≤ s(r) < τ_acc → 进入不确定性区间，交给下一阶段。
3. **语义验证**（按需 VLM 仲裁）：仅对不确定性区间内的候选调用 Qwen3-VL 小模型，让其返回二元判定 v(r) ∈ {0,1}，回答“该区域是否真的是目标类别，而非雕像、模型、照片等相似物”。为保证判定独立性，**将邻域候选像素黑化遮蔽**；并采用固定格式输出，**禁止自由推理 token**，降低单次成本。
4. **掩码生成**：对接受集合 Aₜ（直接接受 + v(r)=1）用 SAM 2 生成每实例掩码 Mₜ⁽ⁱ⁾ = S(Iₜ, rᵢ)。

> 四种设计演进说明（对应消融）：  
> 1. 密集目标描述 + 文本过滤 + 复合视觉 prompt 会因 open-set 幻觉、空间聚合、认知负荷过高而失败；  
> 2. softmax 式对比过滤存在 **softmax 瓶颈**——目标与其他高显著性对象共现时分数被抑制，无法设置稳定阈值；  
> 3. 改用 **sigmoid 式独立评分** + 原生宽高比编码器 + 提示集成，解决分数抑制；  
> 4. VLM 法官需**只在不确定性区间启用**，使用黑化裁剪与结构化提示（不使用深层推理 tokens），兼顾精度与延迟。

## 6. 论文的主要结论与发现
- **级联验证是填补“强感知、弱验证”的关键**：仅靠视觉 embedding 过滤，无论阈值松紧都无法同时达到高 precision 和高 recall；只有在不确定性区间内启用 VLM 才能打破此权衡。
- **选择性咨询 VLM 优于全程启用 VLM**：VLM-Only（区间 0.00–1.00）不仅更慢（5.05 s/帧），且 F1 反而下降（79.1% vs 82.8%），说明对小模型（2B）而言，对清晰样本的“过度推理”会引入随机误差。
- **记忆型跟踪有效解决身份保持**：在目标消失/遮挡时不漂移，在特写时保持空间完整性；文本适配 SeC 能直接支持自然语言初始化。
- **sam 3 是强检测器但语义过滤极弱**：Church Statues 中 F1 仅 19.5%、precision 仅 11.1%（每个正确框伴随约 8 个误报），ENEAS 以召回换精度，F1 提升到 82.8%~87.6%。
- **系统可扩展**：更大 VLM（4B）能恢复更多有效实例，提供离线的最高精度配置；阈值可调可使系统在简单场景以近实时速度运行，实现“成本随场景歧义度自适应”。
- **本体论鲁棒性需要显式推理层**：视觉基础模型倾向于用“像不像”作答，ENEAS 的 VLM 仲裁看到全局上下文和材质特性（扁平画布、石材颗粒）后，能区分“看起来是”与“实际上是”。

- **评测视角新颖**：自建 Church Statues 恰当地暴露了现有模型在“雕像 vs 人”场景上的灾难性失败，并以 precision/recall 清晰量化为 F1 的四倍提升。

## 8. 不足与局限
- **召回上限受区域提案限制**：Florence-2 从未提出的实例（小、远、重度遮挡）无法被后续阶段补救，系统 recall 天然有天花板（文中的 False Negative 在各配置下保持一致）。
- **VLM 对上下文敏感**：极端特写（裁剪内毫无场景线索）和微小/低分辨率裁剪上，VLM 仍可能像视觉模型一样接受伪造品。
- **密集场景成本失控**：验证成本随候选数增长，拥挤街道等场景超出方法设计范围。
- **无时间身份关联**：语义发现模式是逐帧独立进行的，不给跨帧实例分配持久身份。
- **不输出置信度分数**：限制了基于分数阈值的评测协议应用。
- **尚未达到实时**：Robust 配置在单个 L4 上约 3~5 秒/帧（2B/4B）。
- **基准话语均较窄**：未在 DAVIS/YouTube-VOS/MOSE/COCO/LVIS 等通用公开基准上做系统化对比；自制数据未公开细节（未描述标注协议、帧数、内部分布），论文通用性证据有限。
- **实验不对称**：论文重点分析语义发现并承认是刻意为之，跟踪部分主要依赖于少样本定性展示而非大规模定量跟踪实验（SA‑V 上虽然报告了 HOTA 但数值较小，可能因短时或稀疏标注设计）。
- **作者身份/机构信息不足以验证双盲性**：该 preprint 来自 “SperidLabs”，未详细给出机构背景，结果可复现性依赖其公开 repo 的质量。
