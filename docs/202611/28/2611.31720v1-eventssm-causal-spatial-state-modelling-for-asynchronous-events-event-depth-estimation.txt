Abstract
Event cameras report asynchronous brightness changes,
yet metric-depth supervision is typically available only at
sparsely sampled reference timestamps. Aggregating events
into frame-like representations simplifies learning but can
obscure the fine-grained temporal structure of the original
event stream. We introduce EventSSM, a causal spatial-
state framework for event-associated metric-depth estima-
tion using a recurrent memory updated by chronological
event packets.
To bridge asynchronous predictions and
frame-time supervision, predicted event depths are geomet-
rically transported using calibrated camera poses and dif-
ferentiably rendered at reference timestamps. Benchmark
evaluations demonstrate improvements over established
event-depth methods across multiple depth-error measures.
Controlled ablations further examine cross-modal initial-
ization, temporal recurrence, individual state, readout and
supervision components, and packet subdivision. Together,
these findings establish EventSSM as an effective frame-
work for causal event-associated metric-depth estimation,
combining persistent spatial context with physically timed
state retention.
1. Introduction
Event cameras report changes in logarithmic brightness as
asynchronous, polarity-labelled events rather than periodi-
cally acquired intensity frames [5, 14, 20]. Their fine tem-
poral resolution and high dynamic range have supported
high-speed optical flow, camera tracking, and geometric re-
construction [1, 18, 22]. However, an event specifies nei-
ther scene depth nor an image-wide geometric measure-
ment: event activity depends on motion, local contrast, and
sensor characteristics [4, 17]. Repeated observations may
concentrate along moving texture boundaries while nearby
surfaces produce few events. Estimating depth therefore re-
quires spatial context that persists across irregularly timed
measurements.
A widely adopted strategy converts event streams into
count images, time surfaces, or voxel grids before ap-
plying a dense predictor [6, 8].
This has enabled re-
current monocular depth networks such as E2Depth and
recurrent-transformer estimators, as well as event–frame
fusion [7, 12, 15]. More recent depth estimators exploit
adverse-condition modelling or spatial knowledge trans-
ferred from image networks [2, 26, 35]. These approaches
provide important dense-depth baselines, but the acquisition
window or temporal binning of an intermediate representa-

tion constrains when its prediction can be formed. For a
model that attaches depth to the original event locations, a
complementary design is to retain a spatial state between
packets and query it using each event’s coordinates, polar-
ity, and age.
A second challenge concerns supervision. Event times-
tamps are much finer than the depth and pose annotations
available in datasets such as MVSEC [32]; geometric recon-
struction and continuous-time event-camera odometry both
demonstrate the importance of accounting for camera mo-
tion between observations [18, 23]. Assigning a reference-
frame depth directly to an event at another time ignores the
change in viewpoint, although over short MVSEC intervals
this has little effect on accuracy (Sec. 4.5). We instead as-
sociate predictions with packet-time events, transport them
through calibrated, interpolated camera poses, and render
depth at the reference timestamp. This uses frame-time la-
bels for learning and evaluation without forcing the predic-
tion domain to become frame-synchronous.
We introduce EventSSM, an event-based encoder archi-
tecture that pairs a motion-transported spatial state with a
local event-conditioned depth readout. Chronological pack-
ets produce polarity-separated observations that update a
single spatial memory through learned backward transport,
physical-time decay, and support-gated injection. A feed-
forward multiscale pyramid supplies each event query with
20 spatial descriptors sampled from a fixed local neighbor-
hood across four feature scales. Attending to these descrip-
tors enables localized depth inference from the accumulated
spatiotemporal context without pairwise attention across the
event stream. The recurrence is causal at packet boundaries:
it can use later events within the current packet, but not ob-
servations from subsequent packets. State-space sequence
modelling motivates the persistent-state perspective [9, 10],
while image-trained representations offer spatial initializa-
tion during training only [28].
Our contributions are: (i) a physically timed spatial-
state transition that couples learned feature transport with
observation-dependent updates; (ii) a multiscale, constant-
neighborhood attention readout producing bounded met-
ric depth at individual event coordinates; and (iii) a cal-
ibrated target-time renderer that places event-time depth
predictions in the annotated reference view for supervision
and matched evaluation. We evaluate these components on
matched MVSEC outdoor windows through depth compar-
isons and controlled initialization, recurrence, component
and packet-subdivision studies.
2. Related Work
Event representations and temporal context.
Count
images, time surfaces, and event voxels expose asyn-
chronous measurements to conventional convolutional net-
works; learned event encodings can optimise this conver-
sion for downstream tasks [5, 6]. Image reconstruction pro-
vides another interface to frame-based vision [24], whereas
point- and graph-based processing preserves irregular event
support more explicitly [25]. Recurrent event transformers
extend temporal context across discretised inputs [8, 15].
These methods motivate different trade-offs between spatial
completeness, event timing, and the cost of irregular com-
putation. EventSSM retains packet chronology in a persis-
tent image-plane state but assigns its final depth estimates
to events rather than to every image pixel.
Depth estimation from events.
Classical event-based ge-
ometry exploits calibrated stereo or motion-induced multi-
view consistency [23, 29], while event-only monocular
depth learning commonly produces dense maps at des-
ignated times [12, 15].
RAMNet combines event and
frame observations in a recurrent depth architecture [7];
other methods target adverse night-time conditions, oc-
clusion handling, or dense-to-sparse transfer [26, 31, 35].
Depth AnyEvent investigates transferring visual knowledge
to event-depth models [2], and ScaleEvent extends event-
stream pretraining with visual foundation-model represen-
tations [3]. We compare against the corresponding event-
depth baselines under matched reference-time evaluation.
Our distinction lies primarily in the output domain: the
model predicts event-associated metric depth and renders
those samples into a reference image for comparison, rather
than treating a dense frame as its native depth prediction.
Continuous-time geometry and supervision.
Motion
compensation and contrast maximisation exploit the times-
tamp structure of events in flow and motion estima-
tion [4, 27].
Event-based multi-view reconstruction and
continuous-time visual-inertial odometry further demon-
strate that camera geometry must be evaluated at the ap-
propriate observation time [18, 23].
Event-based self-
supervised approaches obtain learning signals through mo-
tion or cross-modal consistency [11, 33, 34]. Our training
setting is different: metric reference depth and annotated
camera poses are available. We use those poses to project
event-associated 3D samples into the labelled viewpoint,
addressing the temporal mismatch between irregular predic-
tions and sparse metric supervision.
State-space models and spatial context.
Structured and
selective state-space models show how long-range sequen-
tial context can be maintained without all-pairs token atten-
tion [9, 10]. Visual adaptations, including Vision Mamba,
VMamba and LocalMamba, investigate spatial scans and
locality for image features [13, 16, 36]. These are related
motivations rather than interchangeable implementations:
EventSSM does not use a global Mamba scan. It main-
tains a full-resolution spatial tensor whose transition explic-

itly depends on elapsed physical time, learned image-plane
transport and local event support. Its four-scale pyramid is
constructed for readout and does not form an independently
recurrent hierarchy.
Cross-modal spatial priors.
Image-based depth models
demonstrate the value of broad visual representations for
monocular geometry [19, 21, 30]. Distillation into event-
depth estimators offers one route to exploiting such priors
without requiring RGB frames during deployment [2, 35].
Our initialization instead aligns intermediate event-state
features with a frozen DINOv3 image encoder [28]. The
teacher participates only during representation initializa-
tion; the trained depth head and inference pipeline consume
events and recurrent memory.

3.6. Cross-modal encoder initialization
Prior event-depth distillation studies exploit pretrained im-
age representations to supply spatial cues where events are
sparse [2, 35]. We use a frozen DINOv3 ViT-S/16 teacher to
supply features from layers 2, 5, 8, and 11 at synchronized
training images [28]. Student spatial features are pooled to
a 30 × 40 grid and projected to the teacher-token dimen-
sion. SmoothL1 feature regression, cosine alignment, and
spatial-relation matching initialize the student representa-
tion before event-depth training. The teacher is discarded
at inference, and the event encoder and newly initialized
local-attention head are subsequently optimized for target-
time metric-depth supervision.

4.4. Packet-count sensitivity
Figure 4 tests whether the representation remains effective
as the same annotated event interval is divided into differ-
ent numbers of causal packets. The common Day 1 valida-
tion population and scoring intersection make the accuracy
trends directly comparable within this ablation. With the
original K = 6 weights retained, relative error changes lit-
tle around the three- to six-packet settings, indicating that
the learned memory tolerates moderate changes in update
frequency. Independently trained packet-specific configura-
tions improve MAE but not AbsRel uniformly, and increas-
ing K does not produce monotonic accuracy gains. Thus,
finer temporal subdivision is an operational design choice
rather than a guarantee of better reference-time error.
We retain K = 6 as a practical balance between tempo-
ral responsiveness and repeated state-update cost. Dividing
an approximately 50 ms annotated interval into six chrono-
logical packets permits an event-associated depth readout
after roughly 8.3 ms of observations, instead of waiting for
the next annotated endpoint. The packetisation is used dur-
ing supervised training to expose causal intermediate states;
a deployed model can continue updating its memory as
new packets arrive without requiring a ground-truth-aligned
window. These findings concern accuracy on the shared

5. Conclusion
We introduced EventSSM, a causal spatial-state framework
that combines persistent motion-transported memory with
local event-conditioned metric-depth prediction.
Target-
time rendering relates event-time predictions to sparse ref-
erence annotations for supervision and evaluation without
restricting predictions to frame timestamps.
Across the
MVSEC outdoor comparisons, EventSSM consistently im-
proves the principal relative and metric depth errors, with
particularly strong squared-relative and wider-range accu-
racy. Ablations establish the benefits of cross-modal spatial
initialization, the exponential retention parametization and
the efficiency of the recurrent update, while packet-count
experiments clarify the choice of temporal resolution. The
resulting compact model supports depth readouts at succes-
sive short packet boundaries, advancing event-native geo-
metric perception through a combination of accuracy, spa-
tial context and fine-grained temporal responsiveness.

B.3. Baselines (Sec. 4.2, Table 1)
E2Depth [12] uses the released model trained on DENSE
and MVSEC, DepthAnyEvent-R [2] the released recurrent
model fine-tuned on MVSEC, and ScaleEvent [3] the re-
leased MVSEC depth model with a ViT-S encoder, run at
a 640 × 480 input. No trained EReFormer [15] model is
released, so it is trained on outdoor day2 with its un-
modified official code. Every baseline receives all natural
events of the same interval in its own input representation
and predicts one depth map at the reference time, and re-
current baselines start each interval from a reset state, as
EventSSM does.
