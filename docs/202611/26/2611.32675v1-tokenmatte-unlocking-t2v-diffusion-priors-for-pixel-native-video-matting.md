## 摘要
高分辨率视频抠像需要准确恢复连续的 alpha 值，包括细发丝、软边界和运动模糊，然而稠密 alpha 监督仍然稀缺。预训练的文本到视频扩散 Transformer（DiT）提供了丰富的时空先验，而现有的生成式视频抠像方法通常让 alpha 预测经过基于 RGB 训练的 VAE 潜变量，这可能削弱细节并引入额外的解码开销。我们提出 TokenMatte，将预训练视频 DiT 适配为单次前向、无需辅助输入的 RGB 到 alpha 预测器，并具有像素原生输出接口。其核心是一个单一共享线性读出层，将每个时空 token 直接映射到其对应的 t × p × p alpha 像素块，在同一局部视频块内预测空间细节和时间变化。将这些块平铺即可生成全分辨率 alpha 序列，无需卷积解码器或学习式上采样。预测的 alpha 直接在像素空间接受监督，而真值 alpha 从不进入 VAE，从而消除了目标侧 alpha 编码和输出侧 VAE 解码。借助预训练视频先验，TokenMatte 仅使用现有公开抠像数据集训练，无需额外数据整理，推理时也无需辅助输入。与匹配的潜变量输出基线相比，我们的像素原生接口在提高抠像精度的同时实现了 1.51× 推理加速。TokenMatte 在 VideoMatte、YouTubeMatte 和 V-HIM60 上建立了新的无需辅助输入的最先进水平。

## Abstract
High-resolution video matting requires accurate recovery of continuous alpha values, including fine hair, soft boundaries, and motion blur, yet dense alpha supervision remains scarce. Pretrained text-to-video diffusion transformers (DiTs) offer rich spatio-temporal priors, whereas existing generative video matting approaches typically route alpha predictions through RGB-trained VAE latents, which can attenuate fine details and introduce additional decoding overhead. We present TokenMatte, which adapts a pretrained video DiT into a single-pass, auxiliary-free RGB-to-alpha predictor with a pixel-native output interface. At its core is a single shared linear readout that maps each spatio-temporal token directly to its corresponding ($t \times p \times p$) block of alpha pixels, predicting spatial details and temporal variations within the same local video block. Tiling these blocks produces the full-resolution alpha sequence without a convolutional decoder or learned upsampling. The predicted alpha is supervised directly in pixel space, while the ground-truth alpha never enters the VAE, eliminating target-side alpha encoding and output-side VAE decoding. Leveraging the pretrained video prior, TokenMatte is trained using only existing public matting datasets, without additional data curation or auxiliary inputs at inference. Compared with a matched latent-output baseline, our pixel-native interface improves matting accuracy while achieving a 1.51$\times$ inference speedup. TokenMatte establishes a new auxiliary-free state of the art on VideoMatte, YouTubeMatte, and V-HIM60.

## 1. 核心问题与研究背景

- **任务设定**：高分辨率视频抠像（video matting）需从 RGB 视频恢复逐帧连续 alpha，涵盖细发丝、软边界、半透明区域、运动模糊与前景语义，且要求时序连贯。
- **最具部署价值的场景是 auxiliary-free**：推理时只给 RGB 视频，不提供 trimap、mask、点提示或首帧标注。这是最方便也最困难的设定。
- **核心瓶颈是监督稀缺**：alpha 是连续像素量，标注成本远高于分割 mask；公开视频抠像监督多为绿幕拍摄、合成、伪标签、短片或规模有限（VideoMatte240K、P3M-10K、V-HIM2K5 等）。
- **两条既有路线**：
  - 数据规模化：GVM 自建 SynHairMan 并伪标注真实视频；VideoMaMa 构建 50K 伪标签 MA-V；MatAnyone2 整理 28K clips 的 VM-Real。
  - 利用生成先验：但现有生成式视频抠像（GVM、VideoMaMa）把 GT alpha 编码进 **RGB 训练的 VAE 潜空间**再监督，造成两类问题：
    - **质量瓶颈**：VAE round-trip 本身即损失细节，GT alpha 经 VAE 往返后在 VideoMatte / V-HIM60 / YouTubeMatte 上已有 MAD 3.50 / 1.22 / 0.54 的重建误差，构成精度上限。
    - **速度瓶颈**：推理需高分辨率 VAE 解码，单 clip 延迟 576 ms。
- **整体含义**：论文主张不必扩大任务数据或引入辅助输入，而应把预训练视频 DiT 视为“时空表征提供者”，把 alpha 预测重构成对已有 token 的**像素级读出**任务，从而绕开 VAE 对 alpha 的编解码。

## 2. 方法论

### 2.1 核心思想
- 将预训练 T2V 视频 DiT 适配为**单次前向、确定性、RGB→alpha** 的预测器；alpha 目标**从不进入 VAE**，直接在像素空间监督。
- 利用 DiT 固定的 patch 对齐 token 网格：每个时空 token 天然对应一个局部时空块，读出即“反转”这一对应关系，把通道语义从 RGB latent 换成该块的 opacity。

### 2.2 关键技术流程（文字版公式说明）
1. **RGB 视频翻译（Sec. 3.1）**
   - RGB 视频 $x \in \mathbb{R}^{T\times3\times H\times W}$ 经**冻结的** VAE 编码器 $E$ 得到 latent，保持预训练 RGB 输入接口不变。
   - 将随机生成式 DiT 塌缩为一次确定性前向：固定时间步 $\tau=\tau_0$、不注入噪声 $\epsilon=0$，得到 token 场
     $Z = F_\theta(E(x);\,\tau=\tau_0,\,\epsilon=0)$。
   - 此时 $F_\theta$ 不再去噪，而是把编码后的 RGB 场确定性变换为任务适配的 token 场；全 DiT 骨干参与微调。
2. **像素读出（Sec. 3.2）**
   - 每个 token $z_{ijk}$ 对应固定输出区域 $\Omega_{ijk}$。
   - 用**单一共享线性投影**将 token 映射为其 alpha 像素块：
     $\hat{A}_{ijk} = \mathrm{reshape}(W z_{ijk}+b)$，其中 $\hat{A}_{ijk}\in\mathbb{R}^{t\times p\times p\times1}$。
   - 对所有 $\{\Omega_{ijk}\}$ 平铺即得全分辨率 alpha 序列 $\hat{\alpha}$。
   - 该读出**无卷积、无学习式上采样、无 token 间混合、无循环/记忆库**，且与序列长度无关。
3. **像素空间监督（Sec. 3.3）**
   - 损失仅为像素空间 $\ell_1$：$\mathcal{L}=\|\hat{\alpha}-\alpha\|_1$。
   - 无 alpha VAE 编码、无 latent flow-matching/去噪目标、无 VAE 解码。

### 2.3 设计取舍说明
- 作者刻意选择最简 token-local 读出，以验证“高质量生成解码器并非像素级 alpha 读出的必要条件”；实验表明更强局部解码器无稳定收益。

- **“最简读出”具有设计启示**：共享线性投影即可接近浅层卷积解码器，说明关键在于 token 与像素块的固定对齐及预训练表征质量，而非复杂解码器。这为其他密集预测任务（matting、分割、深度、法线）提供了轻量任务适配思路。
- **预训练先验与数据规模的互补关系清晰**：Random Init 严重退化表明公开 alpha 数据主要起“校准 token→alpha 翻译”的作用；这支持“强预训练 + 中等规模任务数据 + 简单接口”的路线。
- **效率与精度可同时获得**：Pixel 接口相对 Latent 接口在 MAD、Grad、dtSSD 上全面更优，同时延迟从 576 ms 降至 382 ms，说明避免 VAE 解码不是以精度换速度，而是同时改善两者。
- **对 auxiliary-free 设定的坚持具有部署意义**：不依赖 trimap、mask、点提示或首帧标注，使方法更接近真实视频编辑、直播抠像、后期合成等场景的输入条件。

## 9. 总体评价

TokenMatte 是一篇问题诊断清晰、方法极简、因果验证充分的工作。其核心贡献不在于复杂网络设计，而在于重新定义预训练视频 DiT 与 alpha 预测之间的接口：冻结 VAE 编码器、塌缩为确定性单次前向、用共享线性读出把时空 token 映射为 alpha 像素块，并在像素空间直接监督。受控消融有力支持了“像素原生接口优于潜空间接口”“预训练先验关键”“最小读出已足够”“全量微调泛化更好”等结论。三个 auxiliary-free benchmark 上达到新 SOTA，并在 YouTubeMatte 上甚至优于 mask-guided VideoMaMa，同时取得 1.51× 推理加速。

其主要不足在于开放场景泛化仍以定性为主、长视频与资源边界未充分量化、统计严谨性和与引导式方法的同条件比较有限。但这些问题不削弱其核心论点：对于像素级 alpha 读出，高质量生成解码器并非必要条件；预训练视频 DiT 的时空 token 本身已携带足够表征，关键在于设计正确的任务读出接口。总体而言，该工作对视频抠像及更广泛的密集预测任务适配具有较强启发意义。
