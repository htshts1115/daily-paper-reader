## 摘要
现有的基于聚焦的深度（depth-from-focus）方法在聚焦线索较弱、新相机或聚焦切片较少时可能表现不佳。我们提出 FocusAnchor，一种循环模型，利用聚焦体查找（focus-volume lookups）来细化度量深度，并反复将来自冻结基础模型的相对深度先验与当前深度估计对齐。对齐后的先验在反馈回路中指导后续细化，将从纹理丰富区域恢复的度量尺度传递到聚焦线索较弱的区域，同时保持场景结构。为支持跨相机迁移，我们合成了具有随机相机参数和聚焦距离的训练堆栈。然而，堆栈合成会在不同切片上以不同方式模糊现有图像噪声，即使在没有纹理的表面上也会产生人工深度线索。我们添加独立的逐切片噪声以抑制这些线索。我们还引入可变堆栈训练，以在聚焦切片较少时提高鲁棒性，并支持更实用的移动端拍摄。与 FOSSA ViT-B 相比，经过微调后，FocusAnchor 在 NYU Depth V2 上将 AbsRel 降低 36%，在 DDFF-12 上降低 9%。在零样本评估中，FocusAnchor 及其可变堆栈变体 FocusAnchor-flex 在所有五个基准上取得了最低的两个 AbsRel 值。在 ZEDD 测试集上，FocusAnchor 的 AbsRel 比最佳对比方法 FOSSA ViT-B 低 9%；而在 ZEDD 验证集上，FocusAnchor-flex 在使用少 40% 的聚焦切片的情况下取得了更低的 AbsRel。

## Abstract
Existing depth-from-focus methods can struggle with weak focus cues, new cameras, or fewer focal slices. We present FocusAnchor, a recurrent model that uses focus-volume lookups to refine metric depth and repeatedly aligns a relative depth prior from a frozen foundation model to the current depth estimate. The aligned prior guides subsequent refinement in a feedback loop, carrying metric scale recovered from textured regions into regions where focus cues are weak while preserving scene structure. To support transfer across cameras, we synthesize training stacks with randomized camera parameters and focus distances. However, stack synthesis blurs existing image noise differently across slices, creating artificial depth cues even on textureless surfaces. We add independent per-slice noise to suppress these cues. We also introduce variable-stack training to improve robustness with fewer focal slices and support more practical mobile capture. Compared with FOSSA ViT-B, FocusAnchor reduces AbsRel by 36% on NYU Depth V2 and by 9% on DDFF-12 after fine-tuning. In zero-shot evaluation, FocusAnchor and its variable-stack variant, FocusAnchor-flex, achieve the two lowest AbsRel values on all five benchmarks. On ZEDD test, FocusAnchor achieves 9% lower AbsRel than the best competing method, FOSSA ViT-B, while FocusAnchor-flex achieves lower AbsRel with 40% fewer focal slices on ZEDD validation.

  - 任务特定训练数据需求大（如 FOSSA 使用 373k 合成图像渲染焦栈），跨相机泛化难；
  - 焦切片数减少时精度显著下降，而移动端采集代价高（iPhone 上约 0.58 s/切片、5 切片约 2.9 s），长采集窗口还会引入手持视角漂移。
- **整体含义**：论文主张将“冻结的深度基础先验”反复**锚定**到“已知距离的对焦线索”上，用对焦线索提供度量尺度、用先验提供结构，从而在跨相机、少切片的零样本场景下取得更稳健的度量深度。

## 2. 方法论

### 2.1 核心思想

- 以**循环反馈回路**同时做两件事：(i) 用聚焦体查找（focus-volume lookup）沿“焦平面坐标”修正深度；(ii) 在每次迭代前把冻结基础模型的相对逆深度**重新对齐**到当前估计，使纹理区恢复出的度量尺度被“搬运”到对焦线索弱的区域。
- 深度以**归一化逆深度** x = d₁/D 表示（d₁ 为最近焦平面距离），度量深度由 D = d₁/x 还原，因此更新量天然以“焦平面”为单位，跨相机、跨对焦计划一致。

### 2.2 网络与流程

- **输入**：N 张焦切片 {Iᵢ} 及已知对焦距离 d₁<…<d_N（米），以及全聚焦图 I_aif（可由切片融合）。
- **聚焦体 C**：共享 CNN 将每张切片编码为 1/4 分辨率 32 通道特征 Fᵢ，按 DFV 方式拼接 [Fᵢ, Fᵢ−Fᵢ₊₁]，经 3 个 3D 卷积沿栈方向得到逐像素逐切片的打分体 C(i,p)，对任意 N 适用；不加 Depth Anything 特征，保证聚焦体与先验解耦。对 C 做 softmax 得到仅用聚焦线索的辅助深度 D_vol 并加以监督。
- **先验 z**：冻结的 Depth Anything V2 Large 从 I_aif 预测相对逆深度 z；其 DPT 头前几层的可训练副本提供多尺度特征，与 I_aif 一起经上下文编码器得到初始隐状态 h₀ 与每轮读取的上下文特征。
- **初始化 x₀**：将 z 最小-最大归一化为 ẑ∈[0,1]，令 x₀ = ρ_N + (1−ρ_N)·ẑ（ρᵢ = d₁/dᵢ），即最近表面落在最近焦平面、最远落在最远焦平面，从而一开始就具备近似度量尺度。
- **平面索引 u = g_ρ(x)**：g_ρ(ρᵢ)=i 的分段线性映射，把“逆深度”换算为“第几个焦平面”，一步 = 一个焦平面，与相机参数无关。
- **尺度阶段（t ≤ 4）**：在 g_ρ(σ·x_{t−1}) 处对 9 个尺度因子 σ∈[0.5,2]（每处 5 个采样）做尺度查找，GRU 预测逐像素尺度 s_t，更新 x_t = s_t·x_{t−1}，用于纠正初始尺度大误差。
- **步进阶段（t > 4）**：在 u_{t−1}+kδ（k∈{−4,…,4}，δ 取 0.5 与 1 两档）处线性插值读取同一聚焦体（不池化，因切片太少），GRU 预测平面索引增量并裁剪：
  - x_t = g_ρ⁻¹( u_{t−1} + clip(Δu_t, −4, 4) )
- **先验对齐（每步进迭代前）**：在 33×33 窗口（1/4 分辨率）内，用上一轮置信度 c_{t−1} 加权做逐像素最小二乘仿射拟合（无梯度）：
  - a_p = max(0, Cov_p[ẑ, x_{t−1}] / max(Var_p[ẑ], ε))
  - b_p = E_p[x_{t−1}] − a_p·E_p[ẑ]
  - 对齐先验 x̃_t = a_p·ẑ + b_p，并裁剪到 [½·min x_{t−1}, 2·max x_{t−1}]；窗口内无置信像素时通过伪计数 κ 回退到全图拟合。
- **置信度**：小头 ψ 由最细隐状态、查找 L_t 及 log x_{t−1} − log x̃_t 预测 c_t（估计落在真值约 5% 内的概率），作为下一轮拟合权重；c_t 在送入 GRU 前被 detach。
- **融合**：步进阶段 GRU 的输入由 x_{t−1} 扩展为 [x_{t−1}, x̃_t, c_t]，使模型在聚焦体平坦处跟随先验、在峰明显处跟随对焦证据。
- **损失**：对所有 T 个估计（凸上采样到全分辨率）、仅聚焦体深度与置信度做加权 L1 对数损失，γ = 0.915/(T−1)，λ_v = 1，λ_c = 0.1；置信度用阈值 0.05 的二值交叉熵监督。
- **训练策略（三项关键设计）**：
  - **随机相机与对焦计划**：80% 训练样本的最近焦平面 d₁~U(0.6,1) m、最远 d_N = r·d₁（r~U(7,15)），并用参数 β 在“逆深度均匀”与“对数深度均匀”间插值；其余 20% 按图像真值深度 5–95 分位均匀布置（避免“焦平面贴着真值范围”的捷径）。
  - **逐切片独立噪声**：合成渲染是对同一张清晰图按不同对焦距离模糊，原图传感器噪声在对焦切片中最清晰，会在无纹理表面制造**伪深度线索**。作者为每张渲染切片独立加入高斯噪声（σ~U(0,0.01)）。实测无纹理像素“最清晰切片=真值最近切片”的比例从 62% 降到 27%（随机为 20%，真实 ZEDD 为 41%）。
  - **可变栈训练**：FocusAnchor-flex 在每批中随机采样 2–5 张切片训练，支持更短的采集。
