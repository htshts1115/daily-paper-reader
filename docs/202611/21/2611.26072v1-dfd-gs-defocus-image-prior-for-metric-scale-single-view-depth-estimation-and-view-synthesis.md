## 摘要
从单视角观测中恢复度量尺度几何本质上仍是病态问题，限制了新视图合成的可靠性。近期方法依赖学习到的单目深度先验，这类先验能提供强结构估计，但可能受尺度模糊和数据集相关偏差影响。我们提出 DfD-GS，一种前馈框架，可从单视图的全聚焦—散焦图像对预测度量尺度的 3D 高斯场景表示。其核心思想是利用散焦模糊作为物理度量深度线索。DfD-GS 首先从全聚焦—散焦图像对及相应散焦强度估计基于散焦的度量视差图。该估计用于将单目深度先验对齐并细化到度量尺度。随后预测可见与隐藏的 3D 高斯，用于遮挡感知的新视图合成。在由 Booster 和 Middlebury 构建的合成散焦数据集上的实验表明，DfD-GS 在度量深度估计和新视图合成方面优于单图像基线。在 WildRGB-D 上，DfD-GS 相比单图像基线取得更低的 AbsRel 和 LPIPS，但深度 RMSE 更高。额外分析表明，DfD-GS 在视场变化下能保持更稳定的度量尺度。真实数据集上的定性结果显示，在光学散焦条件下可恢复主要场景结构。

## Abstract
Recovering metric-scale geometry from observations at a single viewpoint remains fundamentally ill-posed, limiting the reliability of novel view synthesis. Recent methods rely on learned monocular depth priors, which provide strong structural estimates but can suffer from scale ambiguity and dataset-dependent biases. We propose DfD-GS, a feed-forward framework that predicts a metric-scale 3D Gaussian scene representation from a single-view all-in-focus--defocused image pair. The key idea is to exploit defocus blur as a physical metric depth cue. DfD-GS first estimates a defocus-based metric disparity map from the all-in-focus--defocused image pair and the corresponding defocus strength. This estimate is used to align and refine a monocular depth prior to metric scale. Visible and hidden 3D Gaussians are then predicted for occlusion-aware novel view synthesis. Experiments on synthetic-defocus datasets constructed from Booster and Middlebury show that DfD-GS outperforms single-image baselines in metric depth estimation and novel view synthesis. On WildRGB-D, DfD-GS achieves lower AbsRel and LPIPS but higher depth RMSE than the single-image baselines. Additional analyses show that DfD-GS maintains a more stable metric scale under field-of-view changes. Qualitative results on a real dataset show recovery of the main scene structure under optical defocus.

# DfD-GS 论文结构化总结

## 1. 核心问题与研究动机

- **问题定位**：从单视角图像恢复**度量尺度（metric-scale）**的三维几何本质上是病态问题——同一张图像可由多种场景尺度与深度配置解释，这直接限制了单视图新视角合成（NVS）的可靠性。
- **现有路线及其缺陷**：
  - 主流做法依赖**单目度量深度基础模型**（Metric3D v2、Depth Pro、UniDepth、MoGe、Depth Anything 3 等）。它们提供强结构先验、泛化性好，但绝对尺度仍主要由数据驱动先验推断，存在**尺度模糊与数据集相关偏差**；当场景内容、物体尺度或成像条件偏离训练分布时，几何误差会传导到 NVS，造成误投影与结构扭曲。
  - **散焦（defocus）**提供了与度量几何直接挂钩的物理线索（模糊半径与离焦面距离相关），但模糊估计**依赖纹理**，在平坦/饱和区域不可靠。
- **核心动机**：将单目深度先验的**全局结构能力**与散焦模糊的**物理度量线索**结合，形成互补的混合方案，并用统一的 3D 高斯表示同时完成度量深度估计与单视图 NVS。

## 2. 方法论

### 2.1 核心思想
输入为单视角的**全聚焦图像 I、散焦图像 I_def 与散焦强度 k_def**（并假设对焦距离 z_f 已知，采用"最近对焦"假设，即对焦平面置于最近场景深度）。先用散焦线索得到度量视差估计，再用它**全局对齐 + 局部细化**单目深度先验，最后提升为**遮挡感知的 3D 高斯**表示。

### 2.2 三阶段流程

- **阶段一：DA3 单目先验提取**
  - 用冻结的 Depth Anything 3（DA3 Large）提取多尺度特征 F_DA 与深度图；转为视差后线性归一化到 [0,1]，得到归一化视差偏移先验 D_DA（最近点→0，最远点→1）。

- **阶段二：散焦引导的度量深度预测**
  - **物理模型**：定义度量视差 D = 1/Z（单位 m⁻¹），对焦视差 d_f = 1/z_f；最近对焦假设下偏移 ΔD = d_f − D ≥ 0 恒非负；模糊半径建模为 `r(p) = k_def·|D(p) − d_f| = k_def·ΔD(p)`。
  - **散焦强度**由相机参数解析计算：`k_def = f²/(2N)·(i_w/s_w)`（f 焦距、N 光圈数、i_w 图像宽像素、s_w 传感器宽），单位 pixel·m。
  - **散焦条件 U-Net（f_U1）**：输入图像对 {I, I_def} 并以 k_def 为条件，双 sigmoid 分支分别输出偏移 `ΔD_U = Δd_max(1−u)`（Δd_max = 10 m⁻¹）与置信度 C_U；深度监督时对 d_f − ΔD_U 施加平滑正下界（softplus 形式，τ = 0.02）。
  - **全局对齐**：以单一全局尺度 a 做**置信度加权最小二乘** `min_a Σ_p C_U(p)[a·D_DA(p) − ΔD_U(p)]²`，得到 ΔD_align = a·D_DA，并硬裁剪到 [0.01, d_f] 得 D_align。
  - **稠密细化**：第二个 U-Net（f_U2）以 `1−ΔD_align/Δd_max`、`1−ΔD_U/Δd_max`、C_U 为输入预测尺度图 S∈[−1,1]；修正幅度由 ρ = log(q90/q10)（D_align 的 10/90 分位数）限定，最终 `D_ref = clip(D_align·exp(ρS))`，`Z_ref = 1/D_ref`。

- **阶段三：遮挡感知高斯参数预测**
  - 每个源视图像素预测**两个高斯**（可见 + 隐藏），共 2HW 个，用于处理近邻视角的遮挡显露（disocclusion）。
  - 特征融合：RGB 图像 token（64 维）、多尺度 DA3 特征（256 维）、深度 token（64 维）经 MLP 融合为 256 维、解码为 128 通道稠密特征图；可见高斯额外使用源视图局部 RGB 线索。
  - 每个高斯参数化为均值 μ（由 Z_ref 反投影 + 学习的亚像素/深度偏移）、协方差 Σ（各向异性尺度 + 旋转）、不透明度 α、2 阶球谐颜色；用可微 3DGS 渲染器渲染。

### 2.3 损失函数
- 总损失 `L = (1/|V_sup|)Σ_v (L_rgb^v + L_depth^v) + L_defocus`，监督视图含源视图 + T 个目标视图。
- **RGB 损失**：L1 + DSSIM + LPIPS（λ = 0.8 / 0.2 / 0.1）。
- **深度损失**：在按视图 GT 视差 min–max 归一化的视差空间中计算 L1 + DSSIM + 水平/垂直梯度 L1（λ = 0.8 / 0.2 / 1.0）。
- **散焦引导深度损失**：仅作用于源视图 U-Net 预测的**置信度加权 MSE**（λ_defocus = 10.0），低置信像素被降权。

### 2.4 训练数据生成
- 用 Blender 合成 **11,000 个多视图 RGB-D 场景**（10,000 训练 / 1,000 验证）；每场景 30 个随机基元（立方体、球、柱、锥、环），深度 0.1–10 m，随机材质与光照。
- 相机 55 mm 焦距、24×24 mm 传感器、256×256 分辨率；每场景 1 源视图 + 4 目标视图。
- 散焦图由预训练 **BokehMe** 合成，对焦面设为最近场景深度，k_def 从 [0.3, 10.0] 采样。

- **Booster / Middlebury**：本文方法在 AbsRel、RMSE、δ1 **三项深度指标上全面优于所有单图像基线**（Booster：AbsRel 0.075 vs 最优基线 0.230；Middlebury：0.098 vs 0.189），NVS 的 PSNR/SSIM/LPIPS 也全面领先。
