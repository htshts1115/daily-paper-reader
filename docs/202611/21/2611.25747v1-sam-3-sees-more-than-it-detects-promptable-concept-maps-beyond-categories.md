## 摘要
可提示分割器回答某个物体是什么。密集预测任务也会提出与类别无关的问题，例如什么物体突出或被隐藏，光如何被遮挡、透射或反射，以及结构位于何处。机器人、监控系统和图像编辑器都建立在其答案之上。我们研究可提示概念图（PCM），它将 SAM 3 的可提示概念分割从名词实例扩展到由简短名词短语命名的概念图，例如“透明物体”，并以“none”作为答案。PCM-Bench 按所提问题将七类此类任务的标准测试集分组。在它上面，我们发现 SAM 3 看到的比检测到的更多。其语义路径会响应其中许多概念，但较低的图像级存在分数可能会阻断其实例路径的所有检测。我们提出 UNVEIL，它为这些图训练 SAM 3 语义路径的副本，并在其最后若干块的副本上使用 LoRA。一个独立的存在解码器从已验证的负样本中学习概念是否出现。每次查询使用一个文本短语，UNVEIL 可映射显著与伪装物体、阴影、透明物体和镜子等区域概念。相同的权重既能映射边缘和骨架等细薄结构，也能映射物体类别。与 SAM 3 并排运行时，它保持 SAM 3 自身的输出不变。在七项任务中的每一项上，UNVEIL 在比较的可提示模型中取得最高分数，包括 SAM 3 的官方微调以及基于多模态大语言模型构建的流水线。代码见 https://github.com/yuhuan-wu/UNVEIL。

## Abstract
Promptable segmenters answer what a thing is. Dense prediction tasks also ask class-agnostic questions, such as what stands out or hides, how light is blocked, transmitted or reflected, and where structure lies. Robots, surveillance systems and image editors build on their answers. We study promptable concept maps (PCM), which extend SAM 3's promptable concept segmentation from noun instances to maps of concepts named by short noun phrases such as `"transparent object", with "none" as an answer. PCM-Bench groups the standard test sets of seven such tasks by the question they ask. On it, we find that SAM 3 sees more than it detects. Its semantic path responds to many of these concepts, yet a low image-level presence score can block every detection of its instance path. We present UNVEIL, which trains a copy of SAM 3's semantic path for these maps, with LoRA on copies of its last blocks. A separate presence decoder learns from verified negatives whether a concept occurs. With one text phrase per query, UNVEIL maps region concepts such as salient and camouflaged objects, shadows, transparent objects and mirrors. The same weights map thin structures such as edges and skeletons as well as object categories. Run next to SAM 3, it leaves SAM 3's own outputs unchanged. On each of the seven tasks, UNVEIL reaches the highest score among the compared promptable models, including SAM 3's official fine-tuning and pipelines built on multimodal LLMs. Code is available at https://github.com/yuhuan-wu/UNVEIL.
