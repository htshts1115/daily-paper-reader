Abstract
In-context segmentation uses annotated references to spec-
ify the target and its extent in a query image.
Accu-
rately transferring this reference-specified foreground re-
quires recovering target regions while suppressing irrel-
evant predictions. We propose ReSA, a reference-guided
framework that unifies query adaptation and mask selection
through a shared reference kernel. ReSA leverages fore-
ground and background reference prototypes to constrain
prediction changes during adaptation and guide foreground
selection through reference-weighted reconstruction. This
shared guidance promotes consistent use of reference infor-
mation across prediction refinement and mask formation.
ReSA further selects among adapted predictions and aligns
boundary refinement with the selected foreground thresh-
old. We establish a theoretical bound connecting reference-
response changes during adaptation and soft reconstruc-
tion. With a frozen visual encoder and lightweight test-time
adaptation, ReSA requires no offline task training. Ablation

mIoU among the evaluated methods, reaching 62.6% in 1-

1. Introduction
In-context segmentation uses a few annotated reference im-
ages to specify the target in a query image.
The refer-
ence masks define both target identity and foreground ex-
tent, supporting object, part, and cross-domain segmenta-
tion [5, 6, 8, 11, 13, 16, 22, 23, 38, 51]. Reference fore-
ground and background provide examples of target and non-
target content. Segmentation must recover the specified ex-
tent while excluding surrounding distractors.
Existing approaches use learned decoders [25, 32, 47]

or pretrained mask generators [26, 52, 53].
Decoder-
based methods learn reference-conditioned segmentation
from annotated training data. This requires task-specific su-
pervision; cross-domain research reports declining target-
domain performance with continued source-domain train-
ing [28]. SAM-based approaches combine semantic corre-
spondence with a mask generator, requiring prompt selec-
tion and alignment with the reference-specified mask gran-
ularity [52]. These dependencies have motivated segmenta-
tion directly from dense self-supervised features.
On frozen features, reference matching and feature
affinities guide query-region selection and aggregation [10,
44]. The conversion from correspondence to foreground re-
gions determines mask quality. Confident predictions can
include distractors and omit target regions. Figure 1 illus-
trates two remaining errors: incomplete target coverage and
extra foreground from unrelated regions. Part segmentation
further requires selecting the annotated portion of an object
(Fig. 4). These errors motivate using reference foreground
and background throughout mask inference.
We study foreground recovery through two connected
decisions: query adaptation and mask selection. Adapta-
tion updates foreground probabilities; selection determines
which regions enter the mask. Both affect coverage and
background inclusion. Our central idea is to use the same
reference-to-query similarities to guide both decisions. The
annotated context thus informs both the adaptation objec-
tive and the selection criterion.
We propose ReSA, a unified framework for reference-
guided adaptation and mask selection (Fig. 3). A shared
reference kernel represents similarities between query fea-
tures and foreground/background reference prototypes.
Response-constrained adaptation (RCA) uses this kernel to
regularize weighted foreground responses during entropy
minimization. Reference-weighted mask selection (RMS)
reuses the kernel to fit candidate-specific thresholds through
weighted probability reconstruction and selects a candidate
by relative reconstruction gain. Threshold-aligned refine-
ment (TAR) uses the selected threshold to align the CRF
unary scores before refining the mask boundaries.
The
framework keeps the encoder frozen and adapts lightweight
classifiers separately for each episode.
Our contributions are:
• We propose ReSA, an in-context segmentation frame-
work that uses foreground and background reference cues
to guide query adaptation and mask selection, improving
target coverage and suppressing false positives.
• We connect response regularization and reconstruction-
based threshold fitting through a shared reference kernel,
and select candidates by relative reconstruction gain. We
derive a bound linking adaptation and soft reconstruction,
and align boundary refinement with the selected thresh-
old.

4. Experiments
4.1. Evaluation setting
Benchmarks and metric.
We evaluate 1-shot and 5-shot
segmentation on ten datasets: LVIS-92i, COCO-20i, FSS,
and PASCAL-5i for natural objects; PASCAL-Part and
PACO-Part for parts; and ISIC, SUIM, iSAID, and X-Ray
for specialized imaging domains [5, 6, 8, 11, 13, 16, 22,
23, 38, 51].
The eight original benchmarks follow IN-
SID3’s class and fold protocols. FSS uses Matcher’s 240
test classes and 2,400 episodes per shot setting. PASCAL-
5i [41] uses VOC2012/SBD annotations and FSSAM’s
sampling pools, with 1,000 fixed episodes per fold and shot
setting [14]. The evaluation covers 133,962 episodes in to-
tal. We pool intersections and unions across episodes within
each class to compute foreground IoU, then average over
classes and folds. Cross-dataset averages weight all datasets
equally.
Implementation.
We use a frozen DINOv3 ViT-L/16 en-
coder with 1024 × 1024 inputs, producing 64 × 64 tokens.
Positional debiasing uses a rank-500 basis, and each clas-
sifier has 1,025 parameters.
Reference fitting and query
adaptation use separate AdamW [30] optimizer states, with
a learning rate of 0.004 and betas (0.9, 0.999). We use the
same inference configuration across datasets and shot set-
tings. TAR runs five iterations on a 640 × 640 grid with
η = 8 and a five-pixel band radius. Full implementation,
optimization, sampling, and evaluation details are provided
in Supplementary Sections A and C.

5. Conclusion
We presented ReSA, a framework connecting query adapta-
tion and mask selection through a shared reference kernel.
Foreground and background reference cues regularize query
responses and weight probability reconstruction for thresh-
old fitting. Relative reconstruction gain selects a candidate
whose threshold aligns CRF unary scores for boundary re-
finement. Our analysis links adaptation and soft reconstruc-
tion through a bound on reference-response drift. With a
frozen encoder and lightweight adaptation, ReSA leads the

evaluated methods across ten benchmarks at 62.6%/71.8%
mean mIoU in 1-shot/5-shot. Ablations quantify adapta-
tion and selection gains; visualizations show more complete
masks and fewer isolated false positives.

A.3. Episode-local optimization
Each episode initializes a zero-weight, zero-bias head and
fits the reference annotations once. Both query branches
copy the fitted head and reset their AdamW states. They
share detached features, a fixed reference kernel, and fixed
initial responses.
A.4. Reference-mask sampling
Reference masks are bilinearly resized to the token grid
and thresholded at 0.5, following INSID3 [10]. Candidate
matching, dense evidence, and head supervision use this
same sampling.

For AdamW, ϵ = 10−8 and the exact weight decay is

Threshold-aligned boundary evidence.
On the CRF
grid specified in Table S2, the spatial scales are α = 15 and
γ = 5 pixels, the color scale is β = 0.03, and spatial and

are all 1 [19, 20]. Circular erosion/dilation defines the band.
Foreground priors are 0.95 in the eroded core, 0.05 out-

background and channel 1 foreground; the corresponding
input scores are the negative and positive logit of the prior.
TAR retains these scores outside the band and sets its band
scores to (ℓbg

x ) = (−ηezx/2, +ηezx/2), where ez is the
interpolated aligned logit. The solver subtracts these scores
in its unary energy, so positive ezx favors foreground. The
final band label is foreground when the channel-1 output
exceeds channel 0. The probability and selected threshold
are clipped to [10−6, 1 −10−6] before taking logits. After
optimization, the core foreground and exterior background
are explicitly restored.
A.6. Reference-based foreground check
Reference–query correspondence identifies candidate fore-
ground tokens before probability fitting. For a query to-
ken, the foreground and background matching scores are
log-mean-exp similarities to the respective reference token
sets, with inverse temperature β = 8. A reference votes
foreground when its foreground score is larger. Majority
voting across references is intersected with positive similar-
ity to the equally weighted reference foreground prototype.
If no query token has positive similarity, the prototype gate
instead retains similarities above their 90th percentile. A
reference containing only one class on the token grid votes
for that class.
If the candidate set is empty, the coarse mask is empty.
If candidates exist but any reference lacks foreground or
background tokens, reference-conditioned region aggrega-
tion produces the coarse mask. These cases bypass head
adaptation and threshold fitting and use neutral-evidence
CRF refinement with a five-pixel band radius and ten itera-
tions. Their predictions are included in the full evaluation.
A.7. Execution and computational cost
The two RCA branches share feature extraction and ref-
erence fitting; each branch adds query adaptation and
O(N log N) threshold search. TAR runs once on the se-
lected output. All-pairs correspondence scales quadratically
with token count; Section G reports measured runtimes.
