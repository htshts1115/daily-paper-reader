## 摘要
扩散模型通过迁移大规模预训练学到的生成先验，在图像抠图中展现出强大潜力。然而，现有方法大多依赖潜在扩散模型，其压缩表示和基于 VAE 的重建与抠图所需的高频精度之间存在不匹配。我们提出 PixelMatte，一个将预训练像素空间扩散 Transformer 适配于高保真图像抠图的框架。我们表明，即使仅使用纯文本到图像模型，而无需成对的图像到图像预训练，也能获得强大的图像条件抠图能力。我们的方法复用骨干网络原生的 patch embedding，将输入图像、trimap 和带噪 alpha matte 作为空间对齐的 token 联合处理，从而无需额外的条件编码器或适配器即可实现直接的像素空间预测。借助像素级精确的合成监督和真实图像微调，PixelMatte 在单次前向传播中预测 alpha matte。两个轻量级校准模块 LayerShift 和 High-Pass Refiner 进一步提升区域不透明度准确性和边界保真度。在四个基准和两个不同的像素扩散骨干上的实验表明，相较于现有方法有显著提升：在 P3M-500-NP 和 AM-2K 上，相对于 RenderMatte 将 SAD 和梯度误差降低 24–44%，同时在 AIM-500 和 RenderMatte-2K 上取得有竞争力的性能。这些结果证明了像素空间生成先验对于精度敏感的图像抠图的有效性。项目页面：https://white-yc.github.io/pixelmatte/。

## Abstract
Diffusion models have shown strong potential for image matting by transferring generative priors learned from large-scale pretraining. However, existing approaches largely rely on latent diffusion models, whose compressed representations and VAE-based reconstruction introduce a mismatch with the high-frequency precision required for matting. We present PixelMatte, a framework that adapts pretrained pixel-space diffusion transformers for high-fidelity image matting. We show that strong image-conditioned matting capabilities can be acquired even from a pure text-to-image model without paired image-to-image pretraining. Our approach reuses the backbone's native patch embedding to jointly process the input image, trimap, and noisy alpha matte as spatially aligned tokens, enabling direct pixel-space prediction without additional condition encoders or adapters. With pixel-accurate synthetic supervision and real-image fine-tuning, PixelMatte predicts alpha mattes in a single forward pass. Two lightweight calibration modules, LayerShift and High-Pass Refiner, further improve regional opacity accuracy and boundary fidelity. Experiments across four benchmarks and two distinct pixel diffusion backbones demonstrate substantial improvements over existing methods, reducing SAD and gradient errors by 24-44% relative to RenderMatte on P3M-500-NP and AM-2K, while achieving competitive performance on AIM-500 and RenderMatte-2K. These results demonstrate the effectiveness of pixel-space generative priors for precision-sensitive image matting. Project page: https://white-yc.github.io/pixelmatte/.

## 1. 核心问题与研究动机

- **任务背景**：Trimap 引导的图像抠图需要从合成图像中逐像素估计 alpha，本质上是一个病态逆问题；难点集中在发丝、毛发、枝叶、透明边界等高频细节区域，要求像素级精度。
- **现有方法的矛盾**：近年生成式抠图方法（DiffMatte、RenderMatte、SDMatte 等）借助大规模预训练扩散先验提升泛化性，但绝大多数建立在**潜空间扩散模型（LDM）**之上：
  - 骨干在空间压缩的潜表征上运算，发丝级结构与不透明度过渡未被显式表示；
  - 像素级监督只能通过**冻结的 VAE 解码器**间接施加，高频细节依赖生成先验“恢复”而非直接建模。
- **论文主张**：抠图是典型的高频任务，与潜空间压缩天然不匹配；应改用**像素空间扩散 Transformer**，绕过 VAE 的压缩—重建链路，在像素空间直接预测与监督 alpha。
- **整体含义**：验证像素空间生成基础模型可迁移到精度敏感的稠密预测任务，拓展其应用边界（不止于图像合成）。

## 2. 方法论

### 2.1 核心思想
- 复用预训练像素扩散骨干的**原生 patch embedding**，把输入图像、trimap 与带噪 alpha matte 编码为**共享空间网格上对齐的 token 序列**，联合自注意力直接建立像素级对应关系。
- **不需要** VAE、独立条件编码器或适配器；**单次前向**输出 alpha；甚至可直接改造**纯文本到图像模型**（PRXPixel），无需成对 image-to-image 预训练。

### 2.2 关键公式与流程
- **表示**：`x0 = 2α − 1`（复制三通道）；条件 `c = (I, T̄)`，`T̄ = 2T − 1`；未知区域 `U = {p : T(p) = 0.5}`。
- **前向加噪与预测**（式 1）：`xσ = (1−σ)x0 + σkε`，`ˆx0 = fθ(xσ, σ, c)`，其中 σ 为噪声水平、k 为骨干原生噪声尺度。
- **对齐条件拼接**（式 2）：`S = [E(xσ); E(I)+s; E(T̄)+s]`；PRX 用共享学习向量 `s`（零初始化），HiDream 不用 `s`，改在旋转位置编码的**时间轴**上区分三段，空间坐标保持一致。
- **训练目标**（式 3）：RenderMatte 的监督配方——未知区域内的 flow-matching 项（权重 `w(σ)/σ²`，钟形且 `w(1)=0`）+ alpha 边缘损失 `LAE`（ℓ1、SAD、MSE、梯度、拉普拉斯金字塔），λ 自适应平衡。与潜空间基线的区别是 `LAE` 直接作用于像素级预测，无解码器介入。
- **两阶段微调**：① 合成阶段用 RenderMatte 的像素精确合成数据；② 真实数据阶段按 75% 合成 + 25%（P3M-10k、AM-2K 训练集）混合训练，全部 Transformer 权重参与。
- **单步推理**（式 4）：固定 `σ = 1` 与固定种子噪声，一次前向取通道均值反归一化并裁剪；`U` 外像素直接赋 trimap 值。

### 2.3 两个轻量校准模块
- **误差分解动机**（式 5）：`e(p) ≈ β0 + βedge(d(p)) + r(p)`，即区域 alpha 水平偏移、边缘轮廓误差与其余图像相关误差，分别对应一个模块。
- **LayerShift**（式 6）：在每层第二次归一化后、MLP 前，对与未知区域重叠的 target token 加一个可学习向量 `bℓ`（按 `un` 掩码）；骨干冻结，仅训 300 步（σ=1，用 `LAE`）；HiDream 上仅 `36×4096 = 147,456` 参数。作用为**输入无关的区域不透明度校准**。
- **High-Pass Refiner**（式 7–8）：小型 CNN `gϕ`（8 个膨胀残差块、96 通道、约 1.3M 参数）输入 `(ˆα, T, I)`，输出残差场 `D`；经高通算子 `P_hp^U` 减去掩码归一化的高斯局部均值（σh = 24 px、η = 1e−3），抑制慢变校正、保留局部校正，最终 `ˆα' = clip(ˆα + P_hp^U(D))`。在冻结骨干（无 LayerShift）的缓存预测上训练，推理时作用于带 LayerShift 的输出。作者指出：去掉减均值操作会在合成集上更好、在两个真实集上更差。

## 6. 主要结论与发现

- 像素空间扩散先验可有效迁移到高精度抠图，**无需 VAE、条件编码器或适配器**即可在像素空间直接预测与监督 alpha。
- **纯 T2I 骨干（PRXPixel）** 经监督微调即可获得强图像条件抠图能力，说明“图像编辑型预训练”并非必要条件。
- 定量结果：P3M-500-NP 上 SAD 由 RenderMatte 的 6.2 降至 4.3、AM-2K 上由 6.5 降至 4.4（HiDream-8B）；相对 RenderMatte，HiDream 降低 SAD/Grad 30–44%，同分辨率的 PRX 降低 24–38%；AIM-500 上两骨干 Grad 降低 24–31%；RM-2K 上与 RenderMatte 相当（3.3 vs 3.6/3.5）。
- **校准模块作用机制被分离验证**：LayerShift 带来跨像素子集的均匀小幅改善（区域不透明度）；High-Pass Refiner 的增益集中在硬边界附近（轮廓 3 px 内饱和像素的 SAD 贡献由 0.54 降至 0.23）。
- Refiner **不是在重新估计抠图**：替换为无关图像仍保留约 95% 的合成集改进，无 RGB 重训在 RM-2K 上几乎持平（3

（接上文）……（无 RGB 重训版本在 RM-2K 上与完整版本基本持平），说明 Refiner 主要在做**局部残差校准**而非重新解抠图问题；但 RGB 输入对合成集仍有可观贡献，作者据此保留了 RGB 分支。

- **两模块互补且分工明确**：LayerShift 提供跨像素子集的均匀小幅改善（区域不透明度偏差 β0），Refiner 的增益集中在硬边界附近（轮廓项 βedge），二者叠加优于任一单独使用，与式 5 的误差分解假设一致。
- **模块具有一定通用性**：同一 High-Pass Refiner 迁移到潜空间骨干 RenderMatte 上仍带来一致改进（Tab.5），说明“冻结骨干 + 高通残差校准”是一种与骨干无关的通用后处理思路。
- **骨干规模/分辨率的影响**：HiDream-8B（patch 32、2048²）整体略优于 PRX-7B（patch 16、1024²），但 PRX 在同等 1024² 分辨率下已相对 RenderMatte 有明显提升，说明收益主要来自“像素空间 + 原生 patch 对齐”这一设计，而非单纯参数量。

## 7. 局限性与可讨论之处

- **方法新颖性偏“组合式”**：核心配方（flow-matching 监督 + `LAE` 边缘损失 + 合成/真实两阶段微调）直接沿用 RenderMatte，本文的主要增量是**把骨干从潜空间换成像素空间**，以及两个轻量校准模块。前者是架构选择层面的验证性贡献，后者参数量虽小但引入了额外训练阶段与超参。
- **训练成本与可获得性未量化**：7B/8B 级骨干 + 两阶段全参数微调，实际门槛远高于传统抠图模型；论文只报告推理时延，缺少训练 GPU 时数、显存需求等信息，难以评估方法的实际可用性。
- **推理时延并非实时**：0.46–0.64 s/张虽快于 RenderMatte（0.91 s），但对视频抠图、直播等场景仍偏慢；且单步推理**固定 σ=1 与固定噪声种子**，论文未分析种子/噪声尺度对结果方差的影响，也未讨论多步采样是否能进一步提升精度。
- **超参敏感性缺失**：LayerShift 仅训练 300 步、单一噪声水平 σ=1；Refiner 的高斯尺度 σh=24 px、η=1e−3、8 个膨胀残差块等均为固定设定，均无敏感性分析；真实/合成 75/25 的混合比例也只有一个设定。
- **评测严谨性**：主表数值引自他人汇总结果而非统一重跑，Conn 指标定义在 Tab.1 与其他表之间不一致；部分分析实验仅用单一噪声种子；定性对比的放大区域为独立选取，存在展示偏差的可能。
- **任务覆盖有限**：仅评估 trimap 引导的静态图像抠图，未涉及视频抠图、无 trimap 的交互式/自动抠图；对大面積半透明物体（玻璃、烟雾）的表现只通过按 GT alpha 值分桶的 SAD 间接反映，缺少针对性讨论。
- **数据规模**：P3M-500-NP、AIM-500 各 500 张，基准规模较小，指标差异的统计显著性未做检验（未报告置信区间或多次运行方差）。

## 8. 总体评价与启示

- **定位**：这是一篇**验证性 + 工程改良型**工作。其价值不在于提出全新的抠图监督范式，而在于用受控实验回答了一个明确的问题——“高频稠密预测任务是否应该绕过 VAE 潜空间”，并给出肯定答案与可操作的实现路径（原生 patch embedding 对齐、旋转位置编码时间轴区分模态、零初始化共享向量）。
- **可迁移的设计范式**：① 用误差分解（区域偏移 / 边缘轮廓 / 其余残差）指导轻量模块设计，而非盲目加大骨干；② 冻结骨干 + 极小参数量校准模块的低成本适配策略；③ 把 Refiner 跨骨干迁移验证通用性——这三点对其它稠密预测任务（深度、法线、去 matting 化）都有参考意义。
- **对领域的启示**：像素空间扩散在 1024²/2048² 分辨率下已具备可行性，若后续能在采样效率、训练成本上进一步优化，"像素空间基础模型 + 轻量任务头"可能成为精度敏感任务的新默认路线；同时也提示潜空间生成模型在高频任务上的评测需更谨慎，避免 VAE 解码器掩盖真实建模能力。
- **可复现性**：方法描述与公式较完整，两个校准模块的结构、参数量、训练步数均有交代，具备较好的复现基础；但训练算力、随机种子、代码与权重发布情况在正文中未明确，实际复现仍存在门槛。
- **一句话结论**：论文以扎实的对照实验证明“抠图不必走潜空间”，并用两个精心设计的小模块把像素扩散骨干的精度推到新 SOTA，是一次方向明确、证据链完整的架构级验证。
