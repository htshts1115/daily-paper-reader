## 摘要
预训练生成模型为图像抠图提供了丰富的视觉先验，但其适配往往依赖变分自编码器（VAE），而VAE的空间压缩会损害精细的alpha细节，并引入额外的推理开销。为解决这些局限，我们提出X-Matte，一种用于单步图像抠图的无VAE像素空间流匹配框架。通过消除潜在空间压缩，X-Matte将RGB到alpha的转换直接建模为像素空间中的连续流。我们采用轨迹级x预测与过渡感知的alpha监督，使模型能够从中间状态中学习，同时在单次前向传播中直接预测目标alpha蒙版。该设计避免了VAE编码与解码以及迭代采样。大量实验表明，在P3M基准上，其性能与最先进的无trimap抠图方法相当，并在RWP-636和AIM-500上展现出良好的零样本泛化能力。此外，在高分辨率下，X-Matte相较于构建的单步潜在空间对应模型实现了最高9.4倍的推理加速，证明了无VAE像素空间建模在实现准确且高效图像抠图方面的有效性。

## Abstract
Pre-trained generative models offer rich visual priors for image matting, but their adaptation often relies on variational autoencoders (VAEs), whose spatial compression can degrade fine alpha details and introduce additional inference overhead. To address these limitations, we propose X-Matte, a VAE-free pixel-space flow matching framework for single-step image matting. By eliminating latent compression, X-Matte formulates the RGB-to-alpha transition as a continuous flow directly in pixel space. We adopt trajectory-wide x-prediction with transition-aware alpha supervision, enabling the model to learn from intermediate states while directly predicting the target alpha matte in a single forward pass. This design avoids both VAE encoding and decoding and iterative sampling. Extensive experiments demonstrate performance competitive with state-of-the-art trimap-free matting methods on P3M benchmarks, together with promising zero-shot generalization to RWP-636 and AIM-500. Moreover, X-Matte achieves up to a 9.4x inference speedup over a constructed single-step latent counterpart at high resolution, demonstrating the effectiveness of VAE-free pixel-space modeling for accurate and efficient image matting.

# X-Matte 论文结构化总结

## 1. 核心问题与研究背景

- **任务定位**：图像抠图（image matting）需要估计每个像素的连续不透明度（alpha matte），比二值分割更强调发丝、毛发、半透明边界等精细结构；微小误差在合成时会产生可见伪影。
- **现有路线的问题**：
  - 判别式方法（CNN / ViT 密集回归）在分布外前景与成像条件下泛化能力有限。
  - 生成式方法借助预训练模型先验，但主流做法基于潜空间扩散（LDM），存在两类范式缺陷：
    - **迭代潜空间生成**：把 alpha 编码进 VAE 潜空间再迭代采样；VAE 面向自然 RGB 图像设计，压缩会丢失 alpha 敏感的精细空间信息，且对确定性任务引入不必要的采样开销。
    - **固定时间步回归**：在固定 timestep 上把扩散骨干当特征提取器，虽高效但仍依赖压缩表示、高分辨率下有 VAE 开销，且未利用任务特定的 RGB→alpha 轨迹监督。
  - 两类范式还共同面临**分辨率鸿沟**：生成骨干预训练分辨率远低于高保真抠图所需。
- **核心研究问题**：能否让预训练生成模型**直接在像素空间**预测 alpha，既不用 VAE 接口也不用迭代采样？
- **整体含义**：论文主张用「无 VAE 的像素空间流匹配 + 单步 x-prediction」替代「潜空间压缩 + 迭代/固定步回归」，在保持精度的同时显著降低高分辨率推理成本。

## 2. 方法论

### 2.1 核心思想
- 把 RGB→alpha 的转换建模为**像素空间中的连续流（continuous flow）**，彻底移除 VAE 编码/解码，直接在原生分辨率上做 alpha 预测。
- 训练时沿整条插值轨迹监督（trajectory-wide），推理时只做**一次前向**（t=0）即可输出 alpha。

### 2.2 关键技术细节

- **像素空间流公式**：给定 RGB 图像 \(x\in\mathbb{R}^{H\times W\times3}\) 与 alpha \(\alpha\in[0,1]^{H\times W}\)，将 alpha 复制为三通道 \(\alpha_{3c}\)，定义线性插值
  \[
  z_t = t\,\alpha_{3c} + (1-t)\,x,\quad t\in[0,1]
  \]
  其中 \(z_0=x\) 为观测 RGB，\(z_1=\alpha_{3c}\) 为目标 matte。与常规「噪声→alpha」生成不同，**RGB 图像本身是流的起点**，而非辅助条件。

- **x-prediction 训练目标**：网络 \(f_\theta(z_t,t)\) 不预测速度，而是直接估计 alpha 端点：
  \[
  \mathcal{L}_{gen}=\mathbb{E}_{t\sim U(0,1)}\|f_\theta(z_t,t)-\alpha_{3c}\|_1
  \]
  在轨迹上采样 \(t\)，使模型见到大量中间 RGB→alpha 状态，形成「轨迹级端点监督」。

- **骨干与像素接口**：采用 SiT 的时间条件 Transformer 架构，配卷积式 pixel patch embedding 与线性预测头；骨干在 ImageNet 上**直接以像素空间**预训练（无 VAE），微调时保持同一像素接口以迁移生成先验。

- **单步端点预测**：由线性路径可得速度参数化
  \[
  \hat v_t=\frac{\hat\alpha_t-z_t}{1-t},\quad 0\le t<1
  \]
  推理时直接取 \(\hat\alpha=f_\theta(x,t=0)\)，一次前向、无数值积分。作者强调：轨迹仅作为**结构化监督**，而非采样轨迹；中间状态只部分暴露 alpha，相当于一组共享网络的「更简单的相关子问题」，起到正则化单步预测的作用。

- **过渡感知轨迹监督**：总损失
  \[
  \mathcal{L}=\mathcal{L}_{reg}+\mathcal{L}_{ta}
  \]
  - \(\mathcal{L}_{reg}\)：对端点回归做空间加权；
  - \(\mathcal{L}_{ta}\)：额外的加权 alpha 重建项 + 梯度监督（针对边界/发丝）。
  - **过渡感知加权**：多数像素为完全不透明或完全透明，稀疏过渡区（分数 alpha、细结构）更重要，故对中间 alpha 值赋更高权重，并在整条轨迹上施加；梯度监督补充像素级重建，惩罚边界与细发丝处的局部差异。所有监督都在 alpha 域完成，无推理期后处理。

- **分辨率自适应位置嵌入**：骨干预训练于 256×256，微调在 768px 使用**可学习位置嵌入**以适配更密 token 网格；推理时对位置嵌入做双三次插值以匹配任意输入 token 网格与长宽比，无需额外微调或精修模块。

## 6. 主要结论与发现

- **精度**：X-Matte-H 在 P3M-500-P 取得 SAD 7.53 / MSE 2.1 / Grad 10.25 / Conn 7.16；P3M-500-NP 取得 7.71 / 2.0 / 9.52 / 7.17，多数指标优于对比基线；X-Matte-B（仅 140M）也具竞争力（8.61 / 10.76 SAD）。
- **vs P3M-Net**：在 P3M-500-P 上 SAD、MSE、Conn 更优，但 Grad 略逊；在 P3M-500-NP 上四项指标全面领先（SAD 11.23→7.71），说明对人脸模糊带来的分布偏移更稳健。
- **vs 生成式基线**：相比 TeachMatte（P3M-500-P SAD 9.53→7.53），且无需教师-学生蒸馏；相比 GenPercept（P3M-500-NP SAD 12.77→7.71），且无 VAE 编解码开销。
- **零样本**：RWP-636 上 SAD 27.98 / MSE 12.8，为对比方法最佳；AIM-500 上 SAD 44.45 / MSE 18.8，优于 GenPercept（56.36 / 20.1），但绝对值仍偏高。
- **范式结论**：预训练至关重要（像素生成式无预训练 54.50 → 有预训练 22.16）；轨迹级训练显著优于固定 t=0 回归（22.16 vs 36.87）；像素 x-pred 优于潜空间 v-pred（22.16 vs 25.17）。
- **单步即最优**：1 步 SAD 8.61 最低，2/4/8 步反而升至 9.21/9.11/9.44，说明迭代采样在本公式下无益。
- **分辨率**：同一 checkpoint 从 512→768→1024px，示例 SAD 由 29.63 降至 14.23、13.15，高分辨率持续恢复更细发丝。
- **效率**：512² 时 8.7ms vs 47.4ms（5.4×），1024² 时 19.0ms vs 177.8ms（9.4×）；参数量 220M→140M，且潜空间对照同为单步，故加速不来自减少采样步数。

## 7. 优点

- **架构层面去冗余**：直接取消 VAE 接口，避免面向 RGB 的感知压缩破坏 alpha 连续值与过渡边界，同时省去高分辨率编解码开销，是「表示空间选择」层面的清晰论证而非单纯堆模块。
- **训练/推理解耦得漂亮**：训练沿整条 RGB→alpha 轨迹做 x-prediction，推理只取 t
