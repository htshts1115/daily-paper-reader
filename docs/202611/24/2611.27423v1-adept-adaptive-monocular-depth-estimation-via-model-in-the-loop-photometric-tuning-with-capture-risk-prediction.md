## 摘要
曝光和增益决定了单目深度估计（MDE）可用的视觉证据，尤其是当机器人运动在光线采集与运动模糊之间形成权衡时。我们提出 ADEPT，一个利用来自冻结深度模型的学习反馈来自适应调整这些设置的框架。在训练期间，真实深度在一组经过物理评估的相机设置中识别出误差最低的参考设置。一个紧凑的预测器使用回归损失和排序损失来学习每个候选设置的深度预测与参考预测之间的参考相对不一致性（RRD）。在部署阶段，它利用冻结模型特征以及相机、运动和光照上下文对观测到的采集图像进行评分，无需真实深度或参考图像。一个上下文高斯过程控制器利用近期评分，在运动和光度约束下选择后续的曝光和增益设置。我们使用相对与度量版本的 Depth Anything v2 评估离线相机选择，并在移动机器人上使用仿射不变变体演示在线控制。在九种等权重的场景-光照条件下，ADEPT 将平均尺度与平移对齐后的 Abs_rel 相较于内置自动曝光降低 14.6%，相较于表现最佳的已评估先前控制器降低 10.0%。

## Abstract
Exposure and gain determine the visual evidence available to monocular depth estimation (MDE), particularly when robot motion creates a tradeoff between light collection and motion blur. We present ADEPT, a framework that adapts these settings using learned feedback from a frozen depth model. During training, ground-truth depth identifies the lowest-error reference within a group of physically evaluated camera settings. A compact predictor learns reference-relative disagreement (RRD) between each candidate's depth prediction and the reference prediction using regression and ranking losses. At deployment, it scores observed captures using frozen-model features and camera, motion, and illumination context, without ground truth or reference images. A contextual Gaussian-process controller uses recent scores to select subsequent exposure and gain settings under motion and photometric constraints. We evaluate offline camera selection with relative and metric Depth Anything v2 and demonstrate online control with the affine-invariant variant on a mobile robot. Across nine equally weighted scene-illumination conditions, ADEPT reduces mean scale-and-shift-aligned $\mathrm{Abs}_{\mathrm{rel}}$ by 14.6% relative to built-in auto-exposure and by 10.0% relative to the best-performing evaluated prior controller.

## 1. 核心问题与研究动机

- **背景**：单目深度估计（MDE）仅凭单张 RGB 图像即可提供稠密几何线索，对受传感器成本、体积、载荷限制的移动机器人极具吸引力；Depth Anything v2 等深度基础模型进一步提升了跨场景泛化能力。
- **核心矛盾**：相机采集参数（曝光时间 e 与增益 g）在推理开始前就决定了可用于深度估计的“视觉证据”。长曝光可在暗场景收集更多光，但机器人运动时会引入运动模糊；缩短曝光可抑制模糊，却牺牲信噪比。饱和会抹平强度差异，模糊与低信噪比会破坏边界与纹理，而丢失的细节无法靠学习先验可靠恢复。
- **现有方法不足**：
  - 经典控制器（Shin、Kim、Shim、Zhang 等）优化梯度、熵、亮度、噪声等手工图像质量指标，并非面向 MDE。
  - 学习方法（Tomasi 用 VO/SLAM 特征匹配、Lee 用图像属性奖励、Zhang 用含 VO 性能的 DRL 奖励）监督信号与深度质量不直接对应。
  - LENS 用冻结分类模型的置信度，但面向准静态环境与分类任务。
  - 深度不确定性估计器（TTA、梯度法、SLURP 等）能否用于“排序物理相机设置”尚未被验证。
- **关键挑战**：在线部署时没有真值深度，如何获得能区分不同相机设置对冻结深度模型“有用程度”的反馈信号。
- **整体含义**：论文提出“模型在环”（model-in-the-loop）的采集端自适应框架 ADEPT，把相机曝光/增益调节转化为面向冻结 MDE 模型的采集质量控制问题。

## 2. 方法论

### 2.1 核心思想
- 用**参考相对不一致性（Reference-Relative Disagreement, RRD）** 作为采集质量的代理监督目标：训练时用真值深度在“近似同视角、不同相机设置”的采集组内选出误差最低的参考设置 c\*(s)，让轻量预测器学习“候选预测与参考预测之间的分歧”；部署时仅凭冻结模型特征与上下文即可打分，无需真值或参考图像。
- 上层用**上下文高斯过程（GP）bandit 控制器**，结合运动与光度可容许性约束，序贯选择下一组曝光/增益。

### 2.2 关键技术细节

**(1) 问题形式化与参考选择**
- 场景状态 s、相机配置 c=(e,g)，冻结模型 f_φ 输出 d̂(s,c)；相对深度模型需先做尺度-平移对齐得到 d̃，度量模型则直接用原输出。
- 图像级误差 Abs_rel(s,c) = (1/|Ω|)Σ_p |d_p − d̃_p| / d_p。
- 参考（最优）设置：c\*(s) = argmin_{c∈C} Abs_rel(s,c)；超出误差 ΔAbs_rel(s,c) = Abs_rel(s,c) − Abs_rel(s,c\*(s))。
- 通过方差分解 Abs_rel = 均值 + 场景项 + 相机项 + 场景×相机交互 + 残差，说明固定场景下相减可保留真值误差排序。

**(2) RRD 监督目标（Eq. 7）**
- D(z_{s,c}) = (1/|Ω|)Σ_p |d̃_p(z_{s,c}) − d̃_p(z_{s,c\*(s)})| / d̃_p(z_{s,c\*(s)})，即在候选与参考的深度预测之间做归一化相对偏差。

**(3) 轻量风险预测器**
- 结构：FiLM 条件化网络，输入为冻结 MDE 编码器特征 v、相机配置 c、运动状态 m 与光照状态 ℓ 组成的上下文 ξ；共 165,910 参数。
- 输出标量观测模型：D_t | z_t ~ N(b_θ(z_t), σ²_θ(z_t))，网络同时预测均值 b_θ 与对数方差 V_θ = log σ²_θ。

**(4) 训练损失（Eq. 8–11）**
- 高斯负对数似然：L_NLL = ½[e^{−V_θ}(D − b_θ)² + V_θ]。
- 列表排序损失：在同一训练状态的候选小集合 C_mini（|C_mini|=8）上，用温度 T=0.02 的 softmax 构造目标分布 π_tar ∝ exp(D/T) 与预测分布 π_pred ∝ exp(b_θ/T)，做交叉熵 L_rank（注意：分歧越大权重越大，而选择时预测 RRD 越小越好）。
- 总目标 L = L_NLL + λ_rank·L_rank，λ_rank = 0.1；训练用 AdamW，lr = 5×10⁻⁴，batch B=4。部署时深度模型与预测器均冻结。

**(5) 在线上下文 GP 控制**
- 采集打分：q_t = b_θ(z_t) + κ·σ_θ(z_t)，κ = 1.645；该分数是“采集代价”，不是标定过的失效概率。
- GP 输入 u_t = (c_t, ξ_t, τ_t)；对历史 H_t（窗口 W = 48）内分数做标准化（下限 γ_min = 0.01 防退化），残差噪声方差 σ²_n = 0.1。
- 乘积核：k = k_c(相机, 各向异性平方指数, λ_e=λ_g=0.35) × k_m(运动, 类别核, ρ_m=0.2) × k_l(光照, 类别核, ρ_l=0.2) × k_τ(时间, 指数衰减, λ_τ=5.0)。
- 后验均值/方差还原到原尺度：μ = q̄_t + γ_t·μ̃，σ = γ_t·σ̃。
- 约束选择（Eq. 17）：c_{t+1} = argmin_{c∈C_t} [μ_t(c) − β_GP·σ_t(c) + λ_switch·1{c ≠ c_t}]，β_GP = 0.5，λ_switch = 0.005（不确定性项鼓励探索，切换惩罚抑制抖动）。
- 可容许集 C_t：运动相关曝光上限（fast/rotate ≤ 16 ms，spin ≤ 8 ms）+ 光度护栏（用 ΔEV 投影亮度 Ŷ 与 RGB 做饱和筛查；过曝判据：饱和像素比 0.89 且投影均值亮度 ≥ 243；严重欠曝判据：阴影像素比 0.50 且均值亮度 ≤ 45）。
- **异步更新**：GP 条件化与当前帧预测器推理重叠，只使用已完成观测；推理结束后把分数连同配置、上下文、时间戳写入历史。

- **离线选择**：ADEPT 在所有骨干/划分组合上取得最高相关性、最低遗憾与最高准确率；相较 TTA 与梯度不确定性，绝对选择遗憾降低 **59.6%–92.4%**。例如 Metric-DAv

2 上的具体数字为：Ours 的 Pearson 相关约 0.86–0.87、Spearman 约 0.79–0.80，绝对选择遗憾约 0.008–0.011，相对选择遗憾约 0.6%–0.9%，R_rel<10% 容忍准确率约 0.93–0.95；而 TTA 与梯度基线的绝对遗憾约 0.02–0.11，R_rel<10% 准确率明显更低。相对骨干（DAv2）上趋势一致，说明 RRD 监督学到的是与骨干无关的“采集质量排序”，而非绑定某一模型的伪影。值得注意的是，训练划分与验证划分的相关系数接近，表明预测器在未见过的场景-配置组合上仍能保持排序能力。

- **在线控制**：在 9 个条件（3 场景 × 3 光照）等权平均下，ADEPT 取得最低 Abs_rel 与最高 δ1.25。相对内置 AE，Abs_rel 平均降低约 **11%–15%**；相对 Shin 与 Zhang 分别降低约 **6%–9%** 与 **4%–7%**。增益在暗光照与快速运动条件下最大：暗场景中 AE 因固定曝光策略导致严重欠曝，Shin 的噪声感知指标虽能提升亮度但常选择偏长曝光而在 fast/rotate 下引入模糊；ADEPT 通过运动约束与 RRD 打分倾向选择“较短曝光 + 较高增益”的组合，兼顾信噪比与运动鲁棒性。在 bright 且 stop 的“简单”条件下，各方法差距缩小，ADEPT 与 AE 接近，说明其收益主要来自困难工况而非普遍性提升。标准差方面，ADEPT 在多数条件下的重复间波动小于或接近基线，未出现因探索导致的大幅抖动，这与切换惩罚 λ_switch 和 GP 平滑的作用一致。

- **消融：监督目标与排序损失（Table IV）**：去掉排序损失后，离线相关性与在线 Abs_rel 均下降，说明仅靠逐点 NLL 回归难以在候选间保持正确相对次序；改用真值 ΔAbs_rel 直接监督（即“ oracle 监督”）在训练划分上略优，但在验证划分上并未超过 RRD 监督，作者据此论证 RRD 作为“无需真值即可构造”的代理目标在泛化上并不逊色，且部署时无需真值。该对比是论文方法论主张的关键证据，但其“oracle 监督”变体仍依赖训练期真值深度，二者在训练数据效率上的差异未被进一步分析。

- **消融：可容许性约束（Table V）**：在验证场景 1 暗光照下，无滤波版本出现较多退化选择（过曝或运动模糊），仅运动约束主要改善 fast/rotate/spin 条件，仅光度约束主要改善 dark/bright 极端光照，两者兼有取得最佳 Abs_rel 且方差最小。说明两类约束分别针对不同失效模式，具有互补性；但该消融仅在单一场景单一光照下重复 5 次，覆盖范围有限。

- **运行时开销（Table VI）**：如第 4 节所述，ADEPT 总时延约 298 ms（≈3.35 Hz），介于内置 AE（≈4.86 Hz）与 Shin（≈2.86 Hz）、Zhang（≈3.10 Hz）之间；其中相机切换（59.48 ms）是主要固定开销，决策计算仅 6.65 ms，GP 与预测器的额外计算负担相对 MDE 推理（205.82 ms）较小。异步更新设计使控制计算与当前帧推理重叠，避免串行累加，是其在嵌入式平台上可用的关键工程决策。但 3.35 Hz 的控制频率对高速运动或快速光照变化的适应性仍有上限，论文未给出更高动态场景下的时延敏感性分析。

- **定性分析（Fig. 3–4）**：轨迹图显示 ADEPT 在暗区倾向提高增益/延长曝光、在亮区与转向时收缩曝光，呈现与场景结构相关的自适应模式；图像与深度图对比显示，AE 在暗场景产生欠曝导致的深度空洞与边界糊化，Shin 在运动段出现拖影，ADEPT 的深度图在物体边界与远处结构上更完整。定性证据与定量趋势一致，但样本为挑选的代表性帧，未做系统性的人为评分或下游任务验证。

- **描述性双因素 ANOVA（255 个圈级观测）**：场景与光照主效应及交互在 Abs_rel 上显著，支持“相机设置收益依赖场景-光照上下文”的设计前提；但该分析为描述性、基于圈级聚合，未对在线方法间差异做配对显著性检验，因此“ADEPT 优于基线”的统计稳健性仅由均值 ± 标准差与重复次数间接支持。

## 7. 局限、启示与总体评价

- **主要局限**：
  1. **场景与模型覆盖有限**：仅 3 个验证场景、单一建筑布局，训练/验证配置结构相同；仅评测 Depth Anything v2 Small 一个家族与规模，未验证对更大模型、度量模型在线部署或非 Transformer 架构的迁移性。
  2. **状态感知不完整**：光照状态为人工标注而非在线感知，运动状态依赖轮式编码器（对打滑、非平坦地形敏感）；实际部署需补上光照分类器与更鲁棒的 ego-motion 估计。
  3. **动作空间离散且范围有限**：16 组离散配置、曝光上限 32 ms、增益上限 128，未验证连续优化、更大动态范围或与光圈/ND 滤镜等的联合控制。
  4. **统计严谨性不足**：在线结果缺少显著性检验与置信区间；消融覆盖条件偏少；基线未针对本任务重调参，也未与 LENS 等最相关工作直接比较。
  5. **代理目标的理论保证有限**：RRD 依赖“近似同视角配准 + 组内参考”的构造，配准失败样本被丢弃可能引入选择偏差；方差分解仅提供描述性支持，未给出 RRD 排序与真值排序一致性的形式化界。
  6. **下游任务验证缺失**：论文以深度精度指标为主，未展示对 VO/SLAM、导航或避障等机器人下游任务的端到端收益。

- **启示**：
  - 将“采集控制”重新表述为“面向冻结感知模型的采集质量控制”，并用模型自身的相对不一致性构造免真值监督，是一种可迁移到其他任务（如语义分割、光流、VIO 特征跟踪）的范式；关键在于找到“同视角、多设置”的配对数据构造方式与合适的相对度量。
  - 轻量条件化预测器 + 上下文 GP bandit 的分层设计，把“学习式打分”和“序贯决策与安全约束”解耦，便于在嵌入式平台部署，也便于替换打分器或约束模块。
  - 显式建模运动与光度的可容许集，比单纯优化图像质量指标更贴近“感知可用性”，这一思路对自动曝光、HDR 与主动感知系统均有参考价值。

- **总体评价**：论文问题定义清晰、动机充分，方法论上把“无真值在线反馈”这一核心难题转化为“训练期用真值构造参考、部署期用相对分歧打分”的可操作方案，并以离线选择、在线控制、多组消融与嵌入式时延测量形成了较完整的证据链。其主要贡献在于提出并验证了 RRD 这一免真值采集质量代理目标与配套的约束 GP 控制框架，而非追求单点精度 SOTA。不足主要在实验规模、模型/场景覆盖与统计严谨性上，结论的普适性仍需在更多场景、更大参数空间与下游任务中检验。
