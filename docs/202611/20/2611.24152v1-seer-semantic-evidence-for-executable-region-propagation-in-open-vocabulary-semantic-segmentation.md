## 摘要
免训练开放词汇语义分割（OVSS）通过将类CLIP表示适配到稠密预测已取得显著进展，但其残余误差往往是局部的、结构化的，并与当前激活的标签空间相关。一次成功的修正必须在视觉上合理、在目标词汇表下合法，并能在分割得分场中执行。我们提出SEER，一种用于语义证据与可执行区域传播的免训练测试时修复层。SEER将预测后的OVSS修复建模为以证据为条件的标签传播。OVSS得分空间提出紧凑的候选标签，冻结的VLM验证闭集区域证据，执行门控则判定该证据是否在合法性和语义上可操作。被接受的标签随后由OVSS侧策略进行传播：连贯的高置信度区域允许广泛传播，而存在目标或边界风险的案例则采用保守的、基于得分的传播。在八个标准OVSS基准上，SEER在不更新OVSS权重的情况下达到58.0的平均mIoU。匹配输入对照实验分离出修复机制的作用，资源测量则报告了完整冻结系统的开销。

## Abstract
Training-free open-vocabulary semantic segmentation (OVSS) has made strong progress by adapting CLIP-like representations to dense prediction, but its remaining errors are often local, structured, and tied to the active label space. A successful correction must be visually plausible, legal under the target vocabulary, and executable in the segmentation score field. We propose SEER, a training-free test-time repair layer for Semantic Evidence and Executable Region propagation. SEER casts post-prediction OVSS repair as evidence-conditioned label propagation. The OVSS score space proposes compact candidate labels, a frozen VLM verifies closed-set regional evidence, and an execution gate certifies whether the evidence is legally and semantically actionable. The accepted label is then propagated by an OVSS-side policy: coherent high-confidence regions allow broad propagation, while object- or boundary-risk cases use conservative score-grounded propagation. Across eight standard OVSS benchmarks, SEER reaches 58.0 average mIoU without updating OVSS weights. Matched-input controls isolate the repair mechanism, while resource measurements report the cost of the complete frozen system.

## 1. 核心问题与整体含义

- **研究背景**：开放词汇语义分割（OVSS）借助 CLIP/OpenCLIP 等视觉语言表征，在免训练稠密预测上已取得明显进展；但剩余错误往往是**局部的、结构化的**，例如边界溢出、物体部件混淆、stuff/object 歧义等。
- **核心问题**：对固定 OVSS 预测进行后处理修复时，一个修正动作必须同时满足三个条件：
  - 标签在视觉上合理；
  - 标签在当前激活词表下合法；
  - 标签能在 OVSS 得分场中执行到正确像素。
- **现有 VLM 直接修正的不足**：通用 VLM 能描述区域语义，但若直接让其决定像素掩码，会把“区域语义判断”“标签空间合法性”“像素传播范围”混在一起，导致不可执行或边界越界。
- **论文定位**：SEER 将 OVSS 后预测修复建模为**证据条件的可执行区域标签传播**：VLM 只提供闭集区域证据，像素写回权仍由 OVSS 得分场控制。整体含义是：在不更新 OVSS 权重的前提下，为已有 OVSS 系统增加一个训练无关的测试时修复层。

## 2. 方法论

### 2.1 核心思想

- 将修复动作形式化为 \(r_i=(\ell_i,W_i)\)：\(\ell_i\) 是验证后的目标标签，\(W_i\subseteq M_i\) 是传播支持像素集合。
- 更新规则为：若像素 \(p\in W_i\)，则 \(Y^{t+1}_p=\ell_i\)，否则保持 \(Y^t_p\)。
- 关键分工：
  - **VLM**：负责区域语义证据，选择闭集候选标签或弃权；
  - **OVSS 得分场**：负责判断标签可在哪些像素上执行；
  - **执行门控**：过滤不合法、低置信、混合/不清晰证据。

### 2.2 算法流程

1. **候选 proposal 选择**：
   - 使用固定 SAM2 类无关 proposal bank 提供空间域；
   - 对每个 proposal 计算主标签、区域一致性、面积、候选与主标签的得分竞争、风险暴露等；
   - 用固定优先级函数 \(\pi_i\) 在审计预算 \(K\) 下选 TopK proposal，减少 VLM 调用。

2. **构建闭集候选标签**：
   - 对 proposal \(M_i\)，主标签为 \(b_i\)；
   - 从 OVSS 得分中取最多 3 个非主标签候选 \(Q_i\)；
   - 候选集为 \(A_i=\{b_i\}\cup Q_i\cup\{\text{uncertain}\}\)；
   - VLM 不允许发明词表外标签，只能从闭集候选选择或弃权。

3. **多视图 VLM 验证**：
   - 输入包括全图高亮、局部邻域裁剪、紧裁剪三视图；
   - 输出证据元组 \((\hat\ell_i,\text{conf}_i,\text{form}_i)\)：候选标签、置信度、区域形态（coherent/boundary/mixed/unclear）。

4. **执行门控**：
   - 仅当标签合法、非当前主标签、非 uncertain、置信度为 high、且区域形态不是 mixed/unclear 时，才允许写回；
   - 否则该 proposal 不改变预测。

5. **得分控制的像素传播**：
   - 对通过门控的标签，传播支持 \(W_i=\Gamma(S,Y^0,M_i,\ell_i,a_i)\)；
   - 三种策略：
     - **连贯传播**：高置信、低风险、连贯区域允许 \(W_i=M_i\)；
     - **得分支撑传播**：只传播到目标标签在 OVSS 得分场中仍有支撑的像素；
     - **边界保守传播**：对物体类、边界敏感或高风险区域，仅传播到低 margin 像素，限制越界。
   - 文中给出得分支撑谓词 \(\rho(p,\ell_i,b_i)\)，结合目标得分、主标签得分差、margin 和固定阈值 \((\tau_s,\tau_m,\tau_l)=(0.02,0.20,0.25)\)。

### 2.3 理论解释

- 论文给出精确的收益–风险分解：一次修复的误差变化等于“被修复像素数”减去“被破坏的正确像素数”。
- 进一步论证：仅凭区域证据无法识别最优像素支持集；因此需要将“标签方向”和“像素投影器”分离，前者由 VLM 证据决定，后者由 OVSS 得分场决定。

## 6. 主要结论与发现

- **精度提升**：
  - ViT-L/14 下，SEER 在 8 个 benchmark 上平均 **58.0 mIoU**，较 CorrCLIP 的 53.6 提升 **+4.4**；
  - ViT-B/16 下平均 **56.2 mIoU**，较 CorrCLIP 的 51.0 提升 **+5.2**；
  - 每个 benchmark 均有提升，ADE20K 与 Cityscapes 提升尤其明显。
- **机制结论**：
  - 仅得分规则、CLIP crop 分类器、单独 VLM 答案、Dense-CRF 平滑均明显低于完整 SEER；
  - 闭集 top-3 候选在机制 benchmark 上目标在集合内覆盖率约 **99.9%**；
  - 执行过滤将执行答案精度从 **57.9%** 提升到 **82.3%**，约 **36.2%** 审计不修改预测，仅 **0.2%** 无效/越界；
  - 三视图证据优于单视图或紧裁剪；
  - 跨 OVSS base 平均增益约 **+4.53 到 +5.93 mIoU**；
  - 更强 proposal 源（如 SAM3）可提高上限，说明 proposal 覆盖是重要瓶颈。
- **残余失败**：
  - 主要集中在混合 proposal、细薄结构、候选漏检、得分支撑碎片化；
  - harm 来源主要是支持溢出与语义错误；
  - oracle 分析显示 SEER 平均约恢复完整 proposal 池 oracle 增益的一半，仍有明显 headroom。

## 7. 优点

- **

- **问题分解清晰**：把“区域语义判断”“标签合法性”“像素传播范围”拆成三个可分别验证的环节，避免了通用 VLM 直接输出掩码时职责混杂的问题；这一分解也直接对应论文给出的收益–风险分解，方法论与理论解释自洽。
- **训练无关、即插即用**：不更新 OVSS 权重、不需要像素级写回监督，作为后处理层可叠加在 CorrCLIP、ProxyCLIP、ResCLIP、Trident 等不同 base 上，并报告了稳定的跨 base 增益，工程迁移成本较低。
- **闭集候选约束设计合理**：限定 VLM 只能在“主标签 + 最多 3 个得分竞争标签 + uncertain”中选择，既抑制了词表外幻觉，又保留了修正空间；约 99.9% 的目标在闭集内覆盖率说明该约束的召回代价很小。
- **执行门控有效**：将执行答案精度从 57.9% 提升到 82.3%，同时仅约 0.2% 的无效/越界写回，说明门控在“少改、改对”上取得了较好的折中；约 36.2% 的审计不修改预测，也体现了弃权机制的实际作用。
- **像素传播由得分场控制**：三种传播策略（连贯、得分支撑、边界保守）针对不同风险类型分别设计，尤其对物体类与边界敏感区域采用低 margin 限制，直接针对 OVSS 后处理中最典型的边界溢出问题。
- **实验矩阵覆盖面广**：8 benchmark × 2 backbone 的主结果，加上接口、视图、VLM 家族、proposal 来源、预算、阈值、prompt、传播策略的消融，以及 2,000 个 proposal 的质量审计与 oracle headroom 分析，证据链较完整。
- **控制实验较严谨**：机制实验中固定 \(Y^0\)、\(S\)、proposal、候选、parser、gate、传播策略与审计预算，仅改变单一因素，使归因相对清晰；同时明确区分“机制诊断状态”和“published row”，避免把诊断 delta 与主表提升混为一谈。
- **对自身局限有明确交代**：承认基线数字非等资源比较、Qwen 预训练数据可能重叠、常数非 domain-blind、proposal 覆盖是瓶颈、oracle 仍有 headroom，态度较为客观。
- **成本透明度较好**：报告了单次调用延迟、峰值显存、权重体积、平均审计调用量以及 cached/cold 两种端到端开销，便于读者判断实际部署可行性。

## 8. 局限与不足

- **额外依赖与成本**：SEER 需要 SAM2 proposal bank 与一个 9B 级 VLM 审计器，cached 模式下端到端开销约 +9.3%，cold 模式约 +19.3%；相比纯 OVSS 前向，显存与延迟门槛明显提高，在边缘部署或高吞吐场景下适用性受限。
- **比较公平性有限**：主表与已发表基线对比，未在等硬件、等外部资源、等 proposal/VLM 预算条件下重跑所有基线；SEER 的增益部分来自额外引入的 SAM2 与 VLM，难以完全归因于方法本身。
- **机制诊断与主结果存在口径差**：机制实验使用独立冻结的诊断状态，并非复现主表中 CorrCLIP 的完整 row，因此其 delta 不能直接等同于主表提升，读者需注意两类数字的可比性。
- **proposal 覆盖是硬瓶颈**：闭集候选与传播均以 proposal 为空间域，混合 proposal、细薄结构、候选漏检、得分支撑碎片化是主要残余失败来源；SAM3 等更强 proposal 源能提高上限，说明当前性能受制于上游分割质量。
- **VLM 依赖与数据重叠风险**：默认验证器为单一本地 Qwen3.5-9B，虽然替换了多个 VLM 家族做鲁棒性检验，但作者承认预训练数据可能与分割/grounding 数据重叠，未做严格去污染验证，绝对精度的可信度存在一定不确定性。
- **超参与开发域假设**：阈值 \((\tau_s,\tau_m,\tau_l)=(0.02,0.20,0.25)\) 等常数在自然图像验证域上选定后冻结，作者不声称 domain-blind；跨域（如医学、遥感、自动驾驶极端场景）泛化性缺乏直接证据。
- **只修标签、不改结构**：修复动作是“对 proposal 内像素赋新标签”，不改变 proposal 边界本身，因此对系统性欠分割、过分割或 proposal 完全缺失的错误无能为力；oracle 分析显示仅恢复约一半 headroom，也印证了这一点。
- **审计预算与候选顺序的敏感性**：TopK 预算、候选排序、prompt 表述均会影响结果，论文虽做了敏感性扫描，但未给出在未知分布上自适应设定预算的机制。
- **harm 分析仍偏描述性**：支持溢出与语义错误被识别为主要 harm 来源，但缺乏对 harm 与 proposal 形态、得分分布之间更细粒度的定量建模，限制了进一步针对性改进。

## 9. 启示与可借鉴点

- **“证据–执行”分离范式**：让 VLM 只回答“这个区域像什么”，让稠密得分场决定“改哪些像素”，是提升 VLM 在稠密预测任务中可用性的一个通用思路，可迁移到开放词汇检测、指代分割、全景分割后处理等任务。
- **闭集候选 + 弃权接口**：把开放词表问题转化为“在得分竞争候选中做选择或弃权”，既控制幻觉又保留召回，是低成本约束 VLM 输出的实用设计。
- **门控先于传播**：先判断“是否值得改”，再决定“改到哪里”，比端到端让模型输出掩码更可控；执行答案精度与无效写回率的联合报告，为评估修复类方法提供了可借鉴的指标组合。
- **多视图证据设计**：全图 + 局部邻域 + 紧裁剪三视图的互补性在消融中得到支持，说明上下文尺度对区域语义判断有实质影响，可作为 VLM 视觉提示的通用实践。
- **风险分层的传播策略**：按区域形态、类别类型、margin 风险选择不同传播强度，是一种“保守优先”的工程哲学，适合对误改代价敏感的应用。
- **诊断实验的组织方式**：固定状态、单因素变动、区分诊断口径与主表口径、报告 oracle headroom 与 harm 来源，这套实验组织方式对后续“后处理/插件式”研究具有方法学参考价值。

## 10. 总体评价

SEER 的核心贡献不在于提出新的表征或训练目标，而在于把“VLM 能否可靠地修复 OVSS 预测”这一模糊问题，重构为**证据条件约束下的可执行区域标签传播**，并通过闭集候选、执行门控与得分控制传播三个机制，把 VLM 的语义能力约束到可执行、可审计的范围内。实验上，8 个 benchmark、2 个 backbone、4 个 base、多个 VLM 家族与 proposal 源的组合，加上较系统的机制消融与 harm/oracle 分析，支撑了“稳定正增益 + 低无效写回”的主要结论；同时论文对成本、比较公平性、数据重叠与 proposal 瓶颈的交代也较为坦诚。

其主要价值在于提供了一种**低侵入、可解释、可插拔**的测试时修复范式，而非追求单点 SOTA；主要局限在于额外计算与外部模型依赖、上游 proposal 覆盖的硬约束，以及跨域与去污染验证的不足。总体而言，这是一篇问题分解清楚、工程落地性较强、实验证据较充分的工作，适合作为“VLM 辅助稠密预测后处理”方向的方法学参考。
