## 摘要
单目深度估计已通过大规模预训练和强视觉骨干网络取得进展，但度量深度仍对场景级尺度敏感。室内房间与室外驾驶场景的深度范围差异很大，然而大多数深度解码器仅从视觉特征中隐式推断这种全局结构。我们探究场景级语义结构能否转而作为上游先验，在稠密预测之前塑造度量输出空间。我们提出 LangDepth（SemanticBins），一种将强视觉特征与场景条件化输出空间耦合的单目深度架构。冻结的 CLIP 编码器和可学习的、面向场景与几何的概念键库将图像特征转换为紧凑的场景描述符，无需逐图像文本或外部描述生成器。场景先验模块（SPM）将该描述符映射为场景条件化的度量深度区间，在稠密解码前提供全局范围锚点。同时，DINOv2-L 骨干网络与轻量级 FPN 提取稠密视觉特征，逐像素分配网络（PPAN）将像素分配到场景规定的分箱结构。置信度门控融合稠密视觉估计与 SPM 先验。我们在适度的有监督深度预算下，联合在 NYU Depth V2 和 KITTI 上训练 LangDepth，不使用网络规模深度监督或伪标签深度数据。单一模型在 NYU 上达到 delta_1 = 0.960，在 KITTI 上达到 0.960，在 DIODE indoor 上达到 0.887，在 iBims-1 上达到 0.946，在 SUN RGB-D 上达到 0.861。除总体精度外，SPM 预测出紧凑的室内范围和更宽的室外 KITTI 范围，门控在室外场景中变为 SPM 主导，扰动路由的场景上下文会导致 KITTI 和 iBims-1 上的大幅下降。这些结果支持将场景条件化输出空间作为跨域单目深度估计的一种实用且可解释的机制。

## Abstract
Monocular depth estimation has advanced through large-scale pretraining and strong visual backbones, yet metric depth remains sensitive to scene-level scale. Indoor rooms and outdoor driving scenes occupy very different depth ranges, but most depth decoders infer this global structure implicitly from visual features. We ask whether scene-level semantic structure can instead act as an upstream prior that shapes the metric output space before dense prediction.   We present LangDepth (SemanticBins), a monocular depth architecture that couples strong visual features with a scene-conditioned output space. A frozen CLIP encoder and a learnable bank of scene- and geometry-oriented concept keys convert image features into a compact scene descriptor, without requiring per-image text or an external captioner. A Scene Prior Module (SPM) maps this descriptor to a scene-conditioned metric depth interval, providing a global range anchor before dense decoding. In parallel, a DINOv2-L backbone with a lightweight FPN extracts dense visual features, and a Per-Pixel Assignment Network (PPAN) assigns pixels to the scene-prescribed bin structure. A confidence gate fuses the dense visual estimate with the SPM prior.   We train LangDepth jointly on NYU Depth V2 and KITTI under a modest supervised depth budget, without web-scale depth supervision or pseudo-labelled depth data. A single model achieves delta_1 = 0.960 on NYU, 0.960 on KITTI, 0.887 on DIODE indoor, 0.946 on iBims-1, and 0.861 on SUN RGB-D. Beyond aggregate accuracy, the SPM predicts compact indoor ranges and much wider outdoor KITTI ranges, the gate becomes SPM-dominant on outdoor scenes, and perturbing the routed scene context causes large drops on KITTI and iBims-1. These results support scene-conditioned output spaces as a practical and interpretable mechanism for cross-domain monocular depth estimation.

# LangDepth 论文结构化总结

## 一、核心问题与整体含义

- **背景**：单目深度估计在大规模预训练与强视觉骨干（DINOv2、ViT 等）推动下精度显著提升，但**度量尺度（metric scale）仍高度依赖场景级全局上下文**：紧凑室内房间、杂乱办公室、室外驾驶场景的有效深度范围差异巨大。
- **现有范式的缺口**：多数深度解码器（包括 AdaBins、BinsFormer、iDisc 等自适应输出空间方法）**从视觉特征中隐式推断全局尺度**，解码器必须同时从像素中恢复局部几何与全局尺度，跨域时尤为困难。
- **语言类方法的不足**：DepthCLIP、CLIP2Depth、WorDepth 等把语言作为**辅助/后期条件信号**，附加在视觉计算之后，并不真正定义度量输出空间；caption 条件方法还依赖逐图像文本或外部 captioner。
- **本文要解决的问题**：能否用**场景级语义结构作为上游先验**，在稠密预测之前**显式塑造度量输出空间**（深度区间与分箱布局），且无需逐图像文本？
- **核心主张**：让"语义定范围、视觉定像素"——场景语义负责定义度量输出空间，视觉分支在该空间内完成逐像素分配。

## 二、方法论

### 2.1 整体架构（双分支 + 门控融合）
- **语义分支**：冻结 CLIP → 概念路由 → 场景描述符 z → 场景先验模块（SPM）→ 场景条件化深度区间与 bin 中心。
- **视觉分支**：DINOv2-L + 轻量 FPN → 逐像素分配网络（PPAN）→ 逐像素 bin 权重 W 与门控图 g。
- **融合**：`d̂ = g ⊙ d̂vis + (1 − g) ⊙ d̂SPM`，其中 `d̂vis = Σ_k W_k c_k`，`d̂SPM = Σ_k π_k c_k`。
- **关键结构性约束**：SPM **只消费场景描述符 z**，不接触 DINOv2–PPAN 的稠密特征图，因此语义路径是在"定义输出空间"而非"辅助条件化"。

### 2.2 场景描述符与概念路由
- 冻结 **CLIP ViT-B/32**，输入 224²，取 CLS 嵌入 v 与 7×7 patch 网格 P。
- **空间查询**：将 P 的全局均值 + 四个象限均值拼接后投影到学习路由空间。
- **概念库**：65 个 prompt，分两组——20 个场景类型 prompt（室内布局 / 室外驾驶）+ 45 个几何/材质 prompt（深度范围锚点、平面、杂乱度、阴影、边界、光照、室外几何）。
- **路由方式**：概念键在 256 维学习路由空间随机初始化；概念值由冻结 CLIP 文本嵌入初始化、投影到 512 维后变为可学习。查询对概念键做注意力检索，再经线性投影与 v 融合为 **z ∈ R^512**。
- **推理阶段**：**不需要任何逐图像文本、caption 或外部 captioner**，概念库训练后固定。
- **多层级路由**：额外从一个早期块与一个后期块提取 patch token，做同样的五区域池化并与默认 CLIP 统计拼接，兼顾局部纹理与高层场景语义；CLIP 主干全程冻结。
- **正则化**：用熵项与键排斥项鼓励概念使用"有选择性但多样"。

### 2.3 场景先验模块（SPM）
- 轻量 MLP，仅输入 z。
- 输出**保序且被 clamp 到最大有效深度**的区间 `(d_min, d_max)`；K 个 bin 中心在区间内**均匀放置**。
- 同时输出 K 维 logits ℓ，经 softmax 得 π，构成全局先验 `d_SPM = Σ π_k c_k`。
- **实证发现**：π 高度集中，SPM 主要起"场景条件化范围锚点"作用——这直接引出"range-only"消融。

### 2.4 视觉分支
- **DINOv2-L/14**，输入 518²，取块 {5, 11, 17, 23}（通道 1024），轻量 FPN 融合为 256 维多尺度特征；**最后四个 ViT 块与最终 LayerNorm 可训练**，早期块冻结。
- **PPAN**：以 z 为条件对 FPN 特征做 **FiLM 调制 (γ, β)**，小卷积头输出逐像素 softmax 权重 `W ∈ R^{K×h×w}` 与门控 `g ∈ [0,1]`。
- **门控语义**：g→1 偏向稠密视觉估计，g→0 偏向 SPM 先验；作者明确其**不是严格概率意义上的不确定性估计**，而是自适应融合机制。

### 2.5 翻转一致性置信（Flip-consistent confidence）
- 训练时一次前向同时处理原图 x 与水平翻转 x̃，翻转回对齐后得 d̂a、d̂b。
- 一致性目标：`a = exp(−|log d̂a − log d̂b| / τ)`，τ = 0.15；对两张门控图都以 detach 后的 a 做监督（L_cc），权重 λ_cc = 0.1。
- 作用：让门控与"预测稳定性"一致，同时保留按场景/区域自适应。

### 2.6 训练目标
- 总损失：`L = L_depth + λ_spm·L_spm + λ_concept·L_concept + λ_cc·L_cc`。
- `L_depth`：Eigen 风格尺度不变 log 损失 + 残差梯度 + 边缘加权梯度 + 采样像素对序数排序损失 + PPAN 特征上的辅助 SiLog 头。
- `L_spm`：鼓励预测区间覆盖每图有效深度范围、但避免无信息地过宽。
- `L_concept`：保持概念路由选择性与多样性。
- 配置：**K = 64 bins**；NYU 用 10 m cap，KITTI 用 80 m cap，联合训练使 SPM 同时学到紧凑室内范围与远程室外尺度。
