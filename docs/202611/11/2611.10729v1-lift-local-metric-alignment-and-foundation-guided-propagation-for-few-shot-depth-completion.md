## 摘要
少样本深度补全旨在仅使用少量目标域标注，从稀疏测量中恢复稠密度量深度，在标注成本与模型适配之间取得良好平衡。我们提出 LIFT 框架，利用冻结的预训练单目深度估计（MDE）基础模型中的深度先验和特征先验来完成少样本深度补全。具体而言，LIFT 首先在粗网格上估计局部尺度和偏移参数，并将其插值为平滑的稠密参数场，从而提供空间自适应的度量深度初始化。随后，它通过由基础模型特征引导的多尺度深度传播逐步细化该初始化。最后，轻量级残差解码器将多级基础模型特征与传播校正相结合，以细化度量深度。在 NYUv2 和 KITTI-DC 上的大量实验表明，所提方法取得了最先进的少样本性能。源代码即将发布。

## Abstract
Few-shot depth completion aims to recover dense metric depth from sparse measurements using only a small number of target-domain annotations, offering a favorable balance between annotation cost and model adaptation. We propose LIFT, a framework that harnesses both depth and feature priors from a frozen pretrained monocular depth estimation (MDE) foundation model for few-shot depth completion. Specifically, LIFT first estimates local scale and shift parameters on a coarse grid and interpolates them into smooth, dense parameter fields, providing a spatially adaptive metric depth initialization. It then progressively refines this initialization through multi-scale depth propagation guided by foundation features. Finally, a lightweight residual decoder combines multi-level foundation features with propagation correction to refine the metric depth. Extensive experiments on NYUv2 and KITTI-DC demonstrate that our proposed method achieves state-of-the-art few-shot performance. The source code will soon be released.

- **任务定义**：少样本深度补全（few-shot depth completion）旨在仅使用少量目标域 RGB-D 标注，从稀疏深度测量与 RGB 图像中恢复稠密度量深度，在标注成本与模型域适应之间取得平衡。
- **应用价值**：相比单目深度估计（MDE）与立体视觉，深度补全可直接利用稀疏深度观测，在视觉困难场景下提供更可靠的 3D 几何，是自动驾驶、机器人感知与决策的基础任务。
- **范式转变**：随着 Depth Anything、Marigold、Metric3D 等 MDE 基础模型出现，深度补全从“从零设计任务特定模型”转向“利用预训练先验”。现有路线分两类：
  - **训练型**：将预训练 MDE 嵌入专用架构，在大规模合成数据（Hypersim、Virtual KITTI）上训练后迁移，效果好但数据与算力成本高。
  - **测试时适应型**：推理时针对每个样本迭代优化，无需任务训练，但逐样本优化带来显著推理开销，难以满足实时机器人应用。
- **少样本范式的动机**：UniDC、OASIS-DC 等工作探索了少样本深度补全，以兼顾训练成本与推理效率。本文沿此方向，研究如何在有限监督下更好地利用基础模型先验。

  2. **先验利用**：仅用对齐后的深度先验，未能充分挖掘 MDE 基础模型中丰富的语义与几何特征。

## 2. 方法论

### 2.1 核心思想与总体框架

- 采用**冻结的 Depth Anything V2（ViT-B/14）** 作为 MDE 基础模型，输出相对深度图 \(D_r\) 与多级中间特征。
- 框架由三部分组成，逐步将相对深度先验转化为稠密度量深度：
  1. **Grid-based Local Alignment（GLA）**：空间自适应的度量对齐初始化；
  2. **Multi-scale Depth Propagation（MDP）**：由基础特征引导的多尺度深度传播；
  3. **轻量残差解码器**：融合多级特征与传播校正，恢复细粒度细节。
- 仅训练传播与细化模块，MDE 骨干完全冻结；可训练参数仅 **0.763M**。

### 2.2 Grid-based Local Alignment（GLA）

- **目的**：在“空间自适应性”与“参数稳定性”之间取得平衡，避免逐像素独立拟合在稀疏邻域下产生的参数抖动。
- **流程**：
  1. 在粗空间网格上定义查询点集合 \(\Omega_q\)（网格步长为 4 像素）。
  2. 对每个查询点 \(q\)，在图像平面选取 \(k\) 个最近的有效稀疏度量观测 \(\mathcal{N}_k(q)\)（NYUv2 取 \(k=10\)，KITTI-DC 取 \(k=20\)）。
  3. 以距离平方倒数 \(1/\|q-p\|^2\) 为权重，求解加权最小二乘，估计局部尺度 \(s_q\) 与偏移 \(t_q\)，拟合对象为逐图像 min–max 归一化后的相对深度 \(\bar{D}_r\)。
  4. 将粗网格上的 \(\{s_q,t_q\}\) 双线性插值到原图分辨率，得到稠密参数场 \(S\)、\(T\)。
  5. 对齐深度：\(\hat{D}_0 = S \odot \bar{D}_r + T\)。
- **特点**：用少量局部回归构造平滑参数场，既保留空间自适应性，又显著提升稀疏观测下的稳定性与效率（KITTI-DC 仅 0.036 s，NYUv2 仅 0.004 s）。

### 2.3 Multi-scale Depth Propagation（MDP）

- **动机**：GLA 后仍可能存在局部误差与物体级不一致；DINOv2 编码器天然蕴含语义与几何线索。
- **特征准备**：取冻结编码器第 12、9、6、3 层特征，对应四个由粗到细的传播阶段；每层经可训练投影器 \(\phi_l\)（LayerNorm + 1×1 卷积 + GroupNorm + GELU）投影到 64 维，并双线性缩放到对应传播分辨率。
  - 通道 \(\ell_2\) 归一化后的特征 \(\bar{F}^{(l)}\) 用于计算亲和力；
  - 未归一化的 \(Z^{(l)}\) 用于门控与残差解码器。
- **亲和力**：在局部 3×3 邻域 \(\mathcal{N}(p)\) 内，以特征内积的 softmax 计算传播权重 \(w_{pq}^{(l)}\)；不同尺度下 3×3 窗口的有效空间覆盖不同，粗层捕获更大上下文、细层保留局部结构。
- **可学习空间门**：\(g^{(l)} = \sigma(\mathrm{Conv}_{3\times3}(Z^{(l)}, D_{in}^{(l)} - \hat{D}_0^{(l)}))\)，逐像素控制邻居信息更新当前深度估计的程度。
- **传播更新**：\(D_{out}^{(l)}(p) = (1-g^{(l)}(p))D_{in}^{(l)}(p) + g^{(l)}(p)\sum_{q} w_{pq}^{(l)} D_{in}^{(l)}(q)\)。
- **输入构造**：稀疏度量观测始终通过掩码 \(M^{(l)}\) 保留；
  - 最粗层：稀疏深度与下采样的粗度量深度 \(\hat{D}_0\) 融合；
  - 后续层：稀疏深度与上一层传播结果的上采样融合，实现由粗到细的逐级细化。

### 2.4 轻量残差解码器

- **输入**：多尺度特征 \(\{Z^{(l)}\}\)、传播校正 \(D_{out}^{(L)} - \hat{D}_0\)、稀疏深度二值掩码 \(M\)。
- **输出**：残差图 \(R\) 与融合门 \(G\)。
- **最终深度**：\(\hat{D} = (1-G)\odot \hat{D}_0 + G \odot D_{out}^{(L)} + R\)，融合门自适应调节传播深度的贡献，残差补偿剩余细粒度误差（尤其在物体边界附近）。

### 2.5 训练损失

- 总损失：\(\mathcal{L} = \mathcal{L}_{data} + \lambda_g \mathcal{L}_{grad} + \lambda_r \mathcal{L}_{residual}\)。
  - \(\mathcal{L}_{data}\)：L1 与 L2 组合的数据保真损失；
  - \(\mathcal{L}_{grad}\)：相邻有效像素对上的梯度匹配损失，鼓励局部深度变化一致；
  - \(\mathcal{L}_{residual}\)：残差 L1 正则，鼓励残差稀疏。
- 超参数：\(\lambda_g=0.1\)；\(\lambda_r\) 在 1/10/100-shot 与 1-sequence 设置下分别为 5.0、2.0、0.2、0.2。
- 优化：AdamW，学习率 \(10^{-4}\)，权重衰减 \(10^{-3}\)，batch size 为 1。
