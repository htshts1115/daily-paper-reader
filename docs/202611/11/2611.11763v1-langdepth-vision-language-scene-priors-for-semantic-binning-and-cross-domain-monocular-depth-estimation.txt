Abstract. Monocular depth estimation has advanced through large-scale pretraining and strong visual backbones, yet metric depth remains sensitive to scene-level scale. Indoor rooms and outdoor driving scenes occupy very different depth ranges, but most depth decoders infer this global structure implicitly from visual features. We ask whether scene-level semantic structure can instead act as an upstream prior that shapes the metric output space before dense prediction. We present LangDepth ( SemanticBins ), a monocular depth architec-ture that couples strong visual features with a scene-conditioned out-put space. A frozen CLIP encoder and a learnable bank of scene- and geometry-oriented concept keys convert image features into a compact scene descriptor, without requiring per-image text or an external cap-tioner. A Scene Prior Module (SPM) maps this descriptor to a scene-conditioned metric depth interval, providing a global range anchor be-fore dense decoding. In parallel, a DINOv2-L backbone with a lightweight FPN extracts dense visual features, and a Per-Pixel Assignment Network (PPAN) assigns pixels to the scene-prescribed bin structure. A confidence gate fuses the dense visual estimate with the SPM prior. We train LangDepth jointly on NYU Depth V2 and KITTI under a modest supervised depth budget, without web-scale depth supervision or pseudo-labelled depth data. A single model achieves δ1=0 .960 on NYU, 

0.960 on KITTI, 0.887 on DIODE indoor, 0.946 on iBims-1, and 0.861

Beyond aggregate accuracy, the SPM predicts compact indoor ranges and much wider outdoor KITTI ranges, the gate becomes SPM-dominant on outdoor scenes, and perturbing the routed scene con-text causes large drops on KITTI and iBims-1. These results support scene-conditioned output spaces as a practical and interpretable mecha-nism for cross-domain monocular depth estimation.

1 Introduction 

Predicting metric depth from a single RGB image remains a central challenge in computer vision, with applications in robotics, augmented reality, autonomous navigation, and 3D scene understanding. Recent progress has been driven by large-scale pretraining [22], strong visual backbones [13], and carefully designed output spaces [2,12,15]. These models achieve impressive accuracy, but the met-ric scale of a scene is still strongly shaped by global scene context. A compact indoor room, a cluttered office, and an outdoor driving scene occupy very differ-ent depth ranges. Even when the output space is adaptive, most depth decoders infer this global structure from visual features alone. The decoder must there-fore recover both local geometry and global scale from pixels, which becomes especially challenging when evaluation spans domains whose depth ranges and scene layouts differ substantially from those seen during training. 

Scene semantics as an upstream structural prior. Vision-language mod-els such as CLIP [17] encode scene-level information that is directly relevant to metric depth. Recognising that an image depicts a corridor, bedroom, kitchen, street, or long-range driving scene constrains the plausible metric scale before dense prediction begins. However, many language-augmented depth models use language as an auxiliary or late-stage conditioning signal, appended after much of the visual computation has already occurred [9,25–27]. Such conditioning can provide useful cues, but it does not necessarily define the metric output space over which dense visual prediction is performed. Caption-conditioned methods also introduce a dependency on per-image text or an external captioner at in-ference time. The gap we address is therefore one of scene-conditioned output structure : using semantic scene information, derived directly from the image through a reusable concept bank, without per-image text, to shape the depth range and bin layout upstream of dense decoding, so that the visual branch pre-dicts within a scene-adapted metric space rather than a fixed or purely visual one. 

Our approach: scene semantics set the range, vision assigns pixels. 

LangDepth ( SemanticBins ) addresses this gap by coupling a CLIP-derived scene prior with a strong DINOv2 visual decoder. A frozen CLIP image encoder maps each image through a learnable bank of scene- and geometry-oriented concept keys, producing a compact scene descriptor z without requiring per-image text. A Scene Prior Module (SPM) , an MLP that consumes only z,predicts a scene-conditioned metric interval (dmin , d max ) and defines ordered bin centres {ck}Kk=1 within that interval. A DINOv2-L [13] backbone with a multi-scale FPN then extracts dense visual features, and a Per-Pixel Assignment Network (PPAN) assigns each pixel to the scene-prescribed bin structure. The final depth blends the dense visual estimate with the global SPM prior through a learned confidence gate (Fig. 1). Crucially, the SPM does not consume the dense pixel-level features used by the DINOv2–PPAN pathway; the predicted LangDepth: Vision-Language Scene Priors 3

depth interval is determined by the scene descriptor, so the semantic pathway defines the output space rather than merely conditioning it. Our analyses confirm that this structure is not merely cosmetic: the SPM predicts compact indoor ranges ( ≈ 8–10 m) and much wider KITTI ranges, the gate becomes SPM-dominant on outdoor scenes, and perturbing the routed de-scriptor causes large accuracy drops on KITTI and iBims-1. This design leads to three contributions. First, we introduce LangDepth ( SemanticBins ), a scene-conditioned monocular depth architecture in which a CLIP-derived SPM defines a metric depth range before dense visual decoding. Unlike adaptive visual dis-cretisation methods, the predicted output range is derived from a routed scene descriptor rather than from the dense visual feature map itself. Second, we pro-pose a concept-routing mechanism that converts frozen CLIP image features into a compact scene descriptor using learnable scene and geometry concept keys, providing a more effective scene representation for cross-domain depth than a single global CLIP embedding, as confirmed by component ablations on KITTI and DIODE transfer. Third, we combine this semantic range prior with a DINOv2-based PPAN and confidence-gated fusion, enabling domain-adaptive balancing between local visual evidence and global scene-scale infor-mation. Trained jointly on NYU Depth V2 and KITTI under a modest su-pervised budget, LangDepth achieves strong performance across both training domains and transfers to DIODE indoor, iBims-1, and SUN RGB-D. Together, the accuracy results, range analysis, gate statistics, and scene-context pertur-bations demonstrate that scene-conditioned output spaces are a practical and interpretable mechanism for cross-domain monocular metric depth estimation. 

2 Related Work 

2.1 Monocular depth estimation and adaptive output spaces 

Single-image depth has been studied as direct metric regression [5, 6], as multi-task learning with surface normals and semantic segmentation, and more recently as a binned prediction problem in which the network discretises the depth axis and predicts soft per-pixel assignments [2, 3, 12]. Transformer backbones and CRF-style refinement improve local structure, boundaries, and long-range con-text [1, 11, 18, 24], while internal-discretisation methods learn adaptive output representations for depth prediction [15]. LangDepth follows the adaptive-output-space direction, but differs in how the output space is constructed. AdaBins [2] and BinsFormer [12] derive adaptive bin structures from visual feature maps, while iDisc [15] learns an internal discretisa-tion from multi-scale visual representations. In these methods, the global metric range and the dense depth prediction are both inferred from the visual pathway. In contrast, LangDepth predicts the metric interval from a CLIP-routed scene descriptor before dense visual assignment. The SPM does not consume the dense DINOv2–PPAN feature map; it provides a scene-conditioned range anchor, af-ter which the visual decoder assigns pixels within the prescribed bin structure. This separation makes the output space explicitly scene-conditioned rather than 4 R. Ahani Manghotay and J. Liang 

purely visual, enabling domain-adaptive range behaviour that can be inspected and verified empirically. 

2.2 Language and depth 

DepthCLIP [26] and CLIP2Depth [9] were among the first to exploit CLIP’s geometric signal for monocular depth. VPD [27] distils text-to-image diffusion representations for dense prediction. WorDepth [25] is the most directly related recent language-conditioned method: it encodes a scene caption through CLIP’s text encoder and uses an image-conditional sampler to produce a depth map. These works show that language and vision-language representations contain useful geometric and scene-level information. However, language is often used as an auxiliary conditioning signal around an otherwise visual prediction pipeline, and caption-conditioned methods introduce a dependency on per-image text or an external captioner at inference time. In contrast, LangDepth uses language-grounded scene semantics to condi-tion the metric output space itself. Rather than requiring a generated caption, it routes frozen CLIP image features through a reusable bank of scene- and geometry-oriented concept keys, producing a compact scene descriptor. This descriptor is passed to the SPM before dense decoding, where it defines a scene-conditioned depth interval and global range anchor. The visual decoder then as-signs pixels within this scene-prescribed bin structure. Unlike WorDepth, which builds depth prediction around visual features and a sampled language prior, the SPM in LangDepth defines the metric interval explicitly before dense visual decoding. Thus, semantic information is placed upstream of dense prediction, where it can shape the metric scale directly. 

2.3 Web-scale monocular pipelines 

ZoeDepth [4], Metric3D [23], Depth Anything V2 [22], and UniDepthV2 [16] achieve strong performance through large-scale pretraining, pseudo-labelling, or broad multi-dataset training. These systems are important reference points, but operate under substantially larger depth-data and training budgets than our supervised NYU+KITTI setting: ZoeDepth pre-trains on 12 relative-depth datasets, Metric3D uses over 8M images from 11 datasets, Depth Anything V2 uses 595K synthetic images plus 62M pseudo-labelled real images, and UniDepthV2 uses 24 datasets totalling 16M images [4, 16, 22, 23]. We therefore treat them as contextual comparisons. Our focus is distinct: rather than relying on web-scale depth supervision, pseudo-labelled depth data, or broad multi-dataset depth training to implicitly learn scene-scale disambiguation, LangDepth makes the metric range prediction explicit through a scene-conditioned SPM, yielding an inspectable scene-scale mechanism through its range predictions, gate behaviour, and context sensitivity. 2.4 Visual backbones and feature conditioning 

DINOv2 [13] has emerged as a strong self-supervised visual backbone for dense prediction, providing transferable features that are useful beyond the datasets on which a downstream model is trained. Conditioning mechanisms such as FiLM [14] offer a lightweight way to modulate visual features using auxiliary context. In LangDepth, we use these ideas in a separated design: DINOv2 pro-vides dense visual features for per-pixel assignment, while the CLIP-derived scene pathway defines a scene-conditioned metric output space before dense de-coding. 

3 Method 

3.1 Overview 

Given an RGB image I ∈ R3×H×W , LangDepth predicts a metric depth map 

ˆD ∈ RH×W through two complementary branches that meet at a confidence-gated fusion step (Fig. 1). The semantic branch uses CLIP, concept routing, and the Scene Prior Module (SPM) to infer a scene-conditioned metric range and global depth prior. The vision branch uses DINOv2–FPN features and a Per-Pixel Assignment Network (PPAN) to assign each pixel to bins defined inside that scene-conditioned range. Thus, the semantic pathway shapes the output space before dense decoding, while the visual pathway resolves local geometry, object boundaries, and per-pixel depth variation. This design gives scene semantics a structural role in metric depth predic-tion. LangDepth uses a routed CLIP descriptor to define a scene-conditioned range anchor that is shared by the dense prediction branch, rather than treat-ing semantic information only as an auxiliary feature. The final confidence gate then determines, at each pixel, how strongly to rely on the dense visual estimate versus the global scene prior. This is especially useful for mixed indoor–outdoor depth prediction, where the valid metric range can change substantially across scene types. 

3.2 Scene descriptor from CLIP 

We run a frozen CLIP ViT-B/32 [17] on a 224 2 resize of the input. Let v denote the CLS embedding and P the 7 × 7 patch grid. A spatial query is formed by concatenating the global mean and four quadrant means of P and projecting the result into a learned routing space. This query attends over a bank of learn-able concept keys kj ∈ R256 with associated concept values. The concept bank contains 65 prompts in two groups: 20 scene-type prompts covering indoor lay-outs and outdoor/driving scenes, and 45 geometry/material prompts covering depth-range anchors, spatial structure, boundary types, lighting conditions, and outdoor geometry. These prompts were manually curated to cover scene-scale and geometric cues relevant to metric depth across indoor and outdoor domains. 3.3 Multi-layer CLIP routing 

The full model uses multi-layer CLIP routing. Shallow CLIP ViT layers tend to emphasise texture and local appearance, while deeper layers encode higher-level scene semantics. We therefore extract patch tokens from one early and one late intermediate block, apply the same five-region pooling, and concatenate the resulting vectors with the default CLIP statistics before projection. The CLIP backbone remains fully frozen; only the projection and routing weights are trained. This provides the SPM and PPAN with a descriptor that combines local geometric cues and global scene semantics. 

3.4 Scene Prior Module (SPM) 

The SPM is a lightweight MLP that consumes only the scene descriptor z. It predicts a scene-conditioned metric interval (dmin , d max ) within the global valid depth bounds, using a parameterisation that keeps the interval ordered and clamps it to the maximum valid depth. 4 Experiments 

4.1 Setup Training data. We train the final LangDepth model jointly on NYU Depth V2 [19] and KITTI Eigen [7]. NYU provides dense indoor supervision with a 10 m depth cap, while KITTI provides outdoor driving scenes with an 80 m cap. This mixed indoor, outdoor setting lets us evaluate whether the proposed scene-conditioned output space can support both compact indoor ranges and long-range outdoor geometry within a single model. 

Test data. For evaluation, we use NYU Depth V2, KITTI Eigen, the DIODE indoor split [21], iBims-1 [10], and SUN RGB-D [20]. NYU and KITTI evaluate the supervised indoor and outdoor domains used during training, while DIODE indoor, iBims-1, and SUN RGB-D serve as held-out transfer benchmarks without target-domain fine-tuning. Metrics. We report standard monocular depth metrics: AbsRel, RMSE, and threshold accuracies δ1 and δ2. Baselines and scope. We compare against representative monocular depth methods under the closest available protocols. Web-scale foundation models such as Depth Anything V2 [22], ZoeDepth [4], Metric3D [23], and UniDepthV2 [16] use substantially larger depth-data or training budgets and are listed only as contextual references. Full LangDepth uses concept routing, SPM, DINOv2-L, PPAN, and confidence-gated fusion, and is fine-tuned for 20 epochs from a prior NYU+KITTI check-point using AdamW and cosine learning-rate decay on an H100 GPU with 3:1 NYU:KITTI sampling. At inference, it runs at 13.8 FPS at 416 ×544 resolution.

4.3 Component ablations 

We next isolate the contribution of the main architectural components using matched training ablations. The ablation and perturbation studies follow a matched internal evaluation protocol for controlled component comparison; their absolute scores may therefore differ from the main benchmark results in Tab. 1 and should be interpreted only within the same table/protocol. All variants are trained under the same protocol and differ only in the component being ablated. The w/o gate fusion row corresponds to the implementation variant visual_only: it bypasses the final SPM-vision fusion and uses only the PPAN visual estimate, while CLIP concept routing and SPM computation remain active. It should therefore not be interpreted as a no-text model. The ablation results should be interpreted as evidence of architectural bal-ance rather than as a large single-component accuracy gain. 4.5 Scene-context perturbation 

We further test whether the routed scene descriptor is actively used at inference time. For a fixed checkpoint, we intercept the output of the CLIP concept-routing module and perturb the scene descriptor before it is consumed by the SPM and PPAN. All model weights remain fixed. Tab. 5 reports δ1 under several perturbations. Zeroing the context causes severe degradation on KITTI and iBims-1, and wrong-domain context degrades all evaluated datasets. Random, shuffled, and batch-mean contexts also hurt KITTI substantially. These results show that the routed scene descriptor is a structurally active depth-scale signal on KITTI and iBims-1, which rely heavily on the SPM range prior. Zeroing or corrupting the descriptor disrupts the scene-scale anchor and causes large accuracy drops on these benchmarks. 4.6 Discussion and limitations 

The results indicate that LangDepth is best understood as a structured scene-scale mechanism rather than only as an accuracy-oriented architectural change. Strong DINOv2 features already provide robust local geometry, while the pro-posed semantic pathway adds an interpretable way to adapt the metric range across scene domains. This is reflected consistently across the analysis: the SPM separates compact indoor ranges from long-range KITTI scenes, the gate adjusts the balance between local visual evidence and the global range prior by domain, and corrupting the routed scene descriptor causes large drops on KITTI and iBims-1. These findings show that the scene descriptor is actively used for scale prediction and that the predicted output space is meaningfully scene-conditioned. At the same time, SUN RGB-D remains a challenging het-erogeneous benchmark, where scene cues can be noisier; improving robustness on mixed indoor–outdoor scenes is an important direction for future work. 

5 Conclusion 

We presented LangDepth, a monocular depth architecture that uses CLIP-derived scene semantics to define a scene-conditioned metric output space before dense visual prediction. A Scene Prior Module predicts a depth range and global scale anchor from a routed scene descriptor, while a DINOv2–FPN visual branch assigns pixels within the resulting bin structure and a learned gate fuses local visual evidence with the SPM prior. Across NYU, KITTI, and held-out indoor transfer benchmarks, LangDepth provides a strong mixed-domain depth model with an interpretable scene-scale pathway. Range statistics, gate behaviour, and context perturbations show that the semantic branch is structurally active, espe-cially on KITTI and iBims-1. These findings support scene-conditioned output spaces as a practical mechanism for cross-domain monocular depth estimation, while also highlighting the need for more robust scene priors on heterogeneous datasets such as SUN RGB-D.
