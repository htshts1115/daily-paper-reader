tldr: "数字内容创作需要把平面图像分解为可编辑的有序图层，而传统深度定义并不直接服务于这一目标。本文提出Illustrator's Depth，将深度重新定义为逐像素的层级索引，形成离散且全局一致的图层排序，并用分层矢量图数据训练网络从栅格输入预测层次。实验显示该方法在图像矢量化等下游任务上显著优于基线。尽管属于单目逐像素排序预测，但其目标与度量深度估计不同，仅为弱相关。"

## Abstract
We introduce Illustrator's Depth, a novel definition of depth that addresses a key challenge in digital content creation: decomposing flat images into editable, ordered layers. Inspired by an artist's compositional process, illustrator's depth infers a layer index for each pixel, forming an interpretable image decomposition through a discrete, globally consistent ordering of elements optimized for editability. We also propose and train a neural network using a curated dataset of layered vector graphics to predict layering directly from raster inputs. Our layer index inference unlocks a range of powerful downstream applications. In particular, it significantly outperforms state-of-the-art baselines for image vectorization while also enabling high-fidelity text-to-vector-graphics generation, automatic 3D relief generation from 2D images, and intuitive depth-aware editing. By reframing depth from a physical quantity to a creative abstraction, illustrator's depth prediction offers a new foundation for editable image decomposition.

# 论文总结：Illustrator's Depth — 面向图像分解的单目层级索引预测

## 1. 核心问题与整体含义

- **研究动机**：数字创作软件（矢量与栅格工具）普遍以"图层堆叠"组织作品，图层的独立编辑能力是创作流程的核心。但把一张已经压平的图像自动分解为**有序、可编辑图层**，一直是悬而未决的难题。
- **现有方法的空白**：
  - **单目深度估计（MDE）** 预测的是物理深度，对印刷海报、衣服上的图案、阴影等"无真实体积"的内容天然失效；而且插画的图层与物理深度本质不同——阴影常被置于被投射物体之上，非正交平面（如论文中的多米诺骨牌）虽有连续深度梯度却应被映射为离散可排序图层。
  - **全景/实例分割** 只按语义分组，不编码任何全局几何顺序。
  - **分层深度图像（LDI）、多平面图像（MPI）** 产生多采样/多平面深度，而非"每像素一个离散索引"。
  - **透明层分解类工作** 仅在物体级别操作，缺乏细粒度。
  - **矢量化中的分层** 现有方法要么只处理简单输入，要么依赖脆弱的启发式规则。
- **整体含义**：论文提出 **Illustrator's Depth（画师深度）**，把"深度"从物理量重新定义为**创作抽象**——每个像素对应其在数字原稿中的图层索引，形成离散、全局一致的排序，直接服务于可编辑性。这一概念被认为可为下一代智能创作工具提供新基础。

## 2. 方法论

### 2.1 核心概念

- 给定栅格图像 $I \in \mathbb{R}^{H\times W}$，其 illustrator's depth 是每像素到图层索引 $i \in \{1...N\}$ 的映射，反映艺术家可能的构图分层方式。
- 网络输出记为 $D_\theta(I) \in \mathbb{R}^{H\times W}$，训练时视为**连续值**（保留相对顺序），需要时可分箱离散化。

### 2.2 数据集构建（三阶段流程）

- **数据来源**：选用 **MMSVG-Illustration** 数据集，因其图层组织一致且有意义（背景索引最低、前景最高，描边始终在填色之上）。
- **数据清洗（curation）**：
  1. 合并**相邻且 RGB 颜色相同**的图层以简化结构；
  2. 剔除"同色的非相邻图层在最终渲染中重叠"的歧义样本，以提升训练稳定性。
- **真值栅格化**：将每层原始颜色替换为编码其索引的唯一颜色，索引以 base-256 编码到 RGB 三通道：
  $$\big(i \bmod 256,\ \lfloor i/256 \rfloor \bmod 256,\ \lfloor i/256^2 \rfloor \bmod 256\big)$$
  再栅格化得到伪彩色图，并通过 $D(I) = R + 256\cdot G + 256^2\cdot B$ 解码回逐像素整数深度图。该编码可高效表示大量图层且几乎无额外加载开销。

### 2.3 网络与训练

- **骨干**：以 **Depth Pro**（DINO-v2 编码器 + 多尺度 CNN 解码器）预训练权重初始化，利用其从百万级图像中学到的几何/遮挡先验，实现从简单矢量图到复杂艺术图像的泛化。
- **尺度不变损失**：不采用 MDE 常用的视差空间 $1/d$（那会让背景更难学），而是直接预测离散图层索引 $1...N$，对所有图层等权重。为关注相对顺序并适应 $N$ 的取值范围，采用 MiDaS 式归一化：对深度图 $D$ 计算中位数 $m$ 与平均绝对偏差 $s$，归一化 $\hat{d} := (d-m)/s$，再最小化 MAE：
  $$\mathcal{L}_{MAE}(D(I), D_\theta(I)) = |\hat{D}(I) - \hat{D}_\theta(I)|$$
- **训练技巧**：数据增强（颜色抖动、随机反转、随机模糊）、余弦学习率调度、编码器与解码器使用两个不同学习率。
- **后处理**：两种策略——(1) 对深度值分箱/阈值化（用于栅格处理）；(2) RGB 空间聚类后赋予每簇中位深度（用于矢量化），相似颜色与深度的簇可进一步合并以简化 SVG 路径。

## 6. 主要结论与发现

- 物理深度与画师深度是**根本不同的概念**：标准 MDE 模型在插画图层排序上表现很差（Depth Pro Order 0.636、Depth Anything-v2 0.791），而本方法达到 **Order 0.987、MAE 0.12、MSE 0.26**，接近完美。
- 消融显示：深度先验初始化与数据清洗**显著**提升顺序一致性；直接以图层索引（而非视差空间）训练可带来更均衡的前景/背景优化与更优的深度过渡。
- 矢量化方面，本方法在保持与 VTracer 相当的重建保真度（MSE 0.018、SSIM 0.997、LPIPS 0.005）的同时，取得最佳分层质量（Order 0.987、路径数 0.16），优于所有 SOTA。
- 尽管仅用简单 SVG 生成的数据训练，模型可泛化到复杂艺术渲染，支撑文本到矢量生成、自动浮雕生成、深度感知编辑等下游应用。

## 7. 优点

- **概念创新**：将"深度"从物理度量重新定义为面向可编辑性的图层索引抽象，问题定义清晰且实用价值高。
- **数据工程扎实**：基于 SVG 的 base-256 索引编码方案简洁高效；两步清洗（同色相邻合并 + 歧义样本剔除）有效降低了艺术分层主观性带来的噪声。
- **训练策略有针对性**：放弃视差空间、改用尺度不变的索引回归 + MAE，并借力 Depth Pro/DINO-v2 的强先验，兼顾顺序正确性与泛化能力。
- **评测体系贡献**：提出用栅格化预测深度与真值对比来评估矢量图形分层质量，并引入 Order 指标，弥补了该方向缺乏度量的空白。
- **工程可落地**：可直接插入现有矢量化管线（VTracer/Potrace）替换面积排序启发式，全流程仅需数秒。
- **公平性意识**：对基线 VTracer 施加相同的清理步骤，对比条件相对公平。

## 8. 不足与局限

- **训练域受限**：模型完全在 SVG 派生的合成数据上训练，对真实照片、复杂绘画的泛化只有定性展示，**缺乏真值分层因而无法定量评估**。
- **数据清洗可能引入偏差**：剔除"同色非相邻图层重叠"的样本、合并同色相邻层，虽提升稳定性，但也可能使模型在真实存在的复杂/歧义分层上系统性失准。
- **艺术分层本身具有主观性**：不同艺术家对同一图像的分层习惯不同，单一"真值"是否唯一存在争议，评测指标因此带有一定主观假设。
- **定量样本量偏小**：仅 100 张图用于定量分析，统计稳健性有限。
- **依赖强先验骨干**：性能在很大程度上依赖 Depth Pro/DINO-v2 的预训练权重，模型体量与推理依赖较重。
- **失败案例讨论不足**：作者将失败案例分析置于补充材料，正文对方法失效边界的说明较少。
- **应用范围限制**：深度感知编辑"并非旨在与现代表征分割模型竞争"，浮雕与视差效果仍依赖后续模型（如 Stable Diffusion）做 inpainting 补全，整体管线复杂度较高。
