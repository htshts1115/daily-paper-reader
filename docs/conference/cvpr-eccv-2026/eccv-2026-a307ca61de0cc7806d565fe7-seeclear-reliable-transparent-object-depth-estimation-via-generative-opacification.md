evidence: 面向透明物体的单目深度估计，生成式不透明化
tldr: 单目深度估计在透明物体上仍极具挑战，折射与透射难以建模，破坏了深度网络依赖的外观假设，使现有方法产生不稳定甚至错误的深度预测。本文提出SeeClear框架，先定位图像中的透明区域，利用基于扩散的生成式不透明化模块把折射外观转化为几何一致的不透明外观，再将处理后的图像送入现成的深度估计器。该方法使透明物体的单目深度估计变得稳定可靠，为透明材质场景的深度感知提供了新思路。

## Abstract
Monocular depth estimation remains challenging for trans-parent objects, where refraction and transmission are difficult to modeland break the appearance assumptions used by depth networks. As a re-sult, state-of-the-art estimators often produce unstable or incorrect depthpredictions for transparent materials. We propose SeeClear, a novelframework that converts transparent objects into diffusion-generated opaqueimages, enabling stable monocular depth estimation for transparent ob-jects. Given an input image, we first localize transparent regions andtransform their refractive appearance into geometrically consistent opaqueappearances using a diffusion-based generative opacification module. Theprocessed image is then fed into an off-the-shelf monocular depth esti-mator without retraining or architectural changes. To train the opaci-fication model, we construct SeeClear-396k, a synthetic dataset con-taining 396k rendered images across 66k paired transparent-opaque con-figurations. Experiments on both synthetic and real-world datasets showthat SeeClear significantly improves depth estimation for transparentobjects.

# SeeClear 论文详细总结

## 1. 核心问题与整体含义

- **研究动机**：单目深度估计是 3D 重建、导航、机器人操作、抓取、避障以及 real-to-simulation 流程的关键基础。然而，透明物体由于**折射（refraction）和透射（transmission）** 效应，破坏了深度网络依赖的"外观—几何"对应假设，导致现有 SOTA 估计器在透明材质上产生**不稳定甚至错误的深度预测**，并会传播到下游仿真与操作任务（例如透明柜体的碰撞区域重建错误）。
- **现有方法的局限**：
  - 针对透明物体的深度模型微调方法（Depth4ToM、D4RD、DKT 等）依赖**大规模配对透明 RGB–深度数据**，获取困难。
  - 这类方法存在**分布偏移**，且每当深度骨干模型更新（如 Depth Anything 系列迭代迅速），都需要重新微调，**模型依赖性强、可扩展性差**。
- **核心洞察与整体含义**：现代基础深度模型对**不透明物体**具有强泛化性和高精度，只是被透明材质"骗"了。因此论文提出一个自然问题：**能否不修改、不重训练深度模型，而是把透明外观"转换"为不透明外观，从而复用现成深度模型？** 这一视角将透明物体深度估计重新表述为**外观不透明化（opacification）问题**。

## 2. 方法论

### 2.1 核心思想
SeeClear 是一个**即插即用的前端框架（plug-and-play front-end）**，采用两阶段流程：
1. **生成式不透明化**：把透明区域转换为几何一致的不透明图像；
2. **掩码感知合成 + 现成深度估计**：将生成区域与原背景合成后，送入冻结的基础深度模型。

整体流程：输入图像 $I^{tr}$ → 分割得到物体掩码 $M^{seg}$ → 潜扩散模型生成不透明图像 $I^{pred}$ → 掩码细化模块输出融合掩码 $\hat{M}_{ref}$ → 二值合成得 $I^{blend}$ → 现成深度模型输出 $I_d$。

### 2.2 关键技术细节

- **条件潜扩散建模**：
  - 用预训练 VAE 将真值不透明图像编码为 $z_0 = \mathcal{E}(I^{op})$，前向加噪得 $z_t$。
  - 去噪网络输入为**拼接张量**：
    $$z_{input} = \mathrm{Concat}\left(z_t,\ \mathcal{E}(I^{tr}),\ \mathrm{Down}(M^{seg})\right)$$
    即含噪潜变量 + 透明图编码 + 下采样掩码，掩码提供显式空间引导，保留几何、去除折射畸变。
- **CLIP 语义条件**：因透明物体与其漫反射对应物通常属同一语义类别，采用 **CLIP 图像编码器**，仅保留 **class token**（patch token 会泄漏背景局部外观），经轻量 **Transformer Mapper** 投影到交叉注意力条件空间得到条件 $c$。明确避免使用深度/法线等几何条件（对透明物体不可靠）。
- **训练目标**：
  - 标准 DDPM 去噪损失：$\mathcal{L}_{LDM} = \mathbb{E}\|\epsilon - \epsilon_\theta(z_{input}, c, t)\|_2^2$；
  - 补充**感知损失**（像素空间多级 VGG 特征）：
    $$\mathcal{L}_{LPIPS} = \mathrm{LPIPS}\left(\mathcal{D}(z_{pred}) \odot M^{seg},\ I^{op} \odot M^{seg}\right)$$
    仅在**低噪声时间步**施加（高噪声时解码结果偏离干净图像，会降低样本多样性）；掩码 $\odot$ 将监督限制在物体区域。
  - 总损失 $\mathcal{L} = \mathcal{L}_{LDM} + \lambda \mathcal{L}_{LPIPS}$。
- **掩码增强**：训练时在物体边界附近随机增/减小几何形状（圆、矩形），提升对自动分割掩码不完美的鲁棒性。
- **掩码细化模块（MRM）**：
  - 轻量全卷积网络：3 个 3×3 卷积 + 1×1 投影层，GroupNorm + SiLU。
  - 输入：不透明图 $I^{op}$、透明图 $I^{tr}$、增强后的 GT 掩码；输出软融合掩码 $M_{ref}\in[0,1]$，推理时二值化。
  - 损失：$\mathcal{L}_{refine} = \mathcal{L}_{BCE} + \mu\sum M_{ref}(1-M_{ref})$，第二项惩罚中间值，促使物体/背景分离更自信。
  - 最终合成：$I^{blend} = \hat{M}_{ref} \odot I^{pred} + (1-\hat{M}_{ref}) \odot I^{tr}$。
  - MRM 用于解决 VAE 编码-解码导致的非物体区域模糊/色偏、潜空间 inpainting 的边界光晕，以及像素级硬粘贴的接缝伪影。

### 2.3 数据构建（SeeClear-396k）
- **失败模式驱动的构建策略**（受 Booster 启发），覆盖三类挑战：非朗伯线索畸变（折射、无纹理玻璃）、深度定义歧义（玻璃表面 vs 透过玻璃可见的背景）、复杂场景结构（细边界、多层、透明-不透明遮挡）。
- 每个配置**渲染配对**的透明图 $I^{tr}$（玻璃材质）与不透明图 $I^{op}$（固定颜色 Lambertian 漫反射，如 #E7A034FF），几何、相机位姿、光照完全一致，仅改变外观。
- 规模：11 种日常透明物体 × 10 个室内场景 = 110 个物体-场景单元；每单元确定性采样 10 个相机视角、2 种光照（顶灯/随机）、6 种各向异性形变模式 × 5 个幅度；每单元 600 组图像。合计 **396,000 张渲染图**，含绝对深度（OpenEXR）、相对深度、法线、物体掩码（PNG）。

## 6. 主要结论与发现

- **生成式不透明化显著提升透明物体深度估计**：对 DA3，RMSE 从 24.03 mm 降至 21.45 mm（↓10.7%）；对 MoGe-2，RMSE 从 56.83 mm 降至 26.62 mm，δ1.025 从 5.63% 提升到 42.75%。
- **零样本优于/媲美专用方法**：SeeClear(DA3) 在 ClearGrasp 上 RMSE 低于 Depth4ToM、D4RD、MODEST、GenPercept、Marigold、GeoWizard；在 TransPhy3D 上 SeeClear(MoGe-2) 的 AbsRel（0.012）甚至优于在评测集上微调过的 DKT（0.014）。
- **不损伤非透明区域**：在 All 和 Other 区域，SeeClear(MoGe-2) 全指标最优，说明改进透明区域的同时不退化背景预测。
- **跨类别泛化**：在含门、镜子、挡风玻璃、洗衣机等训练外类别的 Booster 上，ToM MAE 从 18.94 mm 降至 12.85 mm（↓32.2%）。
- **消融结论**：掩码定位优于 BBox/Point；CLIP class token 优于 CLIP full 与 DINOv2 变体；MRM + 二值合成优于去除 MRM 或无 blending；纯色填充甚至比未修改的 DA3 基线更差，验证了生成式不透明化的必要性。

## 7. 优点

- **思路新颖且解耦清晰**：把透明深度问题重新表述为"外观不透明化"，将外观转换与深度推断解耦，使方法**即插即用、无需重训练、无需架构修改**，可随深度基础模型迭代而平滑升级。
- **问题定位精准**：抓住"透明物体违反深度网络外观假设"这一本质，而非在深度模型内部硬补透明数据。
- **数据构建系统化**：SeeClear-396k 采用失败模式驱动的配对渲染，规模大（39.6 万张）、几何/光照严格对齐，为监督不透明化提供了高质量监督。
- **条件设计有据**：用 CLIP class token 而非 patch token（避免背景泄漏）、避免用不可靠的深度/法线条件、LPIPS 仅用于低噪声时间步，都体现了细致的工程考量。
- **实验客观性强**：明确区分零样本与微调方法，在 DKT 未见过的数据集上额外对比；双骨干验证通用性；消融覆盖定位、编码器、合成、不透明化四个关键环节。
- **泛化性验证扎实**：Booster 的跨类别实验证明对训练分布外透明物体仍有效。

## 8. 不足与局限

- **明确的失败模式**：
  - 大面积、近乎不可见的玻璃窗格（仅部分可见边框）因上下文线索有限，可能**无法完全不透明化，导致深度泄漏**。
  - 当输入掩码严重误定位时，不透明化内容会被合成到错误区域。
- **依赖前端分割质量**：方法效果受透明物体分割（Trans4Trans + SAM 3）的准确性制约，分割失败会直接传播。
- **推理速度较慢**：单张图像约

7.65 秒（含扩散不透明化采样与一次深度前向），相比纯判别式方法（如 DA3、MoGe-2 的单次前向，通常为数十至数百毫秒）慢一个数量级以上，难以直接满足实时机器人操作、闭环抓取等对时延敏感的场景。虽然可通过减少采样步数、蒸馏或缓存来加速，但论文未做延迟-精度的权衡分析。
- **训练数据全为合成渲染，存在 sim-to-real 域差**：SeeClear-396k 虽然规模大、对齐严格，但透明材质、光照、相机噪声均来自渲染管线，真实世界的反射、污渍、运动模糊、传感器噪声等未覆盖，可能限制不透明化在真实场景中的外观真实感，进而影响深度对齐质量。
- **依赖前置分割管线**：方法效果强依赖 Trans4Trans + SAM 3 的掩码质量，而论文明确指出掩码误定位会导致不透明化内容被合成到错误区域；这使整体系统的鲁棒性受限于外部模块，且引入额外依赖与推理开销。
- **扩散生成的不确定性**：不透明化是生成式过程，存在随机性，不同采样种子可能产生外观差异，从而影响深度估计的稳定性；论文未系统评估多次采样的方差或不确定性传播。
- **深度定义的固有歧义未被完全解决**：对玻璃而言，"表面深度"与"透过玻璃看到的背景深度"在物理上均有意义，论文以固定颜色 Lambertian 物体作为不透明化目标，隐含选择了"物体表面"语义；但真实应用中若需要背景深度，该监督目标可能不匹配。
- **材质多样性覆盖有限**：训练仅用固定颜色漫反射替代外观，未覆盖有色玻璃、磨砂/半透明玻璃、镀膜镜面等，这些在 Booster 的镜子、挡风玻璃类别上虽有效果，但属于零样本外推，缺乏针对性训练。
- **下游任务验证不足**：论文以深度指标为主，虽在动机中强调抓取、仿真、避障，但未给出实际下游任务（如透明物体抓取成功率、real-to-simulation 重建误差）的端到端评估，难以直接量化对机器人应用的收益。
- **基线公平性的边界**：DKT† 虽在评测集上微调，但不同方法的训练数据规模、骨干、对齐协议仍不完全可比；且部分基线（如 Marigold、GeoWizard）为通用扩散模型，并非透明专用，比较时优势来源（透明专用 vs 更强先验）未完全剥离。

## 9. 启示与可扩展性

- **范式可迁移**：将"外观欺骗深度模型"的问题统一转化为"外观规范化/不透明化"问题，这一思路可推广到其他破坏外观—几何假设的因素，如镜面反射、强透明液体、水下成像、雾/烟遮挡等。
- **与基础模型协同演进**：由于深度骨干保持冻结，SeeClear 可随 Depth Anything、MoGe 等基础模型的迭代而"免费升级"，只需替换后端即可，具备良好的可持续性。
- **数据构建方法论可复用**：失败模式驱动的配对渲染策略（同一几何/光照下仅替换材质外观）为其他"配对监督稀缺"任务提供了可复用的数据合成范式。
- **工程上可优化**：未来可通过少步蒸馏、一致性模型、潜空间缓存或按需触发不透明化（仅在检测到透明区域时调用）来降低时延，推动方法向实时机器人落地。

## 10. 总体评价

SeeClear 的核心贡献不在于提出新的深度网络结构，而在于**重新表述问题**：把透明物体深度估计从"训练更强的深度模型"转向"让现成深度模型看得懂"。这一解耦视角带来了即插即用、免重训、可随基础模型升级的工程优势，并以系统化的 39.6 万张配对渲染数据与细致的条件设计（CLIP class token、掩码感知 LPIPS、掩码细化模块）支撑了生成式不透明化的有效性。实验在 3+1 个数据集、双骨干、9 个基线、8 组消融上验证了零样本条件下对透明区域的显著改进且不损伤非透明区域，跨类别泛化也较扎实。其局限主要在于推理时延、合成到真实的域差、对前端分割的依赖以及下游任务验证的缺失。总体而言，这是一篇**思路清晰、工程扎实、定位准确**的工作，为透明物体感知提供了一条与深度基础模型解耦、可持续演进的技术路线，但距离实时、真实场景的机器人闭环应用仍有优化空间。
