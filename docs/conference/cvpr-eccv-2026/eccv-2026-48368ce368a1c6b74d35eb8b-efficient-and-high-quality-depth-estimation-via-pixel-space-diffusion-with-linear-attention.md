## Abstract
This work presents Lapis, a linear-attention-based pixel-space generative framework that achieves efficient and high-fidelity depthestimation with one-step diffusion. While generative frameworks havesignificantly advanced monocular depth estimation with superior detailfidelity, the O(N 2 ) complexity of standard attention and the multi-stepdenoising process introduce prohibitive computational costs when scal-ing them to high-resolution image applications. Although linear atten-tion and one-step prediction are intuitively viable, directly applying themleads to poor structural consistency, detail loss, and noise. Lapis recti-fies these limitations through a coarse-to-fine hierarchy. Specifically, aPatch-level Consistency Module restores structural coherence by inte-grating semantic and spatial priors. Subsequently, a Pixel-level Refine-ment Module recovers sharp geometric boundaries via skip-connection-based pixel correspondence. Furthermore, to mitigate sampling noise in-herent in one-step diffusion, we leverage the manifold assumption andadopt a direct x-prediction strategy to target the clean data manifold.Extensive evaluations on multiple benchmarks demonstrate that Lapisconsistently achieves state-of-the-art (SOTA) accuracy and boundarysharpness across various resolutions, reducing inference latency by upto 7.6× at 1080P and 10.9× at 1440P resolution compared to previousSOTA generative models.

- **核心矛盾**：高分辨率应用需要像素级精细几何，但现有生成式框架面临**保真度 vs 效率**的根本权衡：
  - 潜空间 U-Net 路线（Marigold、Lotus、GenPercept 等）受 VAE 瓶颈的不可逆信息损失限制，且难以建模高分辨率下的长程依赖；

  - 两条路线都还需**多步迭代去噪**，进一步放大开销。
- **朴素方案失败**：直接把线性注意力 + 一步采样搬到像素空间 DiT，会造成两类退化——**patch 级结构错位**（破坏全局一致性）与**像素级保真损失**（细粒度几何丢失）；同时常用的 v-prediction 在单次前向中极不稳定，产生噪声污染的结果。
- **整体含义**：论文提出 **Lapis**，首个基于线性注意力的像素空间生成式深度框架，在单次前向（one-step）内完成高保真深度重建，扩散过程保持 **O(N)** 复杂度，为高分辨率 3D 感知提供"生成质量 + 判别式速度"的折中方案。

## 2. 方法论

### 2.1 核心思想
- 在**像素空间**直接做扩散，不使用 VAE 潜编码器；用**线性注意力**替换 DiT 中全部多头自注意力（MSA），实现线性复杂度。
- 用**由粗到细（coarse-to-fine）层次**修补线性化带来的保真度缺口：PCM 负责 patch 级全局结构一致性，PRM 负责像素级高频细节恢复；再用 **x-prediction** 替代 v-prediction 稳定一步采样。

### 2.2 一步像素空间扩散（flow matching 形式）
- 输入：拼接的含噪深度图与条件图像 c，输出干净深度图。
- 线性噪声调度：`x_t = (1-t)·x_0 + t·ε`，t 采样于 [τ, 1]，τ≈0.05（避免 t→0 的数值问题）。
- 网络直接预测干净数据：`x̂_0 = x_θ(x_t, t, c)`。
- 训练损失：
  - **速度损失**：目标速度 `v_t = dx_t/dt = ε - x_0`，预测速度 `v̂_t = (x_t - x̂_0)/t`，用 L2 均方误差监督；
  - **多尺度梯度匹配损失**：在 x 空间对多个分辨率尺度 s 计算空间梯度 ∇_s 的 L1 差异，提升边界锐度；
  - **总损失**：`L_total = L_velocity + λ_grad · L_grad`，λ_grad = 1.5。
- 深度归一化：对 log 深度 `d̂ = log(d+0.01)` 按每图 2%/98% 分位数归一化到 [-0.5, 0.5]，并重缩放至单位方差。

### 2.3 线性化 Transformer 与"保真度缺口"
- 标准注意力 `softmax(QKᵀ/√d)V` 为 O(N²d)；线性注意力用非负核 ϕ(·) 近似 softmax，利用矩阵乘法结合律，先计算全局上下文 `Σ_j ϕ(K_j)ᵀV_j ∈ R^{d×d}` 与归一化项，复杂度降为 O(Nd²)（即 O(N)）。
- 核函数取 `ϕ(x) = elu(x) + 1`。
- 论文识别出线性化在稠密回归任务中的双重退化：低秩核导致 patch 级结构错位；逐层线性平均导致像素级细节渐进稀释。

### 2.4 Patch-level Consistency Module（PCM）
- **全局关系一致性**：
  - 用冻结的 DINOv2（经 MoGe-2 微调的 DINOv2-Large）提取语义描述子 z，经门控机制精炼：`ẑ = W_o(W_v·z̄ ⊙ σ(W_g·z̄))`（σ 为 sigmoid，⊙ 为逐元素乘）。
  - 将 ẑ 与时步嵌入 t 融合，通过扩展的 **AdaLN-Zero** 调制线性注意力层与 FFN 层：`α ⊙ f(LayerNorm(s) ⊙ (1+γ) + β)`，调制参数 (γ, β, α) 由 MLP 从 ẑ+t 回归。目的是把语义先验作为全局几何布局的"锚点"，使线性骨干不必独自承担全局空间协调。
- **局部空间连续性**：在 FFN 中插入残差式 3×3 深度可分离卷积（**ConvFFN**）：`s' = SiLU(Linear(s))`，`s_out = Linear(SiLU(DWC(s')) + s')`，为相邻 token 引入局部归纳偏置，抑制网格伪影与 patch 间断。

### 2.5 Pixel-level Refinement Module（PRM）
- 目的：弥补 token 离散表示回到连续像素空间时的保真度缺口，恢复尖锐几何边界。
- 输入构造：原始输入 y 拼接可学习 patch 级位置编码，经 MLP 得 `y' ∈ R^{D_pixel×H×W}`。
- token→像素桥接：最后一个 DiT block 的 token `s ∈ R^{N×D}` 先 reshape 为 `R^{D×h×w}`，经 MLP 得 `R^{(D_pixel·p²)×h×w}`，再用 **PixelShuffle** 上采样为 `s_pixel ∈ R^{D_pixel×H×W}`（p 为 patch size，H=h·p、W=w·p）。
- 解码：PRM 由若干 Pixel Refiner block 组成，每个 block 用 AdaLN-Zero 调制的 ConvFFN 解码，调制参数 (γ, β, α) 由 s_pixel 经 MLP 回归；最后由 DiT 线性预测头输出深度图 `d ∈ R^{H×W}`。
- 实现细节：主模型用 M=3 个 block、D_pixel=32；消融实验中降为 M=2、D_pixel=16。

### 2.6 x-prediction 策略
- 依据**流形假设**：自然几何数据位于低维流形上，而含噪量不在该流形上；因此直接预测干净数据 x_0 比预测 v 更贴合干净数据流形。
- 在单步前向约束下，v-prediction 在像素空间严重不稳定；x-prediction 可有效抑制采样噪声，产生空间更连贯的深度图（Fig. 6 定性对比支持）。
