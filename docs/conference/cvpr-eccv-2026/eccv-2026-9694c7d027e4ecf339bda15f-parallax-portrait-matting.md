evidence: 利用连拍视差的双眼人像抠图
tldr: 单图抠图在前景背景均富纹理时高度病态，现有方法依赖绿幕或偏振光等特殊采集。本文提出视差人像抠图，利用轻微视角变化拍摄的第二帧图像，从连拍中自然获得前后景视差与互补观测。方法先估计三分图和前后景运动，再据此构建抠图求解。实验表明该双帧方法在困难纹理场景下优于单图方法，为手机连拍人像抠图提供实用方案。

## Abstract
Image matting is highly ill-posed, especially when both theforeground and background are richly textured. While single-image mat-ting methods learn strong priors from data, they often struggle on thesechallenging cases. Existing approaches improve results by requiring ad-ditional signals such as green screens, polarized lighting, or clean back-ground images, but these typically rely on specialized capture setups.We present Parallax Portrait Matting, a practical two-frame mattingmethod that uses a second image captured with slight viewpoint change.Such a setting arises naturally in burst photography, where small cameramotion induces foreground-background parallax and provides comple-mentary observations for matting. Our pipeline estimates trimaps andforeground/background motion, then constructs aligned views for pre-diction. To handle imperfect motion estimation, the network uses thebackground-aligned pair for direct fusion and the foreground-aligned cuethrough cross-attention for error compensation. Experiments show thatour method recovers finer details and more accurate foreground colorsthan strong single-image matting baselines on challenging portrait cases.

# 《Parallax Portrait Matting（视差人像抠图）》论文总结

## 1. 核心问题与研究动机

- **问题本质**：图像抠图（Image Matting）需将图像分解为前景 $F$、背景 $B$ 与透明度 $\alpha$，满足 $I = \alpha F + (1-\alpha)B$。该问题高度病态：单张彩色图像仅有 3 个约束却有 7 个未知量。
- **单图方法困境**：现代方法（如 MODNet、MatteFormer、生成式先验方法）虽从数据中学习强先验，但当**前景与背景都纹理丰富**时仍难以可靠分离，尤其在发丝、半透明边界等区域。
- **现有附加信号方案的局限**：绿幕、偏振光、相机阵列、焦距堆栈、干净背景图等虽能改善结果，但都依赖**专用硬件或受控拍摄流程**，难以用于日常摄影。
- **本文切入点**：提出 **Parallax Portrait Matting（PPM）**，利用**轻微视角变化的第二帧图像**。这一设定在手机连拍（burst photography）中天然存在——相机微小移动使前景（离相机更近）与背景产生不同视运动（视差），为抠图提供互补约束，无需任何专用设备。

## 2. 方法论

### 2.1 问题建模与核心思想
- 设有基帧 $I_1$ 与另一帧 $I_0$，二者因前后景视差而不同。定义前景运动场 $M^F_{1\to0}$ 与背景运动场 $M^B_{1\to0}$：
  $$\alpha_0 = M^F_{1\to0}(\alpha_1),\quad F_0 = M^F_{1\to0}(F_1),\quad B_0 = M^B_{1\to0}(B_1)$$
  代入得 $I_0 = M^F_{1\to0}(\alpha_1 F_1) + \big(1 - M^F_{1\to0}(\alpha_1)\big) M^B_{1\to0}(B_1)$。
- **关键洞察**：若运动估计正确，第二帧构成对同一组未知量的额外约束；但当前景与背景运动相同时约束线性相关，故需要真实视差。
- **核心设计原则（非对称利用运动）**：背景通常离相机更远、视运动更平滑、对齐更可靠 → 作为**主输入直接像素级融合**；前景运动因局部非刚性（发丝等）难以准确估计 → 仅作为**含噪辅助线索，通过交叉注意力在特征空间补偿**。

### 2.2 流水线技术细节

- **Trimap 估计**：用 BiRefNet 生成二值前景掩码，再分别腐蚀/膨胀 100 像素，得到宽 200 像素的不确定带（足以覆盖分割模型误差）。
- **运动估计**：用 GMFlow 估计两帧光流；因不确定区域内遮挡复杂、光流不可靠，采用**局部平滑假设**，将不确定区域的光流替换为最近邻确定区域的值（前景、背景分别处理）。
- **对齐视图构建**：
  - 背景对齐图 $I^B_{0\to1} = M^B_{0\to1}(I_0)$：仅前景区域与基帧不同，且能揭示原被遮挡的背景（dis-occlusion 提供额外上下文）。
  - 前景对齐图 $I^F_{0\to1} = M^F_{0\to1}(I_0)$：前景固定、背景移位，提供"前景是什么"的强信号。
- **双分支网络架构**：
  - **主分支（背景对齐）**：输入基帧 $I_1$、背景对齐帧 $I^B_{0\to1}$、trimap $Tr_1$，直接预测基帧的前景 $F_1$ 与 $\alpha_1$。
  - **辅助分支（前景对齐）**：输入 $I^F_{0\to1}$、伴随帧 $M^F_{0\to1}(M^B_{1\to0}(I_1))$、扭曲 trimap $M^F_{0\to1}(Tr_0)$，预测前景对齐视图的 alpha 与前景。
  - 两分支在解码阶段通过 **cross-attention** 交互，建立特征空间的软对应，抑制错误对齐区域；两分支共享权重。
- **训练目标**：
  - Alpha 损失：对"软"像素（$0<\alpha<1$）与"硬"像素（$\alpha=0$ 或 $1$）分别归一化加权的 L1 损失 $L_{sep}$；另加 Laplacian 损失 $L_{laplacian}$ 与梯度惩罚 $L_{grad}$。
  - 前景颜色损失：预测预乘前景 $\alpha F$，用合成损失 $L_{composition} = \|I_i - (\alpha_i F_i + (1-\alpha^{gt}_i)B^{gt}_i)\|$ 监督。
  - 总损失：$L_{total} = L_{sep} + L_{laplacian} + L_{grad} + L_{composition}$。
- **Patch 式训练/推理**：以基帧 trimap 提取 448×448 patch（覆盖所有不确定区域），相邻 patch 重叠 224 像素，融合时用高斯窗平滑过渡。

## 6. 主要结论与发现

- 相机微动引入的前后景视差是**实用且信息量充足**的抠图线索，无需专用硬件。
- 在所有合成测试集上，方法在 SAD、MSE、Conn、Grad 及前景颜色 MSE 上**全面优于**单图与视频抠图基线；前景颜色精度提升尤为显著（相对最佳基线**降低 35–45% 误差**），对下游合成任务至关重要。
- 消融证实：背景对齐与前景对齐线索**互补而非冗余**——去掉背景对齐主要损害细节恢复，去掉前景对齐主要造成前后景混淆。
- 即使注入额外运动噪声，方法仍优于单图基线，验证了"前景对齐只作特征级软提示"的设计合理性。
- 真实场景下能恢复比 Adobe Photoshop、Remove.bg 更精细的结构（如发丝），且模型**仅用合成数据训练**即可泛化到真实拍摄。

## 7. 优点与亮点

- **问题设定实用**：将"连拍第二帧"这一日常可得的信号转化为抠图约束，摆脱绿幕/偏振等专业采集依赖，落地性强。
- **非对称融合设计优雅**：依据"背景运动可靠、前景运动不可靠"这一物理不对称性，分别采用像素级直接融合与特征级 cross-attention 补偿，避免了简单拼接对齐图的脆弱性。
- **优雅退化（graceful degradation）**：主分支本身构成强单图预测路径，视差弱或对齐差时自然回退到单帧行为，不会灾难性失败；同帧输入实验验证了这一点。
- **前景颜色预测质量高**：显式预测预乘前景并用合成损失监督，缓解了多数抠图方法前景色被背景污染的问题。
- **与闭源商业方案的正面对比**展现出细节优势，说服力较强。
- **架构与预训练匹配**：选用 CroCo 跨视图补全预训练权重，与双视图对应预测任务天然契合（作者也指出这只是初始化选择，非必需）。

## 8. 不足与局限

- **作者自述局限**：
  - 运动估计与网络训练**解耦**，无法联合优化。
  - 帧间运动**更大或更复杂**时性能可能下降。
  - 在**极度模糊的场景**（如低光、主体与背景在整个连拍中几乎不可分）中视差不足以解决问题。
- **实验覆盖不足**：
  - 真实数据**仅有定性结果**，缺少真实场景的定量评测，泛化能力证据偏弱。
  - 全部训练与定量测试基于合成数据（伪前景色标注由 layer-diffusion 生成、alpha 标注不完美），存在**合成-真实域偏差**风险。
  - 未报告训练时长、推理速度/时延等实用指标，难以评估移动端部署可行性。
- **应用限制**：
  - 依赖现成 trimap（BiRefNet 200M）与光流（GMFlow）模块，全流程计算开销较大。
  - 对"主体基本静止 + 明显前后景视差 + 两帧外观一致（曝光/白平衡/色调）"有隐含假设，剧烈主体运动、风、发丝飘动会引入残余运动误差。
  - 运动估计在不确定区域的最近邻修补属于近似，边界处可能残留伪影。
