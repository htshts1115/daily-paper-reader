## Abstract
We introduce Illustrator's Depth, a novel definition of depth that addresses a key challenge in digital content creation: decomposing flat images into editable, ordered layers. Inspired by an artist's compositional process, illustrator's depth infers a layer index for each pixel, forming an interpretable image decomposition through a discrete, globally consistent ordering of elements optimized for editability. We also propose and train a neural network using a curated dataset of layered vector graphics to predict layering directly from raster inputs. Our layer index inference unlocks a range of powerful downstream applications. In particular, it significantly outperforms state-of-the-art baselines for image vectorization while also enabling high-fidelity text-to-vector-graphics generation, automatic 3D relief generation from 2D images, and intuitive depth-aware editing. By reframing depth from a physical quantity to a creative abstraction, illustrator's depth prediction offers a new foundation for editable image decomposition.

# 《Illustrator's Depth: Monocular Layer Index Prediction for Image Decomposition》论文总结

## 1. 核心问题与研究动机

- **背景**：数字创作软件（矢量与栅格）普遍以「图层堆叠」组织作品，图层化是独立编辑各构图元素的基础。图层顺序与场景中物体的物理远近天然相关（近处遮挡远处）。
- **问题**：现有单目深度估计（MDE）与全景/实例分割模型**无法**把插画分解为「可用且有序」的图层，原因有三：
  - 插画图层与物理深度本质不同：阴影等元素可被放在被投射物体**之上**；多米诺骨牌这类存在物理深度梯度的非正交平面仍会被映射为离散可排序图层。
  - 插画通常印在平面介质（书页、海报、绘画、T恤图案）上，MDE 模型被显式训练去**忽略**这类"无真实体积"的内容。
  - 分割模型（如 SAM 2）只输出掩码、**不编码任何相对顺序**；图层深度需要「分割 + 全局排序」的混合。
- **整体含义**：作者提出 **Illustrator's Depth（插画师深度）**——把"深度"从物理量重新定义为一种**面向可编辑性的创作抽象**，即每个像素对应其数字原型中的图层索引，从而为图像分解提供新的基础范式。

## 2. 方法论

### 2.1 核心思想
- 定义从输入栅格图像 $I \in \mathbb{R}^{H\times W\times 3}$ 到**逐像素图层索引**的映射 $i \in \{1,\dots,N\}$，刻画艺术家可能的构图分层方式；该映射可直接用于编辑。
- 网络输出为连续值 $D_\theta(I)\in\mathbb{R}^{H\times W}$（保留相对顺序，便于后续分箱离散化）。

### 2.2 数据集构建（三阶段）
1. **数据获取**：选用 **MMSVG-Illustration**（图层组织一致：背景低索引 → 前景高索引，描边始终位于填充之上）。
2. **数据清洗**：
   - 合并**相邻且同色**的图层；
   - 剔除**非相邻同色图层在渲染图中重叠**的歧义样本，以提升训练稳定性。
3. **真值栅格化**：把每层原色替换为编码图层索引的"伪彩色"（base-256 编码）：
   - $(i \bmod 256,\ \lfloor i/256\rfloor \bmod 256,\ \lfloor i/256^2\rfloor \bmod 256)$
   - 反解：$D(I)=R+256G+256^2B$，可高效表示大量图层。

### 2.3 网络与训练
- **骨干**：基于 **Depth Pro**（DINO-v2 编码器 + 多尺度 CNN 解码器），用其预训练权重初始化，以继承几何/遮挡先验，从而从简单矢量图泛化到复杂艺术图像。
- **损失**：不同于 MDE 在视差空间 $1/d$ 学习，本文**直接预测离散图层索引** $1,\dots,N$（各层等权，背景与前景难度相当）；为聚焦**相对顺序**并适应 $N$ 的大范围，采用 MiDaS 式尺度不变归一化：对深度图 $D$ 计算中位数 $m$ 与平均绝对偏差 $s$，令 $\hat d=(d-m)/s$，再用 MAE 损失
  $$\mathcal{L}_{\text{MAE}}(D(I),D_\theta(I))=|\hat D(I)-\hat D_\theta(I)|$$
- **训练设置**：数据增强（颜色抖动、随机反转、随机模糊）+ 余弦学习率调度；编码器与解码器使用两个不同学习率。
- **后处理**（可选）：
  - 深度值分箱/阈值分割（用于栅格处理）；
  - RGB 空间聚类后赋予各簇中位深度，并可进一步合并相似颜色与深度的簇（用于矢量化，简化路径）。

## 3. 实验设计

### 3.1 数据集与场景
- 主数据集：**MMSVG-Illustration**，清洗并栅格化至 $1536\times1536$，约 **100K** 一致分层的 SVG 图像，**80% 训练 / 20% 评估**；定量分析随机抽取 **100 张**图像（补充材料另报告 SVGX-Core 数据集与最近邻分析）。
- 泛化场景：插画、绘画、部分真实照片（T恤、海报、日历等）。

### 3.2 评价指标
- **层级/深度预测**：Order（随机采样像素对，统计相对顺序正确率）、MAE、MSE（预测前统一做尺度不变归一化）。
- **矢量化**：Order / MAE / MSE（分层质量）、路径数误差 $|N-\tilde N|/N$（紧凑性）、RGB 空间 MSE、SSIM、LPIPS（视觉保真度）。

### 3.3 对比方法
- 深度预测：**Depth Pro**、**Depth Anything-v2**。
- 矢量化：启发式 **VTracer+Potrace**、**Less Is More**；优化式 **LIVE**；数据驱动/LLM 式 **StarVector**、**OmniSVG**。

### 3.4 应用实验
- 图像矢量化（替换 VTracer 的面积排序启发式为预测层序 + 颜色聚类 + 修补 + Potrace）。

## 6. 主要结论与发现

- 物理深度与插画师深度是**根本不同的概念**：MDE 模型（Depth Pro Order 0.636、Depth Anything-v2 0.791）在插画层序上表现很差，本文模型达到 **Order 0.987、MAE 0.12、MSE 0.26**，大幅领先。
- 矢量化中，本文管线在**分层准确性与重建保真度上同时达到 SOTA**（Order 0.987、MAE 0.46、MSE 2.09、路径数误差 0.16、SSIM 0.997、LPIPS 0.005），优于启发式、优化式与数据驱动基线；而基线呈现"重建好但分层差"（VTracer、Less Is More）或"分层尚可但重建失败"（StarVector、OmniSVG，RGB MSE 高达 9~10×10⁻²）的两极分化。
- 消融表明：**Depth Pro 初始化**与**数据清洗**显著提升层序一致性；**直接以图层索引训练**（而非视差空间）在全局排序上相当，但在前景/背景间取得更均衡优化，各项指标更优。
- 该表示可支撑多种下游任务：矢量化、文本→矢量生成、单图浮雕/触觉图形、深度感知编辑与图层分解、可编辑重叠层 + 修补生成视差效果。
- 仅用简单 SVG 数据训练，却能泛化到复杂艺术渲染，归因于 Depth Pro / DINO-v2 的预训练先验。

## 7. 优点

- **概念创新**：把"深度"从物理度量重构为面向编辑的图层抽象，问题定义新颖且具有明确实用价值。

- **应用面广**：从矢量化到文本→矢量、浮雕制造、触觉图形、深度感知编辑，展示了方法的通用性。
