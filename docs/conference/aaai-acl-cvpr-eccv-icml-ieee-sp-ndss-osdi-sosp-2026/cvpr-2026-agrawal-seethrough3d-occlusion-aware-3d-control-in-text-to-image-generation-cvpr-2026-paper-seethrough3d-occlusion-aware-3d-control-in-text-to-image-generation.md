tldr: 三维布局条件下的图像生成常无法精确建模物体间遮挡，导致几何与尺度不一致。本文提出SeeThrough3D，引入遮挡感知三维场景表示OSCR，用半透明三维盒编码被遮挡区域，使模型能够推理遮挡并渲染深度一致的场景。实验显示该方法可生成具有正确遮挡关系与尺度一致性的部分被遮挡物体，为可控生成中的遮挡推理提供了新表示。

## Abstract
We identify occlusion reasoning as a fundamental yet overlooked aspect for 3D layout-conditioned generation. It is essential for synthesizing partially occluded objects with depth-consistent geometry and scale. While existing methods can generate realistic scenes that follow input layouts, they often fail to model precise inter-object occlusions. We propose SeeThrough3D, a model for 3D layout conditioned generation that explicitly models occlusions. We introduce an occlusion-aware 3D scene representation (OSCR), where objects are depicted as translucent 3D boxes placed within a virtual environment and rendered from desired camera viewpoint. The transparency encodes hidden object regions, enabling the model to reason about occlusions, while the rendered viewpoint provides explicit camera control during generation. We condition a pretrained flow based text-to-image image generation model by introducing a set of visual tokens derived from our rendered 3D representation. Furthermore, we apply masked self-attention to accurately bind each object bounding box to its corresponding textual description, enabling accurate generation of multiple objects without object attribute mixing. To train the model, we construct a synthetic dataset with diverse multi-object scenes with strong inter-object occlusions. SeeThrough3D generalizes effectively to unseen object categories and enables precise 3D layout control with realistic occlusions and consistent camera control.

  - 3D 布局条件方法常使用 3D bbox 的深度图，但深度图无法表达被遮挡物体的完整存在，导致复杂多物体遮挡失败。
  - 将场景拆成 2D 物体图层的方法可近似遮挡，但丢失真实 3D 结构、透视和相机控制。
- **整体含义**：论文提出 **SeeThrough3D**，通过显式建模遮挡的 3D 场景表示，实现文本到图像生成中的**遮挡感知 3D 布局控制**，并支持相机视角控制、复杂布局、个性化物体生成。

## 2. 方法论

### 核心思想
- 提出 **Occlusion-Aware 3D Scene Representation (OSCR)**：用**半透明 3D 包围盒**表示物体，在虚拟环境中从指定相机视角渲染，作为生成模型的条件。
- 半透明性使被遮挡区域仍部分可见，从而让模型能够推理物体间遮挡关系；盒面颜色编码物体 3D 方向；渲染视角天然编码相机姿态。
- 基于预训练 flow-based 文生图模型 **FLUX.1-dev**，通过视觉 token 注入 OSCR 条件，并用注意力掩码将物体框与文本描述绑定。

### 关键技术细节
1. **OSCR 表示**
   - 输入：一组 3D bounding boxes \(b_i\)，每个对应一个物体。
   - 每个盒子半透明渲染，使被遮挡物体区域仍可见。
   - 盒子各面使用预定义颜色映射，例如橙色表示前面、蓝色表示左面、其他绿色，用于编码 3D 方向。
   - 用 Blender 从指定相机视角 \(C\) 渲染得到条件图 \(r\)。
   - 该表示同时编码物体排布、遮挡线索、方向和相机视角。

2. **条件生成框架**
   - 用 VAE 编码 OSCR 渲染图 \(r\)，得到 **OSCR tokens** \(z\)。
   - 将 \(z\) 与文本 prompt tokens \(p\)、噪声图像 tokens \(x_t\) 拼接。
   - OSCR tokens 与噪声图像 tokens 使用相同位置编码，以建立空间对应。
   - 通过 mmDiT blocks 联合处理。
   - 为保留基座模型先验，仅在新 token 对应的注意力投影矩阵上训练 **LoRA**，rank 为 128。
   - 阻断 OSCR tokens 到图像 tokens 的注意力，避免条件 token 干扰图像 token 生成。

3. **对象绑定与注意力掩码**
   - 仅空间条件无法保证每个 bbox 对应正确文本对象，可能导致属性混合。
   - 使用每个盒子的 **amodal segmentation mask** \(s_i\) 定义空间范围。
   - 对注意力进行掩码：某个盒子内的 OSCR tokens 只 attend 到文本 prompt 中对应物体名词 tokens \(p_i\)。
   - 当多个盒子重叠时，交集区域的 OSCR tokens 可同时 attend 多个物体 tokens。
   - 作者观察到，即使重叠，模型仍能在 latent space 中保持物体特征区分，并生成正确遮挡边界。

4. **个性化扩展**
   - 输入参考物体图像 \(v\)，经 VAE 编码得到 appearance tokens。
   - 将 appearance tokens 与文本 tokens、图像 tokens、OSCR tokens 拼接。
   - 复用注意力掩码，使目标盒子内的 OSCR tokens attend 对应 appearance tokens。
   - 支持将个性化物体绑定到指定 3D bbox，并可扩展到多个参考物体。

5. **训练数据构建**
   - 用 Blender 程序化放置 3D 资产，控制物体配置和相机参数，诱导强遮挡。
   - 过滤物体重叠过少或可见性过低的简单场景。
   - 为缓解合成背景过拟合，用深度估计加 FLUX.1-Depth-dev 生成真实感增强图。
   - 再用物体级 CLIP 过滤，保留布局一致的增强样本。
   - 最终数据集：**25K 渲染图 + 25K 增强图**。

## 3. 实验设计

- **训练数据**：合成 Blender 场景，25K 渲染图与 25K 深度增强图。
- **评估 benchmark**：提出 **3DOc-Bench**，包含 **500 个样本**，每个样本有 3D bbox 布局、渲染图像和场景文本 prompt。特点：
  - 多样物体配置；
  - 强遮挡场景；
  - 多相机视角；
  - 保证每个物体有最低可见面积。
- **评估指标**：
  - **Depth ordering / depth ord.↑**：比较物体对相对深度顺序，反映 3D 位置和遮挡一致性。
  - **Objectness score / obj. score↑**：结合 2D 布局与 Segment Anything 得物体 mask，再算 CLIP 相似度，评估布局遵循与物体保真。
  - **Angular error / angular err.↓**：用 OrientAnything 估计方向，与 GT 比较。
  - **Text alignment / text align.↑**：CLIP 图像-文本相似度。
  - **KID↓**：图像质量。
- **对比方法**：
  - 3D 布局控制：**LooseControl**、**Build-A-Scene**。
  - 遮挡控制：**LaRender**、**VODiff**。
  - 另提到 **Compass Control**、**ORIGEN** 用于方向控制，但不直接支持 3D 物体放置，放在附录讨论。
- **其他实验**：
  - 定性结果：复杂布局、透明物体、文本渲染、相机控制、物体交互、未见类别。
  - 用户研究：60 名参与者 A/B 测试，评估图像真实感、布局遵循、文本对齐。
  - 个性化实验：参考图像绑定到指定 3D 框。
  - 消融实验：无透明度、无颜色编码、无注意力绑定、无困难数据过滤。

## 6. 主要结论与发现

- SeeThrough3D 能生成具有**正确遮挡关系、深度一致、尺度合理**的部分被遮挡物体。
- 在 3DOc-Bench 上，方法在 depth ordering、objectness、方向误差、文本对齐、KID 上均优于对比方法：
  - Depth ord.：Ours 1.46，优于 LaRender 1.02、Build-A-Scene 0.89 等。
  - Angular err.：Ours 47.92，显著低于其他方法的 89–93 左右。
  - KID：Ours 5.43，明显优于 13.46–20.12。
- 方法能泛化到未见物体类别，包括乐器、电子设备、透明物体等训练集中没有的类别。
- 能处理复杂多物体布局，即使训练时最多约 4 个物体，测试时可生成更多物体场景。
