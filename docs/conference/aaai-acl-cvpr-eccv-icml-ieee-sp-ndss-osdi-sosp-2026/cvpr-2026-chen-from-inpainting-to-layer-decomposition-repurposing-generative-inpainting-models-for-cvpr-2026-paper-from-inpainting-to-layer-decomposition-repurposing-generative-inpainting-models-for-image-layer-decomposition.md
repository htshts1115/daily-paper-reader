tldr: 图像可看作前景物体叠加背景的图层组合，但将单幅图像分解为图层的方法与数据都十分有限。本文发现图层分解与图像内/外绘任务存在强关联，于是用轻量微调改造扩散修复模型来完成图层分解，并引入线性注意力的多模态上下文融合模块以在潜空间中保留细节。方法能实现前景与背景的独立分层，为灵活的图像编辑与前景背景分离提供可迁移的生成式方案，与抠图/前景分离需求存在方法性联系。

## Abstract
Images can be viewed as layered compositions, foreground objects over background, with potential occlusions. This layered representation enables independent editing of elements, offering greater flexibility for content creation. Despite the progress in large generative models, decomposing a single image into layers remains challenging due to limited methods and data. We observe a strong connection between layer decomposition and in/outpainting tasks, and propose adapting a diffusion-based inpainting model for layer decomposition using lightweight finetuning. To further preserve detail in the latent space, we introduce a novel multi-modality context fusion module with linear attention complexity. Our model is trained purely on a synthetic dataset constructed from open-source assets and achieves superior performance in object removal and occlusion recovery, unlocking new possibilities in downstream editing and creative applications.

## 1. 核心问题与整体含义（研究动机与背景）

- **任务定义**：图像图层分解（Image Layer Decomposition）指将单张图像拆分为前景图层（含被遮挡区域恢复的 RGBA 前景）与背景图层（移除前景物体后的干净背景），从而实现元素的独立编辑。
- **研究动机**：
  - 图层化表示对创意重构图、分层艺术生成、组件检索等下游应用价值显著。
  - 但该任务长期受限于**方法与数据双重稀缺**：高质量图层标注数据难以获取，现有方法（如 LAYERDECOMP）需在闭源大模型上做**全量微调 + 大规模高质量数据集**，计算与数据成本极高，普通用户难以复现。
- **核心洞察**：图层分解与**修复（inpainting）/外绘（outpainting）** 存在结构性统一——
  - 背景层 = 对掩码区域进行内容填充（等价于修复）；
  - 前景层 = 在掩码区域内恢复 RGB + alpha，外部 alpha 置零（等价于带透明度约束的外绘）。
- **整体含义**：本文提出首个通过**轻量改造预训练修复模型**来完成图层分解的方法，验证了"复用现有修复模型"可作为大规模重训练的实用替代方案，降低开发门槛并具备即插即用潜力。

## 2. 方法论

### 2.1 核心思想
- 将图层分解重构为"**修复 + 外绘**"的组合，复用单一修复骨干（FLUX.1-Fill-dev，DiT 架构），仅做轻量适配，而非从零设计模型。
- 方法命名为 **Outpaint-and-Remove**，可同时输出被提取（并外绘补全遮挡）的前景和被移除物体的背景。

### 2.2 关键技术组件（三处改动，见论文图 2/图 3）
1. **多模态上下文分词（Multi-Modal Context Tokenization）**
   - 从输入图像生成**边缘图（Canny）、分割图（SegFormer）、深度图（Depth-Anything-V2）**。
   - 利用预训练 DiT 的 VAE 编码器将这些图像型输入 token 化。
   - 为解决 token 数量增长带来的计算开销，提出 **多模态潜空间融合模块（Multi-Modal Latent Fusion）**：借鉴线性注意力（Perceiver 类思路），用少量常量个潜 token（N ≪ K）作为 query，将注意力复杂度从 O(K²) 降到约 **O(KN)**，实现线性复杂度。

2. **图像-掩码上下文设计（Image-Mask Context）**
   - 标准修复模型只用背景上下文 cb_{I−M}；
   - 本文额外引入**前景上下文 cf_{I−M}**，作为控制信号，帮助模型在"保留已有信息"与"生成新内容"间取得平衡，抑制幻觉。
   - 上下文与噪声输入 token 沿通道维拼接：
     - 前景输入：`concat(zf_t, cf_{I−M}, cMM)`
     - 背景输入：`concat(zb_t, cb_{I−M}, cMM)`
   - 最终 DiT 接收前景、背景两条各 N 个 token 的序列，token 维度为 d1+d2+d3。

3. **参数高效微调（PEFT）与解码**
   - 冻结基础 DiT 权重，**微调输入投影层**并在每个注意力层和前馈层插入 **LoRA**。
   - 背景为 RGB，直接复用预训练 VAE 编解码器；前景为 RGBA，**另训一个 RGBA 编解码器**（沿用 LayerDiffuse 思路）。

### 2.3 训练数据策展（纯公开资源）
- **前景来源混合**：MULAN 真实前景（细节丰富但形状常不完整）+ LayerDiffuse 生成前景（形状完整但纹理过平滑），取长补短。
- **背景来源**：OpenImages 采样，叠加缩放后的前景模拟真实合成场景。
- **掩码策略**：故意使用不完美掩码，使模型学会推断准确边界。
- 最终构建 **100,000 组**图像–前景–背景三元组，每组含 1–3 个前景物体及可能遮挡。
