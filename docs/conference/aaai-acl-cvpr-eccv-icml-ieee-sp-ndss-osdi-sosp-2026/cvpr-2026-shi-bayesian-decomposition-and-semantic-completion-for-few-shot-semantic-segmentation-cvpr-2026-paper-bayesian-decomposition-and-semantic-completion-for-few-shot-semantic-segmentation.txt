# Abstract 

Few-shot Semantic Segmentation (FSS) aims to segment objects of novel categories given only a handful of labeled examples. However, existing methods often rely on complex category-specific modeling, resulting in high computational cost and limited generalization under low-data regimes. To address these challenges, we propose a Bayesian Proba-bilistic Network (BPNet) that reformulates FSS as a com-position of three interpretable components: a prior, a likeli-hood, and a class-consistency term. Specifically, an efficient Segment Anything Model (SAM) is employed to generate fragmented prior regions for the query image, while both the likelihood and the consistency terms are estimated by a lightweight Class-Agnostic Localization Model (CALM). CALM simultaneously predicts the class consistency be-tween support-query pairs through a binary classification head and estimates the likelihood by localizing the target region in the support image. By evaluating SAM-generated regions in parallel, CALM can efficiently identify the core region, thereby transforming the segmentation problem into a simple binary classification task. Furthermore, to mit-igate the semantic incompleteness of SAM proposals, we introduce an attention-based Semantic Completion Mod-ule (SCM), which leverages local and global context cues to integrate fragmented regions into semantically complete masks. Experiments show that BPNet achieves state-of-the-art performance while maintaining high efficiency.

Most metric-based FSS methods [12, 35, 40] extract features or class pro-totypes from support images and compute similarity with query images to segment new classes, as illustrated in Fig.1 (a). However, these methods heavily rely on the accurately modeling of class prototypes, which is diffi-cult to ensure under few-shot settings. Recently, some methods [14, 30, 42] leverage the rich semantic and visual prior knowledge embedded in pretrained Multimodal Large Language Models (MLLMs) to guide few-shot segmenta-tion, typically by generating class-aware prompts or adapt-ing features from the support set, as shown in Fig.1 (b). While these approaches improve the utilization of rich prior knowledge, they impose substantial computational over-head and are still constrained by the quality of the under-lying class representations. To tackle these challenges, we propose BPNet , a novel paradigm based on Bayesian probabilistic formulations. It decomposes the challenging FSS task into three seman-tically lightweight components with distinct probabilistic roles, which eliminates the need to model class prototypes directly, as illustrated in Fig.1 (c). Specifically, given a query image x with its mask y, and a support image s

with mask m, we decompose the FSS prediction objective 

p(y|x, s, m ) into three components: a prior term p(y|x), a likelihood term p(m|x, y, s ), and a class-consistency term 

p(s|x, y ). The prior component provides query image re-gions based purely on structural cues, serving as target pro-posals. Practically, an efficient Segment Anything Model (SAM) [36] is employed to generate these proposals, pro-viding structure-based regions without class-specific se-mantics. It naturally aligns with the few-shot constraint that models have no prior knowledge about target classes be-fore training. Benefiting from SAM’s strong capability in structural segmentation, the generated regions exhibit pre-cise and well-defined boundaries. As for the likelihood term p(m|x, y, s ) and the class-consistency term p(s|x, y ), the former models the proba-bility of observing the support mask m given a hypoth-esized query region, while the latter verifies the seman-tic alignment between the proposed query region and the support image. Instead of predicting explicit category la-bels, we only determine whether the support image and query region share consistent semantics. To this end, both components are integrated into a Class-Agnostic Localiza-tion Module (CALM), which is a lightweight binary clas-sification network augmented with Class Activation Maps (CAMs) of support branch. The classification probabil-ity produced by CALM serves as the class-consistency term, whereas the intersection-over-union (IoU) between the CAM-highlighted region and the support mask provides an approximation of the likelihood term. This probabilis-tic reformulation effectively converts the complex FSS task into a simple binary classification task. Moreover, by lever-aging the joint collaboration among the probabilistic com-ponents, BPNet achieves high segmentation accuracy even without precise estimation of each individual term. To address the semantic incompleteness of SAM pro-posals, we design a Semantic Completion Module (SCM) as shown in Fig.1 (d), which refines fragmented priors into complete object masks by evaluating both local and global semantic similarities between each proposal and the core region (the proposal with the highest confidence obtained from the Bayesian decomposition). The local similarity di-rectly measures the semantic correspondence between each proposal and the core region, providing a straightforward estimate of their feature alignment. However, proposals that appear locally dissimilar to the core region may still belong to the same semantic object in a broader context. For ex-ample, the glass and tire of a car exhibit distinct textures but share the same object semantics. To capture such long-range semantic dependencies, the global similarity is intro-duced. Specifically, SCM first computes the semantic as-sociations between all regions and the core region through a semantic association attention mechanism, and then com-pares these associations with the candidate proposals. This enables SCM to recognize globally consistent semantics, al-lowing fragmented regions to be effectively integrated into semantically complete masks. Our main contributions are summarized as follows: • We propose a novel Bayesian Probability-based paradigm for FSS, which decomposes the complex task into three semantically lightweight components, avoiding the need to directly model class prototypes. • We introduce a Class-Agnostic Localization Module that simultaneously integrates the likelihood and the class consistency terms using a single binary classification net-work, thus significantly reducing training cost. • We propose a Semantic Completion Module, which not only directly compares the semantic similarity between proposals but also leverages the global context to infer their intrinsic relationships, thereby accurately complet-ing target masks. 

# 2. Related Work 

2.1. Semantic Segmentation 

Semantic segmentation aims to classify each pixel of an im-age into a set of preset categories. According to different network structures, current methods can be roughly divided into three categories, i.e., CNN-based [5, 20, 21], RNN-based [28, 31] and Transformer-based methods [9, 38, 39]. CNN-based methods utilize convolution operations to ex-tract semantic information for pixel-level label prediction. Considering dependence of context information, RNN-12355 based methods use recurrent layers to capture local and global spatial structure information of images. Recently, Transformer-based methods have received more popularity. They regard patches of images as a se-quence, then utilize an encoder-decoder structure with at-tention mechanisms to achieve segmentation. For instance, considering the challenge of achieving unified semantic and instance understanding, OneFormer3D [16] utilizes a transformer-based kernel decoder to jointly predict seman-tic and instance masks, thereby demonstrating strong gen-eralization and efficiency. To alleviate the high computa-tional cost of Vision Transformers, ALGM [22] hierarchi-cally merges similar tokens first within local windows and then across the global feature space, thus reducing token re-dundancy without compromising structural details. 

2.2. Few-shot Semantic Segmentation 

Few-shot semantic segmentation extends the ability of seg-mentation to novel category with a few labeled samples. Many researchers have approached the FSS task using feature-level or prototype-level similarity methods [10, 35], which have been enhanced by various strategies e.g., multi-scale, memory modules, and region-level aggregation, thus addressing appearance variations and background noise. To better exploit large-scale pretrained image en-coders [3], recent studies have proposed approaches cen-tered on visual prompts [14], class-aware dynamic enhance-ment [41, 44], and prior knowledge guidance [17, 24, 30], aiming to customize the generic representations for novel categories with minimal parameters or limited fine-tuning efforts. For instance, to leverage the rich prior knowledge embedded in large-scale diffusion models, Shi et al. [30] propose a prior-guided FSS method that incorporates class-specific prior knowledge to guide the segmentation process, thereby improving accuracy and robustness. Those methods, while surpassing traditional prototype alignment and similarity-based approaches in few-shot tasks, often rely on extensive training data and computa-tional resources, limiting their flexibility and scalability in practical applications. In contrast, our method introduces a Bayesian probabilistic framework that decomposes the seg-mentation task into interpretable lightweight components, thereby enhancing computational efficiency and generaliza-tion capabilities. 

# 3. Method 

3.1. Theoretical Formulation 

Let s and m denote the support image and its corresponding binary mask, while x and y represent the query image and its binary mask. The FSS task can be formulated as learning the conditional probability p(y|x, s, m ) [6, 27]. Under the assumption that the support set (s, m ) and query set (x, y ) are independent, we can derive the fol-lowing reformulation of the target conditional distribution based on Bayes’ theorem: 

p(y|x, s, m ) = p(y, s, m |x)

p(s, m |x) . (1) The numerator term can be further factorized as follows: 

p(y, s, m |x) = p(y|x) · p(s, m |x, y )= p(y|x) · p(m|s, x, y ) · p(s|x, y ). (2) Combining the above equations yields: 

p(y|x, s, m ) = p(y|x) · p(m|s, x, y ) · p(s|x, y )

p(s, m |x) . (3) 

p(y|x) represents the structure-based segmentation of the query image, which partitions the image into coherent regions according to visual structures rather than class se-mantics, as the model has no knowledge of novel classes in the FSS setting. p(m|s, x, y ) represents the likelihood of observing the support mask m given the query hypoth-esis (x, y ) and the support image s. A similar idea has also been explored in [29, 34]. Practically, we estimate this term by segmenting the support conditioned on the query region. Unlike the original FSS objective p(y|x, s, m ), this term does not require precise segmentation, allowing for a more lightweight network design. p(s|x, y ) measures the class-consistency between support and query features, while p(s|x) serves as a normalization constant that is inde-pendent of y.By employing this Bayesian decomposition, we refor-mulate the FSS task into three tractable components: pixel-wise class prediction, support segmentation conditioned on the query, and class-level feature consistency measure-ment. Each component can be optimized without requir-ing explicit class prototypes or precise segmentation masks, thereby alleviating overfitting and improving generalization in few-shot scenarios.

3.3. Class-Agnostic Localization Model 

To jointly estimate class-consistency and likelihood prob-abilities, we propose a Class-Agnostic Localization Model (CALM) built upon a binary classification framework with gradient-based activation. CALM predicts whether a query region and a support image belong to the same class, while simultaneously localizing the most relevant regions in the support image by extracting its Class Activation Maps (CAMs). The overlap rate between the CAM and the sup-port mask serves as the likelihood term, whereas the classi-fication probability represents the class-consistency term. Concretely, we first input the query image q and the sup-port image s into a pre-trained lightweight ResNet-18 [8] to extract their feature maps Fq and Fs. For query region Ri,we perform element-wise multiplication between its mask and the query feature map to obtain the region-specific fea-ture maps. Then, we perform global average pooling on the feature maps to obtain their feature vectors. Next, we concatenate the two feature vectors and input them into a Multi-Layer Perceptron (MLP) with a sigmoid activation function to predict whether they belong to the same class. The output same-class probability of this network serves as the class consistency probability. 

P ci = σ(MLP( V ec (Ri ⊗ Fq ) ⊕ V ec (Fs))) , (10) where V ec (·) represents global average pooling, σ(·) is the sigmoid function, ⊗ and ⊕ indicates element-wise multipli-cation and concatenation, respectively. Secondly, we use the class-consistency probability P ci

as a supervision signal to perform backpropagation through the binary classification network. During this process, the gradients with respect to the support feature map Fs are ob-tained. Following the LayerCAM algorithm [13], these gra-dients are utilized to generate a class activation map (CAM) from Fs, which highlights the region in the support image that is most semantically correlated with the current query region Ri. By binarizing the CAM and computing its In-tersection over Union (IoU) with the ground-truth support mask m, we estimate the likelihood probability P li as: 

P li = IoU ( Binarize(CAM( Fs, P ci )) , m ). (11) The training process of CALM only requires binary clas-sification labels, which avoids the dependence on precise segmentation masks, reducing training costs while improv-ing the model’s generalization ability.

4.2. Implementation Details 

To evaluate the performance of our method, we implement BPNet using the PyTorch library, and train it for 200 epochs on an RTX 3090 GPU. During training process, the seg-mentation results produced by SAM for the query images remain nearly unchanged. Therefore, we precompute the segmentation results of SAM for all query images and store them for use during training, which can significantly save GPU memory and speed up training. To supervise the model training, we determine whether each region predicted by SAM corresponds to the target object. Specifically, a re-gion is considered a positive target if its overlap ratio with the ground-truth mask exceeds 0.7.

4.4. Qualitative Results 

We present qualitative results of BPNet in Fig. 3. It can be observed that the SCM can effectively expand incomplete regions from SAM’s fragmented proposals into coherent semantic masks. 4.5.3. Design of SCM 

To validate the SCM design, we analyze the contributions of both local and global similarity measures, as well as exam-ine various context fusion strategies for constructing global vectors. The comparison results are shown in Table 4. Removing either the local vectors or the global vectors results in a noticeable performance drop, demonstrating that both components are essential for effective semantic com-pletion. Local vectors enable the model to capture direct correspondence between the current region and its most relevant neighboring regions, while global vectors provide holistic semantic guidance. Their complementary roles help enrich the semantic representation of the target region, ulti-mately enhancing segmentation accuracy. Furthermore, we evaluate two approaches for generat-ing global vectors: simple weighted averaging and cross-attention. The results indicate that cross-attention yields su-perior performance, likely because it can dynamically em-phasize class-relevant features and better align global se-mantics, thereby improving completion accuracy. 

# 5. Conclusion 

In this paper, we introduce the BPNet, a Bayesian proba-bilistic framework for FSS. By decomposing the complex task into probabilistic models, BPNet reformulates FSS as a composition of three interpretable components: a prior, a likelihood, and a class-consistency term. The CALM uni-fies class-consistency and likelihood estimation through a single binary classification process, while the SCM lever-ages both local and global semantic cues to refine incom-plete regions into coherent object masks.
