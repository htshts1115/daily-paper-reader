## 摘要
开放词汇语义分割旨在不受固定类别集合限制地对像素进行分类。尽管对比语言-图像预训练（CLIP）在开放词汇识别中展现出显著潜力，但其分割能力受到带噪声的类间图像块交互的影响。为此，本文从图像块相关性、特征表示和输出正则化三个互补方面，提出了一种统一的、免训练的以对象为中心的框架 CorrCLIPv2。具体而言，在图像块相关性方面，我们利用类别无关的掩码生成器显式解耦类间交互。此外，我们利用自监督模型提供的空间连贯特征计算注意力分数，以缓解掩码不准确的问题。在特征表示方面，我们设计了一种细化机制，以同时增强空间细节和语义表示。在输出空间中，我们通过在每个掩码内进行投票来统一预测，以增强空间一致性。为缓解上下文偏差并提升对象预测精度，我们进一步通过引入跨图像对象检索范式扩展该框架，其计算开销极小。我们利用无标注图像构建由 CorrCLIP 增强特征组成的记忆库，并实现多 CLIP 集成策略。通过聚合从记忆库中检索到的、跨多样上下文的语义一致对象特征，CorrCLIPv2 缓解了上下文引起的干扰，并获得更稳健的预测。大量实验表明，我们的方法在 10 个标准基准上取得了新的最先进性能。值得注意的是，它甚至在 22 个多领域数据集上超越了全监督开放词汇方法。代码可在 https://github.com/zdk258/CorrCLIP 获取。

## Abstract
Open-vocabulary semantic segmentation aims to classify pixels without being restricted to a fixed set of categories. Although Contrastive Language-Image Pre-training (CLIP) demonstrates remarkable potential for open-vocabulary recognition, its segmentation capability is impaired by noisy inter-class patch interactions. To this end, this work proposes a unified training-free object-centric framework, named CorrCLIPv2, from three complementary aspects of patch correlation, feature representation, and output regularization. Specifically, for patch correlation, we leverage class-agnostic mask generators to explicitly disentangle inter-class interactions. Moreover, we utilize spatially-coherent features from self-supervised models to compute attention scores to mitigate mask inaccuracies. Regarding feature representation, we devise a refinement mechanism to simultaneously strengthen spatial details and semantic representation. Within the output space, we unify predictions via voting in each mask to enhance spatial consistency. To mitigate contextual bias and enhance prediction accuracy of objects, we further extend the framework by incorporating a cross-image object retrieval paradigm, which incurs minimal computational overhead. We build a memory bank of CorrCLIP-enhanced features from unlabeled images and implement a regime of multi-CLIP ensemble. By aggregating semantically consistent object features across diverse contexts retrieved from the memory bank, CorrCLIPv2 mitigates context-induced interference and obtains more robust predictions. Extensive experiments demonstrate that our approach establishes a new state-of-the-art on 10 standard benchmarks. Remarkably, it even surpasses fully supervised open-vocabulary methods across 22 multi-domain datasets. Code is available at: https://github.com/zdk258/CorrCLIP.

## 1. 核心问题与研究动机

- **任务背景**：开放词汇语义分割（OVSS）要求依据开放文本描述为像素分类，不受固定类别集合限制。CLIP 因大规模图文对比预训练成为该任务的主流骨干，但其全局对齐目标与像素级密集预测存在根本错位。
- **核心问题一：类间 patch 交互噪声**。CLIP 的对比预训练偏重全局信息，不同 patch 表示过于相似，局部判别性不足；最终层自注意力又把不同类别的 patch 混合，形成破坏性噪声。
- **关键实证发现**：作者将 patch 相关性拆分为类内与类间两类，通过受控实验（Fig. 1）发现：纯类内/对象内相关显著提升分割；重新引入类间相关（即使语义最相似）会持续降低性能。结论是：在密集预测中，类间相关主要是噪声，而非有用上下文。
- **核心问题二：上下文偏置**。CLIP 前层必须全局聚合信息，对象嵌入会被周围背景干扰（如暗笼中的“猫”更接近“fence”），单张图像信息不足以纠正语义漂移。
- **整体含义**：论文提出免训练、以对象为中心的统一框架 CorrCLIPv2，从 patch 相关性、特征表示、输出正则三方面重构 CLIP 的分割行为，并进一步利用无标注图像构建跨图像检索范式，以边际推理开销缓解上下文偏置。该工作是 ICCV'25 oral 论文 CorrCLIP 的期刊扩展版（IJCV）。

## 2. 方法论

### 2.1 基础设定

- 采用 CLIP ViT 视觉编码器，仅修改最后一层：以 query-query 自相关替代 query-key 注意力，得到相似度矩阵 \(S=Q_CQ_C^T\)；去除最后一层的残差连接与前馈网络。
- 注意力 \(A=\text{Softmax}(S/\sqrt{d})\)，图像特征 \(F_{img}=AV_C\)；文本编码器生成类嵌入 \(F_{txt}\)；分割 logits 为 \(P=F_{img}F_{txt}^T\)，取 argmax 得标签。

### 2.2 CorrCLIP：单图像相关性重建（四个模块）

- **Scope Reconstruction（范围重建）**：
  - 用类无关掩码生成器（EntitySeg）产生 \(Z\) 个区域掩码 \(M\)，未覆盖像素构成背景掩码 \(m_0\)。
  - 构造二值交互矩阵 \(E\)：对象区域内 patch 严格全连接；背景区域用全局相似度均值 \(\bar S\) 作动态阈值过滤弱连接。
  - 用 Masked Softmax 替代标准 Softmax，仅在 \(E_{i,j}=1\) 处允许注意力，显式阻断类间传播。
- **Value Reconstruction（值重建）**：
  - 为缓解掩码不准确，引入自监督 VFM（C-RADIOv3）最终层特征 \(F_{vfm}\)，计算归一化相似度 \(\tilde S=F_{vfm}F_{vfm}^T/\|F_{vfm}\|^2\)，作为软语义过滤器。
  - 最终注意力为 \(\text{Masked Softmax}(\tilde S/\tau,E)\)，温度 \(\tau=0.25\)；即使掩码误放行异类 patch，VFM 低相似度也会抑制其贡献。
- **Feature Refinement（特征细化）**：
  - **语义分支**：引入 \(Z\) 个 Mask Class Token，每个 token 只关注其对应掩码内图像 token，聚合区域级表示后再分配回 patch 级 \(X_{MCT}=M^TT_{mask}\)。
  - **空间分支**：利用 CLIP 前层空间连贯性更强的特征，经最后一层 value 投影得到 \(V'_C\)。
  - 融合：\(F_{img}=AV_C+\alpha AV'_C+\beta X_{MCT}\)，其中 \(\alpha=1.0,\ \beta=0.5\)。
- **Map Correction（预测图校正）**：在每个掩码区域内对预测做多数投票，统一为同一类别，提升空间一致性。

### 2.3 CorrCLIPv2：跨图像检索增强范式

- **动机验证（Oracle 研究）**：用真值掩码按类别构建理想特征库，随机采样同类支持集与目标特征平均，性能大幅提升（PAS-59 +31.2%，COCO-80 +27.7%），证明多实例语义原型可抵消上下文偏差。
- **索引选择（1-NN 分析）**：比较 CLIP、CorrCLIP、DINOv3、C-RADIOv3 的 1-NN 检索一致性，SSL VFM 显著最优，故用 VFM 特征作索引键、CorrCLIP 特征作语义值。
- **离线记忆库构建**：
  - 使用 COCO 训练集约 118k 张**无标注图像**，生成类无关掩码。
  - 对每个掩码做 Mask Average Pooling（MAP）：VFM 特征得索引键 \(k_j\)，CorrCLIP 特征得语义值 \(v_j\)，形成约 2.9M 个对象嵌入。
- **推理与检索**：
  - 直接复用 Scope Reconstruction 的掩码与 Value Reconstruction 的 VFM 特征图，查询 \(q_j=\text{MAP}(F_{vfm},m_j)\)，不增加额外编码计算。
  - 用 FAISS-GPU 的 IVFPQ 做 Top-\(K\) 近似最近邻检索（默认 \(K=20\)），对检索到的 CorrCLIP 特征取平均得支持向量 \(s_j\)，再重分配为稠密支持图 \(F_{supp}=M^TV_{supp}\)。
  - 融合预测：\(P=\theta(F_{img}F_{txt}^T)+(1-\theta)(F_{supp}F_{txt}^T)\)，默认 \(\theta=0.5\)。
- **Decoupled Multi-CLIP Ensemble（解耦多 CLIP 集成）**：
  - 辅助 CLIP 模型（如 DFN）的特征编码在离线阶段完成并写入同一记忆库；推理时仅检索并融合，边际成本极小。
  - 最终预测融合主模型单图 logits、主模型检索支持 logits 与辅助模型检索支持 logits。
- **关键设计**：记忆库与语言解耦，避免文本锚定记忆库的词汇过拟合，天然适配无限类别场景。
