Abstract. Few-shot segmentation (FSS) aims to segment target objects with limited annotated examples. Recent studies have begun to explore large foundation models to improve generalization for this task. In par-ticular, SAM 3 provides strong visual representations and supports text-guided segmentation. However, its performance remains limited in spe-cialized domains, where semantic prompts and visual representations are often poorly aligned. To address this challenge, we propose ViTA-SAM, a framework built upon SAM 3 that integrates visual memory and tex-tual features through cross-modal alignment. Specifically, we construct a visual memory module that encodes support features together with their corresponding masks, providing support-aware visual guidance for query prediction. In parallel, we leverage the text encoder of SAM 3 to extract semantic features as complementary priors. To bridge the gap between se-mantic and visual representations, we introduce a cross-modal alignment module that conditions textual features on memory-enhanced visual rep-resentations, yielding more consistent and visually grounded predictions. In addition, we propose a pseudo-label refinement strategy that updates the memory with predicted query masks, enabling query-adaptive repre-sentation learning. Extensive experiments on multiple benchmarks show that ViTA-SAM achieves the best overall performance among the com-pared methods, outperforming the strongest competing method by over 5% in average mIoU. 

Keywords: Few-shot segmentation · SAM 3.

Few-shot segmentation (FSS) [28, 29, 34, 38, 39] has therefore attracted increasing attention as a promising alternative. Its goal is to segment target objects from only a few annotated examples. Conventional FSS methods mainly focus on constructing representative pro-totypes (Figure 1b). The pioneering work PANet [34] learns class-specific proto-types from support images and segments the query image via pixel-wise matching in the feature space. CANet [39] performs multi-level feature comparison be-tween query features and global support representations. PFENet [32] leverages support-guided prior masks to encode coarse object locations and uses them to alleviate spatial inconsistency between support and query targets. Despite their effectiveness, the visual matching functions learned by these methods are often biased toward the training distribution, limiting their generalization to diverse scenarios. Subsequent methods improve robustness to such distribution varia-tions. For example, PATNet [14] introduces a prototype alignment module to reduce feature discrepancies. DMTNet [4] addresses distribution variations via a dynamic multi-scale mechanism that adaptively weights features based on input characteristics. ABCDFSS [11] performs task-specific feature adaptation at test time, thereby better aligning representations with the current input. Meanwhile, recent advances in large-scale foundation models, particularly the Segment Anything Model (SAM) family, have opened new opportunities for generalizable segmentation. The original SAM [12] introduces promptable zero-shot segmentation using visual prompts such as points and bounding boxes. SAM 2 [26] extends this capability to video segmentation by incorporating a temporal memory mechanism for consistent mask propagation. More recently, SAM 3 [3] integrates the memory mechanism from SAM 2 and improves vision– language alignment, enabling the use of both visual concepts and textual prompts. However, SAM models are primarily pretrained on natural images, which limits their generalization to specialized domains. As illustrated in Figure 1a, SAM 3 struggles with specialized imagery ( e.g., medical or satellite images) and domain-ViTA-SAM 3

specific concepts ( e.g., “keratosis”), suggesting a misalignment between semantic and visual representations that degrades segmentation performance. Based on these observations, we propose ViTA-SAM, a novel framework built on SAM 3 that aligns visual memory and textual prompts through cross-modal interaction and enables robust knowledge transfer (Figure 1c). Specifically, we leverage the visual memory module to encode support features and their corre-sponding masks into a memory bank, producing object-aware representations. During inference, the memory is fused with query features to propagate struc-tural and boundary information from support to query. In parallel, we incorpo-rate textual information using the SAM 3 text encoder to extract task-specific semantic features as complementary priors. To bridge the misalignment between semantic and visual representations under domain shifts, we align textual fea-tures with memory-enhanced visual features via cross-attention, yielding visu-ally grounded semantic features. Furthermore, we introduce a pseudo-label re-finement strategy that uses predicted query masks to update the memory with query features, constructing a query-adaptive memory for progressively refined predictions. During inference, the memory-enhanced visual features and aligned textual features are fused using prediction-confidence-based weights. Overall, the main contributions of this work are as follows: 

– We propose ViTA-SAM, a novel framework for few-shot segmentation. It in-tegrates visual memory and textual features through cross-modal alignment, enabling effective knowledge transfer under domain shifts. 

– We introduce a cross-modal alignment mechanism that aligns textual and visual representations via cross-attention, producing visually grounded se-mantic features and improving support-query alignment. A pseudo-label re-finement strategy is also used to obtain query-adaptive representations. 

– Extensive experiments on four widely used benchmarks demonstrate the ef-fectiveness of our method, which generally outperforms existing approaches. 

## 2 Related Work 

Few-shot Semantic Segmentation. Few-shot semantic segmentation (FSS) aims to segment query images using only a few annotated support samples. Exist-ing methods can be broadly categorized into prototype-based and affinity-based methods. Prototype-based approaches [8, 15, 13, 19, 29, 32, 34] construct category prototypes from support images and segment queries by measuring feature simi-larity. However, prototype construction typically relies on masked average pool-ing, which may discard fine-grained spatial structures and limit representation capacity. Affinity-based methods [20, 21, 24, 40] model dense correspondences be-tween query and support images, better preserving contextual and structural information. Despite their strong performance, traditional FSS approaches gen-erally assume similar training and testing distributions, and often degrade under significant domain shifts. 

Cross-domain FSS. Cross-domain few-shot semantic segmentation (CD-FSS) considers a more challenging setting with significant domain shifts between 4 T. Wei et al. 

source and target domains. Existing methods mainly address this problem by learning domain-invariant representations or adapting models to target-domain data. PATNet [14], DMTNet [4], and IFA [22] model support-query relations to reduce domain-specific variations, while ABCDFSS [11] and DR-Adapter [30] adapt pre-trained features or rectify domain styles at test time. APSeg [10] fur-ther constructs query prototypes through cycle consistency and maps features into a stable domain-agnostic space. More recently, TVGTANet [18] incorporates vision-language modeling by leveraging semantic information from prompts to guide CD-FSS. 

Foundation Models for Segmentation. Large-scale vision and vision-language foundation models, such as CLIP [25], DINO [23], and LLaVA [17], have demon-strated strong zero-shot and few-shot generalization across downstream tasks. The Segment Anything Model (SAM) family has emerged as a representative foundation model for promptable segmentation. SAM [12] enables prompt-based zero-shot segmentation using visual cues, while SAM 2 [26] extends this capabil-ity to video through a temporal memory mechanism. More recently, SAM 3 [3] in-corporates vision-language alignment to support open-vocabulary segmentation. Despite their strong zero-shot capabilities, these models remain constrained by significant domain shifts in specialized scenarios. To bridge this gap, we propose ViTA-SAM, which combines the visual representations and textual guidance of SAM 3 with annotated support images for few-shot segmentation. 

## 3 Methodology 

3.1 Task Formulation 

Following the meta-learning paradigm [14], the FSS task is formulated as learn-ing from a series of episodes. Each episode consists of a query set Q = {(Iq , M q )}

and a support set S = {(Isk , M sk )}Kk=1 , where both sets belong to the same cat-egory. We denote I ∈ RH×W ×3 as the input image and use M ∈ { 0, 1}H×W to represent the corresponding binary ground-truth mask. K represents the shot number, indicating the number of annotated support samples available to guide the segmentation of the query image Iq . The objective is to acquire a segmenta-tion model fθ that predicts the query mask ˆM q = fθ (Iq , S). During the inference process, the model is evaluated on episodes sampled from the test set Dtest .

Unlike traditional prototypical approaches that compress support infor-mation into a single vector, our design maintains spatially-aware feature repre-sentations to provide fine-grained guidance during query segmentation.

3.4 Cross-Modal Alignment Textual Feature Extraction. While the support memory captures appearance-level cues from annotated support images, semantic priors provide complemen-tary category-level information. To incorporate such semantic guidance, we ex-tract textual representations using the text encoder T E of SAM 3. Given a textual prompt T , the text encoder produces a semantic embedding: 

F t = T E (T ) ∈ RL×C , (4) where L denotes the number of text tokens. We keep the text encoder frozen to preserve its generalization ability. The resulting embedding encodes category-level semantics and serves as a complementary source of guidance for segmenta-tion. Compared with the support memory, which mainly conveys instance-level visual cues, the textual feature provides more abstract semantic information and is generally more robust to appearance variations across domains.

## 4 Experiment 

4.1 Datasets 

We evaluate our method on four widely used benchmarks covering diverse tar-get domains: ISIC2018 [5], Chest X-ray [2], DeepGlobe [7], and FSS-1000 [16]. ISIC2018 contains 2,596 images from three skin lesion categories and presents challenges in fine-grained texture discrimination. Chest X-ray consists of 566 annotated lung X-ray images characterized by low contrast and structural noise. DeepGlobe provides high-resolution satellite imagery for land-cover segmenta-tion. Following [14], we exclude the ‘unknown’ class and use the remaining six categories (5,666 images). FSS-1000 contains 1,000 natural object classes, and we evaluate on its official test set of 2,400 images from 240 classes. 

4.2 Implementation Details. 

To preserve the foundational segmenting capabilities, we keep all SAM 3 compo-nents frozen and adopt a parameter-efficient adaptation strategy by optimizing only the proposed cross-modal alignment module. We adopt the Adam opti-mizer with a learning rate of 1 × 10 −4 and supervise the model using binary cross-entropy loss. To align with the original image input setting of SAM 3, im-ages are resized to 1024 × 1024 , with a batch size of 1. For text input, we use template-based prompts constructed from category names Following the stan-dard evaluation protocol in prior work [34], we use mean Intersection over Union (mIoU) as the evaluation metric. 

4.3 Main Results Comparison with Existing Methods. The proposed method is comprehen-sively compared with state-of-the-art approaches for both traditional few-shot semantic segmentation and cross-domain few-shot semantic segmentation. The results are presented in Table 1. Traditional FSS methods perform competi-tively on FSS-1000, which mainly contains natural images, but generally suffer substantial performance degradation on specialized target domains. In contrast, ViTA-SAM achieves the best average performance, surpassing the previous best results by 6.13% and 4.69% in average mIoU under the 1-shot and 5-shot set-tings, respectively. It achieves the best performance on Chest X-ray, ISIC, and FSS-1000, demonstrating strong generalization across diverse target domains. Particularly, notable gains are observed on the medical datasets Chest X-ray and ISIC, demonstrating the effectiveness of our method under substantial do-main shifts. On the challenging Deepglobe benchmark, ViTA-SAM still achieves the best 1-shot result and remains highly competitive in the 5-shot setting. Moreover, the larger overall improvement under the 1-shot setting suggests that ViTA-SAM is particularly effective when only limited support supervision is available. 4.5 Discussion Effectiveness of Cross-modal Alignment. SAM 3 supports text-driven seg-mentation by taking textual prompts as input and predicting corresponding regions. However, under significant domain shifts, such as medical and satellite imagery, textual semantics can be poorly aligned with target-domain visual pat-terns. We therefore compare the raw outputs of the SAM 3 text branch with those obtained after introducing the proposed cross-modal alignment mecha-nism, which incorporates memory-enhanced visual representations. As shown in Table 4, the original SAM 3 achieves moderate performance on FSS, which contains relatively common object categories, but performs poorly on the other datasets. In particular, the results on ISIC and Chest X-ray are close to zero, indi-cating that textual prompts alone provide insufficient guidance under substantial domain shifts. After introducing the proposed alignment strategy, performance improves consistently across all benchmarks, demonstrating the importance of grounding textual representations with memory-enhanced visual features for re-liable cross-domain segmentation.

## 5 Conclusion 

In this work, we present ViTA-SAM, a cross-modal few-shot semantic segmen-tation framework built upon the SAM 3 foundation model. Our approach inte-grates visual memory with textual features, where the visual memory provides support-aware structural guidance and the textual features introduce comple-mentary semantic priors. We introduce a lightweight cross-modal interaction mechanism that conditions textual features on memory-enhanced visual repre-sentations, producing more consistent and visually grounded predictions. In ad-dition, we introduce a pseudo-label refinement strategy that updates the memory using predicted query masks, enabling query-adaptive representation learning. Extensive experiments on multiple benchmarks show that ViTA-SAM consis-tently improves over existing methods.
