## 摘要
对比语言-图像预训练（CLIP）在图像级开放词汇分类任务中表现出优越性能，这得益于其对视觉特征和文本嵌入的强大对齐能力。然而，密集预测任务要求模型进行像素级预测，因此需要对 CLIP 进行修改以实现区域-文本对齐。本文调整了 CLIP 原始视觉编码器中的注意力层。通过一种针对选择性注意力特征的新注意力计算方法，模型保留了更多区域语义信息。为进一步缓解模态差距带来的负面影响，我们引入额外的视觉原型来改进仅基于文本嵌入的原始预测器。具体而言，选择预测置信度高的图像块特征来构成额外的基于记忆的辅助分类器，以实现更准确的预测。我们进一步将可优化特征提取器与指数移动平均更新策略相结合，以提升预测质量。在 5 个语义分割数据集上的大量实验证明了我们方法的有效性。

## Abstract
Contrastive Language-Image Pre-training (CLIP) has shown superior performance in the image-level open-vocabulary classification task, benefiting from its powerful alignment of visual features and text embeddings. However, dense prediction tasks require models to perform pixel-level predictions, necessitating modifications to CLIP for region-text alignment. In this paper, we adjust the attention layers within the vanilla visual encoder of CLIP. With a novel attention calculation method for selective attention features, the model retains more regional semantic information. To further mitigate the negative impact of the modality gap, we introduce additional visual prototypes to refine the original predictor solely based on text embeddings. Specifically, patch features with confident predictions are selected to form an additional auxiliary memory-based classifier for more accurate prediction. We further integrate an optimizable feature extractor with an exponential moving average updating strategy to enhance prediction quality. Extensive experiments on $5$ semantic segmentation datasets demonstrate the effectiveness of our method.

- **CLIP 的适配困境**：CLIP 通过大规模图文对比学习在**图像级**开放词汇分类上表现优异，但其视觉编码器采用全局注意力池化，输出的是整图级特征，与密集预测所需的**像素级区域-文本对齐**存在结构性错配。
- **已有工作的不足**：
  - MaskCLIP 发现注意力模块中的 value 特征已蕴含丰富像素级语义，直接丢弃 q/k、用 value 与文本嵌入计算相似度即可获得分割掩码，但结果仍存在明显噪声。
  - 后续研究指出，注意力中的 q-k 映射倾向于聚合**全局信息**，可能把不属于同一语义类别的特征拼接在一起，削弱相邻像素间的语义相关性。
  - 此外，CLIP 固有的**视觉-文本模态差距（modality gap）** 使仅依赖文本嵌入的预测器存在系统性偏差。

## 2. 方法论

### 2.1 核心思想
在不重新训练 CLIP 的前提下，从两个层面精炼预测：(a) 在视觉编码器最后一层注意力中用 **v-v 自注意力**替代 q-k 注意力，强化邻域语义一致性；(b) 用高置信像素特征构建**类别级视觉原型记忆库**，作为文本预测器之外的辅助分类器，以视觉域内相似度补偿跨模态差距。

### 2.2 区域语义保留模块（Regional Semantic Preservation Module）
- 原始 CLIP 注意力池化为：`Attn_qk = Σ_i softmax(q̄·k_iᵀ/√C)·v_i`，其中 q̄ 为所有 query 的均值。
- 论文**丢弃 W_q 与 W_k 投影**，仅保留 W_v 输出的 value 特征，改为：
  `Attn_vv = Σ_i softmax(v̄·v_iᵀ/√C)·v_i`
- 该修改强调相邻像素级特征之间的相似性，促进近邻特征的聚类，聚合语义相关区域、抑制语义无关区域的注意力响应。
- **仅修改最后一个自注意力层**，以最小改动保留预训练特征提取能力与局部信息完整性。对 ResNet-50 版本，则是重写最终全局池化层，将 q/k 投影替换为 v 投影。

### 2.3 视觉原型预测增强（Prediction Enhancement with Visual Prototypes）
- **流程**：
  1. 用上述改造后的编码器 Ψ_I 对无标签目标数据集逐图提取像素级特征 `F_i^image`；
  2. 用文本嵌入预测器 `C_t(·)` 得到初步类别概率 `p_s = C_t(F_n^image)`；
  3. 对每个类别 c，挑选置信度 **Top-K** 的像素特征，取平均得到视觉原型：
     `F_c^pixel = (Σ_{k=1}^{K} F_{ck}^pixel) / K`
  4. 将原型归一化为与文本嵌入同形式，构成基于视觉嵌入的预测器 `C_p(·)`；
  5. **残差式融合**：`p = C_t(F^image) + λ·C_p(F^image)`，λ 为残差比例。
- **设计意图**：利用视觉嵌入与输入图像之间的**域内相似性**来缓解 CLIP 的视觉-语言模态差距，同时保留文本嵌入所携带的丰富语义知识。

### 2.4 自训练与 EMA
- 将 CLIP 视觉编码器替换为面向分割定制的辅助特征提取器（DeepLabv2-ResNet101，ImageNet 预训练初始化）。
- 以 2.3 节精炼预测器 `C_r(·) = C_t + C_p` 在无标签样本上生成的掩码作为**伪标签**进行优化，全程不使用任何人工标注。
- 推理阶段采用指数移动平均平滑参数：`EMA_t = β·X_t + (1-β)·EMA_{t-1}`，β = 0.9999。

## 6. 主要结论与发现

- 在 annotation-free 设定下，方法在 ADE20K（17.2%）、Cityscapes（32.5%）、PASCAL Context（33.7%）上取得 SOTA，平均 mIoU 达 **35.9%**，优于 TCL（33.9%）、ReCLIP（32.8%）、GroupViT（30.7%）等。

- **残差融合设计合理**：`C_t + λC_p` 在引入视觉域信息的同时保留了文本语义知识，避免完全抛弃 CLIP 的开放词汇能力。
