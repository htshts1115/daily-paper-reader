ABSTRACT 

Contrastive Language-Image Pre-training (CLIP) has shown supe-rior performance in the image-level open-vocabulary classification task, benefiting from its powerful alignment of visual features and text embeddings. However, dense prediction tasks require models to perform pixel-level predictions, necessitating modifications to CLIP for region-text alignment. In this paper, we adjust the attention lay-ers within the vanilla visual encoder of CLIP. With a novel atten-tion calculation method for selective attention features, the model retains more regional semantic information. To further mitigate the negative impact of the modality gap, we introduce additional visual prototypes to refine the original predictor solely based on text em-beddings. Specifically, patch features with confident predictions are selected to form an additional auxiliary memory-based classifier for more accurate prediction. We further integrate an optimizable fea-ture extractor with an exponential moving average updating strategy to enhance prediction quality. Extensive experiments on 5 semantic segmentation datasets demonstrate the effectiveness of our method. 

Index Terms — Semantic segmentation, Open-vocabulary, Con-trastive language-image pre-training 

1. INTRODUCTION 

Semantic segmentation [1, 2] aims to classify an image at the pixel level, applying segmentation masks to separate diverse objects in the input. Conventional semantic segmentation methods follow a supervised paradigm, relying on manually labeled category annota-tions. To address the limitations of predefined categories, the Open-Vocabulary Semantic Segmentation (OVSS) task has been proposed and is receiving widespread attention. OVSS aims to effectively han-dle entirely new categories during inference, which may not have ap-peared during training. Recently, visual language models [3, 4] have shown remarkable generalization performance in image-level classi-fication tasks [5, 6]. Inspired by this, some existing OVSS methods explore the potential of Contrastive Language-Image Pre-training (CLIP) [3] in pixel-level classification tasks. Most of them [4, 7, 8] follow a semi-supervised paradigm, utilizing both image-text pairs and additional dense annotations. Typically, these methods train a dense predictor with segmentation masks and expand target cate-gories using image-text pairs [9, 10]. Furthermore, recent works im-prove feature extraction with additional image-text pairs [11], clus-tering features [12, 13], modifying structures [14, 15], aiming to

convert image-level visual-text alignment to pixel-level visual-text alignment. MaskCLIP [14] revisits the global pooling layer of the visual encoder in the CLIP model, arguing that its value features already encompass rich pixel-level semantic information. Conse-quently, it directly calculates the similarity between the value fea-tures of the last attention module and the text embeddings to obtain accurate segmentation masks. However, the segmentation masks generated by MaskCLIP still exhibit noise. Recent work [16] sug-gests that while using the final value projection for prediction, the 

key and query projection in the attention module may concatenate features that do not belong to the same semantic category, thereby diminishing the correlation between pixels in neighboring regions. Additionally, existing methods remain constrained by the inherent vision-text modality gap of the CLIP. To address the challenging OVSS task, we propose an annotation-free method to obtain high-quality segmentation masks in this work. We begin by introducing a regional semantic preservation module to refine pixel-level visual features. In this module, we modify the attention layer of the original CLIP image encoder, selectively reusing features that contain rich pixel-level semantic information. We design a novel attention calculation method for these features, enhancing regional semantic coherence by calculating the similarity of adjacent pixel-level features. To preserve local information and maintain the integrity of feature extraction, we modify only the final attention layer in pre-trained CLIP. To mitigate the vision-language modality gap in CLIP, we fur-ther leverage additional visual prototypes of the entire unlabeled set to refine the dense predictions. For each semantic category, we select representative pixel-level features to form a visual feature memory module. Serving as an auxiliary dense predictor, the memory mod-ule computes the similarity of its vision embedding with the visual feature of the input image. The dense predictions from the auxil-iary predictor are combined with the outcomes by text embeddings to construct the final segmentation results. The core idea of this de-sign is to use the intra-domain similarity of the vision embedding and the input image to alleviate the vision-language modality gap inherent in CLIP. Additionally, we incorporate an additional feature extractor specifically tailored for semantic segmentation, optimizing it to enhance prediction performance further. The optimization is entirely supervised using model-generated masks of unlabeled sam-ples, without relying on any annotated information during the pro-cess. To improve generalization and stability, we adopt an Exponen-tial Moving Average (EMA) strategy to maintain a smoothly updated version of the feature extractor. 2.2. Regional Semantic Preservation Module 

Although Φ ( vi) contains abundant per-pixel semantic information, it overlooks the semantic correlation among neighboring regions. Additionally, the q-k mapping in the self-attention module encour-ages the model to focus on the global information of images, which may not be suitable for dense prediction tasks. To address this is-sue, we propose the Regional Semantic Preservation Module, aimed at guiding the model to focus more on regional semantic informa-tion. Specifically, as demonstrated in Figure 1, we introduce a novel self-attention calculation method to promote the consistency of vi-sual features in adjacent spatial regions. 2.4. Self-training 

To fully harness the capabilities of the segmentation network, we replace the vision encoder of CLIP with an optimized auxiliary fea-ture extractor customized for semantic segmentation. We utilize the segmentation outcomes generated by the refined predictor in Sec-tion 2.3 as pseudo-labels for optimization. To express concisely, the revised predictor is ensembled by Ct (·) and Cp (·), which is ex-pressed as Cr (·). We replace the original classifiers with Cr (·), to produce open-vocabulary semantic segmentation. Additionally, we employ the Exponential Moving Average (EMA) in the inference stage to smooth the learned parameters of the target feature extrac-tor, EMA t = β · Xt + (1 − β) · EMA t−1. We follow the official settings ( β = 0 .9999 ) for model inference.

4. CONCLUSION 

In this work, we focus on open-vocabulary semantic segmentation with an annotation-free setting. In this task, dense features gener-ated by CLIP’s visual encoder are utilized to align with text embed-dings for dense prediction. We suggest that the inherent attention mechanism of the image encoder in CLIP is not entirely suitable for semantic segmentation, as the visual features tend to focus on the global information of the image rather than pixel-level seman-tics. We propose a novel attention computation approach that en-courages the image encoder to preserve semantic consistency among features from adjacent regions to a greater extent. Additionally, we introduce a feature memory module that stores visual feature proto-types as an additional predictor, collaborating with text embeddings for dense prediction. Our approach achieves state-of-the-art perfor-mance across multiple benchmarks, demonstrating the superiority of the proposed components. 5. ACKNOWLEDGMENTS
