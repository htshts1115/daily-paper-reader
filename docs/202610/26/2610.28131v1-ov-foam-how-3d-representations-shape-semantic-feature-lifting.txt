Abstract 

Existing feature lifting approaches for open-vocabulary segmentation rely on simple backprojection to assign features to primitives. In the case of 3D Gaussian splatting reconstruction, the primitives overlap heavily, leading to suboptimal reconstructions, governed by many primitives per ray. Backprojection, however, reduces to a least-squares solvable problem, exactly when no two primitives share a ray. Motivated by this insight, we propose OV-Foam, which uses PowerFoam as the underlying representation. This representation uses a power-diagram to partition the scene, resulting in zero overlap between primitives and a substantial reduction in primitives per ray, which ultimately simplifies the lifting problem and allows for closer-to-optimal feature assignment. We show that the space partitioning primitives of OV-Foam reach near-optimal assignment, and our experiments demonstrate improved open-vocabulary segmentation over Gaussian baselines.

Open-vocabulary 3D segmentation assigns vision-language aligned semantic features, such as those produced by CLIP (Radford et al., 2021b), to reconstructed scenes, allowing objects and spatial regions to be identified using free-form language queries. This capability supports applications such as robotic manipulation (Gu et al., 2024), complex scene understanding (Kerr et al., 2023) and medical-imaging (Wang et al., 2025). Existing approaches include grouping-based methods, training-based methods, and heuristic-based methods. We focus on the latter family, which directly lifts features from 2D images onto a 3D representation. The process of assigning these features to scene geometry is known as feature lifting . It associates features observed in rendered images with the primitives contributing to each pixel, using their rendering weights to aggregate information across views. This provides an efficient way to obtain semantic representations without training a 3D foundation model from scratch, but introduces a fundamental ambiguity: a 2D observation may be distributed across multiple primitives, while a primitive may collect observations from different objects. As a result, feature lifting can entangle semantic evidence before a classifier makes a prediction. This ambiguity is particularly important near object boundaries. Repeating the lifting process across views can produce feature entanglement and degraded semantic boundaries, even when the underlying image features are accurate. Recent work has begun to formalize this problem by treating feature lifting as a linear inverse problem and quantifying the ambiguity introduced by multiple primitive contributions (Xiong et al., 2026). Existing feature-lifting methods largely operate on Gaussian-based reconstructions, where overlap leads to multiple primitives contributing to the same ray. This raises a more fundamental question: to what extent is feature-lifting ambiguity a property of the lifting procedure itself, and to what extent is it induced by the underlying 3D representation? In this work, we investigate feature lifting as a representation-dependent problem. We ask whether changing the geometric primitives used to represent the scene can reduce the mixing of semantic evidence, while keeping the image features and lifting procedure fixed. We consider PowerFoam (Govindarajan et al., 2026), which represents a scene using bounded power diagrams whose cells partition 3D space. This non-overlapping spatial support reduces the number of primitives that can contribute simultaneously to a ray, reducing semantic feature mixing. We isolate this effect, by evaluating feature lifting independently of errors introduced by the upstream 2D semantic model. We replace predicted image semantics with ground-truth segmentation and text features, allowing us to measure the extent of semantic feature mixing caused by a feature lifting onto a chosen underlying 3D representation. Under this controlled setting, we compare Gaussian-based and PowerFoam reconstructions using the same lifting procedure and find that the reduced dispersion in PowerFoam leads to substantially more class-consistency in lifted features. This demonstrates that the choice of 3D primitive can itself impose a significant limitation on semantic feature lifting. Applied to real datasets, we observe that all our tested lifting methods achieve improved 3D open-vocabulary segmentation results using PowerFoam instead of 3DGS as underlying representation. Our contributions are: • A controlled study of representation-dependent feature lifting. We isolate the feature-lifting stage from upstream semantic errors and systematically compare 3D primitives under the same image features and lifting procedure. • An analysis of representation-induced feature dispersion. We show that space-partitioning primitives can substantially reduce semantic feature mixing compared with overlapping Gaussian primitives. • An open-vocabulary 3D segmentation system based on PowerFoam. We incorporate these insights into a PowerFoam-based semantic representation and demonstrate improved performance on open-vocabulary 3D segmentation benchmarks. 22 Related work 

Existing approaches for lifting 2D features to 3D primitives differ primarily in how the correspondence between image observations and 3D primitives is established: through training-based, grouping-based, and heuristic-forward methods. Early approaches fit continuous 3D semantic fields via scene-specific optimization. LERF, for example, distills CLIP features into a radiance field (Kerr et al., 2023; Radford et al., 2021b), while LangSplat trains a scene-specific autoencoder to represent lifted features in a latent space (Qin et al., 2024). OpenGaussian similarly learns instance-level features together with a codebook for point-level understanding (Wu et al., 2024). These methods can produce expressive semantic representations, but require computationally expensive per-scene optimization and may inherit inconsistencies from the underlying multi-view 2D predictions. An alternative is replacing continuous optimization with discrete associations derived from 2D masks (e.g., SAM (Kirillov et al., 2023)). LAGA decomposes scenes into object entities by clustering SAM mask descriptors across views (Cen et al., 2025), while THGS constructs Gaussian adjacency graphs with contrastive edge reweighting for hierarchical superpoint partitioning (Dai et al., 2025). LUDVIG avoids training altogether by combining multi-view weighted feature averaging with graph diffusion across adjacent primitives (Marrie et al., 2025). Although these approaches eliminate dense feature optimization, they introduce multi-stage grouping heuristics and remain sensitive to primitive spatial overlap. More recent methods avoid additional optimization by directly inverting the image-to-primitive aggre-gation used during rendering. Occam’s LGS (Cheng et al., 2025), CosegGaussians (Dou et al., 2025), and DrSplat (Jun-Seong et al., 2025) independently use row-normalized splatting equations as zero-shot feature lifter.

Splat Feature Solver (SFS) (Xiong et al., 2026) formu-lates feature lifting as a sparse linear inverse problem and provides a closed-form row-sum estimator with a provable approximation bound. Specifically, SFS defines β as a mea-sure of the dispersion of the optimal lifted feature along a viewing ray. In the case where each ray intersects only a single primitive, each row of the system matrix contains a single non-zero entry of value one, yielding this zero-dispersion regime. Standard 3D Gaussians, however, have substantial spatial overlap, causing multiple primitives to contribute to the same ray and increasing feature dispersion (Figure 2). SFS therefore introduces Tikhonov Guidance, which modifies the opacity weights during lifting to in-crease diagonal dominance and reduce this coupling. Thus, while SFS provides a principled formulation and efficient solver, its lifting accuracy remains tied to the overlap struc-ture of the underlying Gaussian primitives. An alternative to mitigating primitive overlap through the lifting procedure is to eliminate overlap at the repre-sentation level. Space-partitioning representations divide the scene into disjoint spatial cells, so each 3D location is associated with a single primitive by construction. Radiant Foam (Govindarajan et al., 2025) represents a scene using non-overlapping volumetric cells based on an unbounded Voronoi construction. However, its ray-tracing procedure relies on explicit cell stepping rather than tile-based rasterization, making it difficult to evaluate under the same rendering pipeline as standard 3D Gaussian Splatting. PowerFoam (Govindarajan et al., 2026) 3instead generalizes foam representations to bounded power diagrams, defining finite spatial cells through seed sites and per-cell radii. These bounded cells support tile-based rasterization while preserving disjoint spatial boundaries, making PowerFoam a suitable representation for studying feature lifting under otherwise comparable rendering conditions. Semantic Foam (Sharafeldin et al., 2026) jointly learns reconstruction and object-identity features supervised by segmentation masks. These features encode scene-specific identities rather than text-aligned semantics, so they cannot be directly compared with text embeddings for open-vocabulary queries. In contrast, we study feature transfer from fixed 2D observations onto an already trained reconstruction, allowing the effect of the underlying representation on lifting to be isolated from semantic optimization. Building on this setting, we introduce OV-Foam , an open-vocabulary 3D segmentation framework that lifts 2D vision-language features onto PowerFoam reconstructions. 

# 3 Method 

OV-Foam lifts image features onto a PowerFoam reconstruction. We first describe how the cells define rendering contributions, then use those contributions in the SFS feature estimator. We then examine how image observations are distributed across primitives and whether each primitive receives consistent features from one class or conflicting features from several classes.

Together, β, the fitting gap, and purity allow us to trace how the 3D reconstruction governs feature lifting: from how closely X′ approximates bX, to the class consistency of the evidence being aggregated, and ultimately to the accuracy of the recovered 3D labels. To disentangle these effects, we separate reconstruction-dependent errors from errors in the semantic observations serving as input to the lifting. We first isolate the geometric quality of the reconstruction by lifting ground-truth class masks encoded as text embeddings. Because both reconstructions receive perfect upstream labels, any difference in the resulting 3D labels proceeds from reconstruction and lifting process, unaffected by CLIP noise. We then evaluate open-vocabulary segmentation using real SAM/CLIP image features, testing whether the reconstruction-dependent effects persist under practical, noisy observation conditions. 

# 4 Experiments 

We evaluate the effect of the reconstruction on feature lifting at three levels. First, we compare the dispersion β

and the fitting gap L(X′)−L ( bX) to determine whether the observed differences in β correspond to differences in the quality of the one-shot lifting solution. We then examine purity and primitive-level prediction accuracy to determine whether the evidence accumulated by each reconstruction is more class-consistent. To isolate the effect of the reconstruction from errors in the input image features, we next lift ground-truth image labels encoded as class text embeddings. This controlled experiment gives both reconstructions the same correct semantic observations and therefore tests whether differences in the recovered 3D labels arise from the reconstruction and lifting process itself. Finally, we evaluate CLIP image features, measuring whether the same differences persist when the lifted observations also contain errors. 74.1 Dispersion and class purity

Centers and primitive counts remain fixed during reconstruction, and all reconstruction parameters remain fixed during lifting. Closer agreement with least squares does not establish whether a primitive receives consistent class evidence. We therefore measure purity from the evidence accumulated by the renderer and compare it with prediction accuracy when lifting CLIP features. Each observation contributes according to its rendering weight Aij , and purity measures the fraction of accumulated class evidence belonging to the dominant class. Figure 4 shows that accuracy increases with purity across all five bands for both representations. PowerFoam places more evaluated points in the highest-purity band, where predictions are most accurate. Its advantage therefore includes a more favor-able distribution of incoming evidence, rather than consistently higher accuracy within every band. Purity tracks prediction accuracy even with real image features, but does not guarantee correct labels. Even points assigned to the highest-purity primitives remain frequently misclassified with real CLIP features. Their contributing rays mostly observe the same GT class, but the image features need not identify that class correctly. We therefore replace the image features with GT class embeddings to measure the segmentation errors that remain when the upstream labels are correct.

4.3 Open-vocabulary segmentation 

We adapt existing Gaussian-based methods’ feature lifting approaches to PowerFoam. Each method uses the same SAM/CLIP image features for both representations, allowing us to compare their segmentation results while holding the upstream observations fixed. For ScanNet, we follow OpenGaussian’s ten-scene point-level evaluation setup (Wu et al., 2024), with the changes to point assignment and opacity filtering described below. We assign each evaluated point its primitive’s predicted class and report mIoU (mean intersection over union) and mAcc (mean class accuracy). Predictions use three different class sets. For PowerFoam, we assign points using the reconstructed surface inside each cell, represented by its dipole, rather than the cell center alone. This surface can shift during reconstruction even when the center remains fixed, so the center need not lie in the primitive’s occupied region (Appendix B.1). OpenGaussian’s protocol excludes ground-truth points associated with Gaussians whose opacity is below 

0.1. However, low-opacity primitives can still contribute to rendering and receive features during lifting. Excluding their associated points removes part of the reconstruction from assessment and allows the evaluated point set to depend on the representation. It also means that a higher score on retained points need not imply better performance on the full scene. We therefore retain all valid labeled ground-truth points for both representations, so weakly represented regions remain part of the segmentation task. Under this common point set, PowerFoam improves both metrics for every tested method across all three class sets (Table 3). For the opacity-filtered evaluation, see Table 6. # 5 Limitations and conclusion 

Our ScanNet experiments cover ten scenes and initialize both representations from the same point cloud through the SfM initialization pipeline. For this benchmark, the supplied point cloud is the ground-truth geometry provided by ScanNet rather than an image-derived SfM reconstruction. The ground-truth lifting experiment isolates errors that remain with correct image labels, but does not establish an upper bound over all lifting methods. Our fitting-gap analysis concerns feature reconstruction loss rather than segmentation accuracy, and high purity can still reflect consistently incorrect observations. The observed advantages therefore depend on the reconstruction, input features, and evaluation setting. We investigated how the choice of reconstruction primitives affects feature lifting. Under matched reconstruction budgets, PowerFoam has fewer contributors per ray and lower measured dispersion than 3DGS, while placing more evaluated points on primitives with high-purity evidence. Its one-shot estimate is closer to its least-squares reference, and lifting correct image labels produces more accurate 3D segmentation. These advantages extend to real image features, adapting existing lifting methods to PowerFoam improves the tested ScanNet and LERF segmentation results. Together, these findings establish representation choice as a practical way to improve semantic lifting without requiring more accurate upstream image features. 10 AI use statement

# B ScanNet evaluation protocol 

We follow OpenGaussian’s ten-scene point-level evaluation setup (Wu et al., 2024). For our matched reconstructions, both representations start from the same ground-truth vertices, with one primitive per vertex. Primitive centers and counts remain fixed during reconstruction, while the remaining reconstruction parameters are optimized. We then hold the reconstruction fixed during feature lifting. We assign semantic labels by maximum cosine similarity to the class text embeddings and report mIoU and mAcc for the 19-, 15-, and 10-class evaluations. Within each scene, these metrics average class IoU and class recall over the valid ground-truth classes present. Final scores average the scene results. 

B.1 Dipole-aware point assignment 

For OV-Foam, point ownership uses the reconstructed dipole geometry. A fixed initialization center need not lie on the occupied side of its primitive’s displaced surface. For each evaluation point q, we take the 64 Euclidean-nearest supported primitive centers and rank them by power distance ∥q − pj ∥2 − a2 

> j

. We select the first candidate satisfying (q − pj ) · nj ≤ hj (q), where hj (q) is the interpolated dipole height at the point’s tangent-plane coordinates. This test checks the occupied side of the dipole surface. If no candidate passes, we use the minimum power distance in the same pool. The fallback preserves assignment coverage, so the dipole test does not discard points. Power distances are evaluated in double precision. The finite candidate search approximates global power-distance ranking.
