tldr: 现有SAM 3等可提示分割模型依赖专用架构、大规模标注与任务训练，难以直接复用通用多模态大模型。LLMSeg提出免训练流程，将视觉大模型组织为检测、B样条描边与迭代精修三阶段，输出可检查的掩码几何。在ReasonSeg、RefCOCO系列及LVIS等任务上，它以Gemini-3.7-Flash为后端常可媲美甚至超过SAM 3，ReasonSeg val达71.5 cIoU。该工作证明无需分割头或重训即可让MLLM完成文本提示分割，并支持后端升级直接受益。

## 摘要
SAM 3 等可提示分割模型实现了显著的开放词汇性能，但需要专用架构、大规模标注引擎和任务特定训练。我们提出一个不同的问题：通用多模态大语言模型（MLLM）能否在无需额外分割头、掩码解码器或训练的情况下直接分割图像？我们提出 LLMSeg，一个无需训练的流水线，可将具备视觉能力的 LLM 转变为文本提示图像分割器。LLMSeg 将分割分解为三个由 LLM 驱动的阶段。首先，detect 阶段定位所有与自由形式文本查询匹配的实例，并描述其粗略形态。接着，segment 阶段使用限制在检测框内的闭合周期 B 样条描绘每个实例。这些样条定义外边界和可选的孔洞环。最后，refine 阶段围绕残余误差迭代提出聚焦框，并重新描绘受限样条。当掩码稳定或迭代预算耗尽时，该过程结束。输出为带有可检查中间几何的二值掩码。我们在十个指代分割与推理分割划分（ReasonSeg 和 RefCOCO/+/g）上评估 LLMSeg。我们还评估了开放词汇实例分割（LVIS、COCO 和 SA-Co）、语义分割以及零样本检测（ODinW13 和 RF-100VL）。在使用现成的 Gemini-3.7-Flash 后端时，LLMSeg 在相同条目上与专用 SAM 3 模型具有竞争力，且经常超越后者。在无需额外分割特定训练的情况下，它在 ReasonSeg val 上达到 71.5 cIoU。后端模型更新可在不重新训练流水线的情况下提升准确率。代码可在 https://abdullahamdi.com/llmseg 获取。

## Abstract
Promptable segmentation models such as SAM 3 achieve remarkable open-vocabulary performance but require dedicated architectures, large-scale annotation engines, and task-specific training. We ask a different question: can a general-purpose multimodal large language model (MLLM) segment images directly, without an added segmentation head, mask decoder, or training? We present LLMSeg, a training-free pipeline that turns a vision-capable LLM into a text-prompted image segmenter. LLMSeg decomposes segmentation into three LLM-driven stages. First, detect localizes all instances matching a free-form text query and describes their coarse morphology. Next, segment traces each instance using closed periodic B-splines confined to its detected box. These splines define an outer boundary and optional hole loops. Finally, refine iteratively proposes focus boxes around residual errors and retraces confined splines. The process ends when the mask stabilizes or the pass budget is exhausted. The output is a binary mask with inspectable intermediate geometry. We evaluate LLMSeg across ten referring and reasoning segmentation splits (ReasonSeg and RefCOCO/+/g). We also evaluate open-vocabulary instance segmentation (LVIS, COCO, and SA-Co), semantic segmentation, and zero-shot detection (ODinW13 and RF-100VL). With an off-the-shelf Gemini-3.7-Flash backend, LLMSeg is competitive with and often surpasses the specialist SAM 3 model on identical items. It reaches 71.5 cIoU on ReasonSeg val without additional segmentation-specific training. Backend model updates can improve accuracy without retraining the pipeline. The code is available at https://abdullahamdi.com/llmseg .
