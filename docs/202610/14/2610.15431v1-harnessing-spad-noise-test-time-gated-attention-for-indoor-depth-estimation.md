## 摘要
单目深度估计（MDE）已成为依赖硬件的三维传感模态的一种经济高效的替代方案，但由于固有的尺度模糊、边缘渗色以及未见环境中零样本泛化能力有限，预测精确的度量深度仍然是一项持续挑战。近期多模态方法引入一维/三维单光子雪崩二极管（SPAD）数据以解决这些模糊性，但它们主要将 SPAD 噪声视为需要去噪的有害伪影，或直接忽略该噪声。在本文中，我们提出一种本质不同的见解：原生 SPAD 噪声是一种信息性先验，隐式编码了确定性的环境特征。受这一范式转变驱动，我们通过利用 SPAD 噪声，提出一种新颖、轻量的测试时门控注意力框架，因此称为 HSN。HSN 面向室内场景定制，利用一维 SPAD 直方图与门控适配器（GAs）的协同组合。通过三个互补的优化阶段，它生成通道级门控注意力向量，以在推理时动态调整编码器特征图，有效解决尺度模糊和边界挑战，且无需承受其他 TTA 方法所面临的高昂计算开销或稠密三维模态。在具有挑战性的真实世界室内基准上的大量实验表明，HSN 在域内设置中实现了最先进的度量深度精度，同时在零样本泛化到陌生环境时展现出更大的潜力。此外，可解释性分析表明，在 SPAD 噪声增强时，所提出的门控注意力机制会自适应地将注意力转向更深的语义层。代码将公开提供。

## Abstract
Monocular depth estimation (MDE) has emerged as a cost-effective alternative to hardware-dependent 3D sensing modalities, yet predicting precise metric depth remains a persistent challenge due to intrinsic scale ambiguity, edge bleeding, and limited zero-shot generalization in unseen environments. Recent multi-modal approaches incorporate 1D/3D Single-Photon Avalanche Diode (SPAD) data to resolve these ambiguities, but they mainly treat SPAD noise as a harmful artifact required for denoising or leave the noise ignored. In this paper, we present an essentially different insight: native SPAD noise is an informative prior that implicitly encodes deterministic environmental characteristics. Driven by this paradigm shift, we introduce a novel, lightweight Test-Time Gated Attention framework by Harnessing SPAD Noise, therefore dubbed HSN. Tailored for indoor scenarios, HSN leverages the synergistic combination of 1D SPAD histograms and Gate Adapters (GAs). Through three complementary optimization phases, it generates channel-wise gated attention vectors to dynamically adjust encoder feature maps at inference time, effectively resolving ambiguous scale and boundary challenges without the heavy computational overhead or dense 3D modalities that other TTA methods suffer from. Extensive experiments on challenging real-world indoor benchmarks show that HSN achieves state-of-the-art metric depth accuracy in in-domain settings, while exhibiting even greater potential under zero-shot generalization to unfamiliar environments. Furthermore, interpretability analysis reveals that the proposed gated attention mechanism adaptively shifts attention toward deeper semantic layers under intensifying SPAD noise. Code will be made publicly available.

## 1. 核心问题与研究动机

- **核心问题**：单目度量深度估计（MMDE）虽仅需单相机、成本低，但存在**尺度模糊**、**边界渗色**、**表面结构伪影**等固有难题，且在零样本跨域场景下急剧恶化。
- **现有方案及其缺陷**：
  - 硬件依赖方案（LiDAR、立体视觉、ToF、结构光）成本高、体积大。
  - 多模态方案引入 3D SPAD 体积、点云、IMU 或 1D SPAD 直方图，但 3D SPAD 网络**把噪声当有害伪影去噪**；1D SPAD 方法要么在全量训练中做多模态融合，要么仅在测试时做直方图匹配，**完全绕过原始噪声处理**。
  - 现有 TTA 方案（如 MfH 依赖扩散生成、DR-LiDAR 依赖稠密 3D 点云）计算开销大、硬件成本高，难以部署在低成本机器人上。
- **核心洞察（范式转变）**：原生 SPAD 噪声**并非纯污染**，而是**隐式编码确定性环境特征的信息性先验**。1D SPAD 信号在室内相对稳定，室外受环境光干扰严重，因此本文聚焦室内场景。
- **整体含义**：首次尝试将**噪声学习**用于测试时深度自适应，为稀疏数据体制下高效多模态感知开辟新路径。

## 2. 方法论

### 2.1 核心思想
- 提出 **HSN（Test-Time Gated Attention by Harnessing SPAD Noise）** 框架：在推理时**冻结预训练编码器-解码器网络 θ**，仅优化 **Gate Adapter（GA）模块参数 ϕ**。
- GA 模块嵌入在**被路由到解码器的选定编码器特征图**与对应解码层之间，利用 SPAD 噪声生成**通道级门控注意力向量**，动态校准编码器特征。

### 2.2 关键技术细节

**(a) 噪声标量估计（熵公式）**
- 将 SPAD 时间直方图 S ∈ R^{N×1} 转为噪声水平指示器 ω ∈ [0,1]：
  - ω = -1/ln N · Σ p_i ln(p_i + ε)，其中 p_i = S_i / (Σ S_k + ε)，ε = 10⁻⁹。
  - ω → 1 表示噪声主导（背景光子散射）；ω → 0 表示干净信号尖峰。

**(b) 门控注意力机制**
- F_out = F_in ⊗ (γ · σ(MLP(ω)))
- MLP 采用轻量瓶颈设计（1 → C_l/4 → C_l），**W₂、b₂ 零初始化**，配合 γ = 2，保证 TTA 起始时调制因子为 2·σ(0) = 1，**完全保留预训练特征**。
- 随 TTA 进行，在 (0, γ) 范围内自适应缩放特征图。

**(c) 三阶段 TTA 优化流程**

1. **统计分布对齐（ZoDA）**：
   - 从 SPAD 直方图计算物理深度期望 μ_s = Σ S_i·z_i / Σ S_i。
   - 阻尼全局偏移：D_base = clamp(D_init + κ·(μ_s - D̄_init), d_min, d_max)，未见数据 κ = 0.65，域内数据 κ = 0。
   - 自适应约束调制：未见数据用保守配置 {λ_f = 1.5×10⁶, γ = 0.995, ε = 0.02}；域内数据用噪声感知缩放 λ_f = clamp(C₁·exp(α·ω), λ_min, λ_max)，C₁ = 4×10⁵、α = 2.5，可靠性阈值放宽至 γ = 0.998、梯度裁剪 ε = 0.05。
   - 预优化评估：若 L_init < τ_exit 则提前退出。

2. **物理约束优化**：
   - 联合目标：L_TTA = ω · (λ_p L_phy + λ_f L_fid)，λ_p = 0.05。
   - **物理一致性损失 L_phy**：泊松负对数似然，通过虚拟 SPAD 模拟器（高斯核模拟激光脉宽、空间平均模拟低分辨率硬件、stop-gradient 尺度因子 s_phy 消除幅度模糊）对齐模拟与观测直方图。
   - **几何保真损失 L_fid** = λ₁L_smooth + λ₂L_huber：L_smooth 用图像亮度梯度指数衰减空间平滑惩罚；L_huber 用 Huber 估计器维持与 D_base 的一致性（小偏差二次惩罚、大偏差线性惩罚防梯度爆炸）。
   - 用 Adam 优化器更新 ϕ，学习率 η = 0.002，带梯度范数裁剪。

3. **稳定性审计机制（SA）**：
   - 若 L_final < γ · L_init 则接受 D_tta，否则**回滚**到 D_base，防止负适应。
   - 最终经后处理算子 Ψ(·) 输出 D*。

## 6. 主要结论与发现

- **域内 SOTA**：DAV1-N-L-HSN 取得 RMSE = 0.200，超越 16 个 SOTA 中的 15 个；ZoeD-M12-N-HSN RMSE = 0.264，优于 13/16。相比 3D 稠密 SPADnet(Linear)，RMSE 大幅降低 **42.4%**（0.200 vs 0.347）。
- **零样本泛化提升更显著**：HSN 将 DepthPro 推至 δ₁ = 0.948，UniDepthV2-L 推至 δ₁ = 0.980（Abs Rel 相对降低 11.1%）；轻量基线 DAV2-H-B 的 δ₁ 绝对提升 **17.5%**、Abs Rel 降低 **32.2%**。UniDepthV2-L-HSN（δ₁ = 0.980, RMSE = 0.186）已接近全监督 Oracle（δ₁ = 0.988, RMSE = 0.180）。
- **真实世界表现**：PhoMoNet-HSN 取得 SOTA（Abs Rel 0.154→0.141，RMSE 0.508→0.474）；DAV1-N-L-HSN 保持最高 δ₁ = 0.879。对弱基线（AdaBins、DAV2-H 系列）提升尤为显著。
- **消融结论**：ZoDA 对跨域迁移至关重要（去除后未见 δ₁ 从 0.689 跌至 0.427）；SA 防止负适应；L_phy 与 L_fid 具有互补协同效应；去除 ω 削弱跨域鲁棒性。
- **步数结论**：零样本比域内需要更多优化步数（3 vs 2），说明陌生特征分布对齐更难。
- **核心发现**：HSN 主要价值在于**弥合跨域泛化差距**，而非仅对域内做边际改进；1D 稀疏 SPAD 引导即可实现优于稠密 3D 方案的度量精度。

## 7. 优点

- **范式创新**：首次将 SPAD 噪声从"待去除伪影"重新定义为"环境信息先验"，并用于测试时深度自适应，视角新颖。
- **轻量高效**：仅优化 GA 模块的少量参数（瓶颈 MLP），使用 1D 稀疏 SPAD 信号，避免扩散模型或稠密 3D 点云的重计算负担，适合低成本平台。
- **即插即用**：适配任意编码器-解码器 MDE 架构，在 AdaBins、PhoMoNet、ZoeD、DAV1/DAV2、DepthPro、UniDepthV2 等多类模型上验证通用性。
- **鲁棒性设计**：零初始化保证 TTA 起始无损伤；稳定性审计机制带回滚，防止负适应；域内/未见双策略自适应切换。
- **可解释性**：门控注意力机制可解释，噪声增强时注意力自适应转向更深语义层。
- **物理引导**：虚拟 SPAD 模拟器（泊松似然 + 高斯核 + stop-gradient 尺度因子）将物理约束引入优化，设计巧妙。

## 8. 不足与局限

- **场景限制**：明确限定室内场景，因室外环境光干扰会破坏 1D SPAD 噪声结构的稳定性，适用性受限。
- **硬件依赖**：仍需单像素 SPAD 探测器采集 1D 直方图，并非纯 RGB 方案；无 SPAD 硬件的场景无法使用。
- **数据集覆盖有限**：真实世界评估仅用 RGB-SPAD 一个数据集，且规模较小；零样本评估主要在 NYU Depth V2 与 RGB-SPAD 上，缺少更广泛的室内外基准与多样传感器配置验证。
- **仿真数据依赖**：NYU Depth V2 的 SPAD 为仿真生成，可能与真实 SPAD 噪声分布存在差距。
- **性能上限**：零样本仍未达到 Oracle 水平（δ₁ 0.980 vs 0.988），且 DAV2-H 系列在真实数据上提升后仍低于部分基线。
- **算力信息不完整**：未报告训练时长、TTA 绝对延迟等实际部署关键指标。
- **超参数较多**：κ、λ_f、γ、ε、λ_p、λ₁、λ₂、α、δ 等大量经验设定，跨场景迁移时可能需要重新调参，泛化便捷性存疑。
- **PhoMoNet 饱和现象**：对已在训练中融合 1D SPAD 的模型（PhoMoNet），HSN 提升空间有限，说明方法对基线特性敏感。
